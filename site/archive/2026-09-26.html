Setting（研究设定）
在预训练流匹配VLA（SmolVLA和π0.5）中，将VLM骨干深度V、动作专家深度A和去噪步数D作为三个可联合配置的计算轴，在冻结原策略的前提下训练轻量级Exit Transformer实现中间层早退。
Motivation（研究动机）
流匹配VLA参数量极大，计算需求对机器人控制常常过高；现有方法主要跳过VLM骨干层或减少去噪步数，而动作专家的深度未被触及，缺少对计算分配位置的系统研究。
Insight（核心洞察）
V、A、D三个计算轴具有互补作用且最优计算预算依赖具体任务；通过KV缓存合成可以让动作专家比骨干退出得更深，从而在冻结预训练策略上以极少新增参数获得帕累托前沿改进。
Challenge（技术挑战）
  • 在不从头训练原策略的前提下，使中间深度成为有效退出点
  • 在跳过骨干层时合成缺失的KV缓存，支持动作专家退出深于骨干（A>V）
  • 不同机器人任务对不同计算轴和深度的敏感性差异显著，固定预算次优
Analyze（问题分析）
作者将VLA计算分解为骨干深度V、动作专家深度A和去噪步数D三个轴，并定义RQ1（各轴作用与组合）、RQ2（任务依赖性）、RQ3（动作专家早退与KV合成有效性）；通过在两款流匹配VLA和两个基准上测量成功率、FLOPs和延迟来刻画边际效应与联合权衡。
Method（方法）
  • 将VLM骨干深度V与动作专家深度A解耦，暴露为两个独立可配置的计算轴
  • 在骨干和动作专家的中间深度附加轻量级Exit Transformer（ET），通过蒸馏策略最后一层来训练各退出点
  • 引入KV缓存合成机制，用被跳过层自身的键值矩阵重新投影已退出前缀，填补缺失的键值槽位
  • 将去噪步数D作为第三个无需训练的计算轴，与V、A联合配置
Experiments（实验）

  • 联合配置(V,A,D)将延迟降低79.2%、FLOPs降低31.8%，同时平均成功率提升5.6%
  • V和A分别降低FLOPs和延迟，D同时改善两者
  • 全策略仅在11/50个SmolVLA任务和22/50个π0.5任务上是最优配置；逐任务选择最优轴可将平均成功率从60.7%提升到79.5%（SmolVLA）和从64.9%提升到75.9%（π0.5）

Limitations（局限）

  • VLA应学习灵活分配计算预算，自适应计算选择策略留待未来工作

Setting（研究设定）
研究在机器人部署时出现硬件偏移（如 actuation bias 与 joint encoder offset）的情况下，如何让原本无记忆的 VLA 策略利用自身失败 rollout 作为上下文进行迭代自适应，而无需持续现场重新标定。
Motivation（研究动机）
VLA 模型在机器人操作中表现强大，但其无记忆特性使其对测试时环境偏移脆弱，尤其是硬件磨损或标定不完美导致的硬件偏移；将部署硬件与训练配置完美对齐耗时且在大规模真实机器人部署与维护中往往不现实。
Insight（核心洞察）
可以通过后训练配方，让策略把部署时的失败 rollout 压缩为潜在 context token，并通过 AdaLN 调制基础策略；且该 token 可被集成，使策略逐步自我纠正。
Challenge（技术挑战）
  • VLA 无记忆或上下文窗口很短，对重复失败模式不敏感
  • 硬件偏移在制造公差和磨损下普遍存在
  • 大规模真实部署中持续现场重新标定不现实
  • 在安全关键任务中假设可安全收集次优 rollout 可能不成立
Analyze（问题分析）
作者将硬件偏移建模为 actuation bias 与 joint encoder offset 两类；通过在故意注入硬件偏移下收集策略 rollout 作为上下文，并将基础策略训练数据中的专家动作预补偿为 shift-conditioned expert demonstrations；分析发现学到的 context token 位于结构化潜在空间，硬件偏移的自由度作为主轴；通过对上下文模态与编码器设计的消融，说明机器人本体感觉对两类偏移都有益，对 actuation bias 尤其关键。
Method（方法）
  • 收集在故意注入硬件偏移下的策略 rollout 作为上下文数据
  • 将基础策略训练数据转换为 shift-conditioned expert demonstrations，通过对已知偏移预补偿专家动作
  • 引入轻量插件式 context encoder，将视觉观察、本体感觉和偏移环境中的动作压缩为潜在 context token
  • 通过 adaptive layer normalization (AdaLN) 用 context token 调制策略
  • 发现 context tokens 可集成，使策略逐步迭代自我纠正并缓解失败
Experiments（实验）
  • 在四个 precision-critical bi-manual 与 dexterous manipulation 任务上实验，使用 6-DoF Piper 和 Piper-X 臂、7-DoF Marvin 臂、20-DoF Wuji Hands
  • 在两种硬件偏移设置下，基础策略成功率从接近 100% 降至接近 0%
  • Self-Adaptive VLA 在单次试验后恢复 46%-49% 性能，集成最多 6 次试验后恢复 80%-84%
  • 推理时无额外计算开销
  • 分析表明学到的 context token 位于结构化潜在空间，硬件偏移的自由度作为主轴
  • 消融表明机器人本体感觉对两类偏移有益，对 actuation bias 尤其关键
  • 演示了 Self-Adaptive VLA 对新工作站未知硬件偏移的鲁棒测试时自适应
Limitations（局限）
  • 当前框架主要局限于可在机器人配置空间内直接建模的部署时偏移，如 joint encoder offsets 与 actuation bias
  • 未来工作应扩展至更广泛的环境差异，如 camera calibration errors
  • 将次优轨迹编码为静态 token 虽消除了闭环控制中的推理开销，但本质上排除了 trial 内自适应
  • 方法假设环境允许安全收集次优策略 rollout；在初始失败可能导致不可逆硬件损坏的安全关键任务中该假设可能不成立

Setting（研究设定）
真实机器人高精度操作任务，包括插入与装配，要求亚毫米级精度
Motivation（研究动机）
当前VLA模型在高精度机器人操作中表现不佳，作者归因于视觉注意力分散在任务无关区域，且标准端到端训练的动作目标不直接约束模型关注位置
Insight（核心洞察）
可以从VLA自身的动作目标中直接导出空间监督：通过反事实视觉干预抑制某区域视觉证据，观察动作预测损失的增加量，从而识别对动作预测关键的区域
Challenge（技术挑战）
  • 避免依赖外部标注、人类注视或外部接地模型来获取空间监督
  • 在早期训练阶段VLA策略动作预测不可靠，导致反事实监督信号不稳定
  • 反事实分析仅停留在视觉层面，扰动可能引入分布偏移
  • 空间监督源自初始策略，受其知识偏差限制，蒸馏无法完全消除
Analyze（问题分析）
作者基于先前工作和实证分析指出视觉注意力错配是VLA策略的主要失败模式，进而提出用反事实问题估计策略对某区域的依赖：若抑制该区域视觉证据而保持其余观测不变，动作预测损失增加越大，则该区域越关键
Method（方法）
  • 通过反事实视觉干预估计动作预测损失变化，得到空间相关性监督信号
  • 训练注视头（gaze head）预测任务相关区域
  • 采用分阶段训练实现空间知识蒸馏与策略精炼
  • 将学到的空间引导通过注视到动作精炼转移回VLA策略
  • 使用一轮迭代精炼以平衡收益与计算成本
Experiments（实验）
  • 在四个真实机器人高精度操作任务上评估，平均成功率从77.0%提升到91.5%
  • 相比CoT Grounding和Implicit Grounding平均成功率分别高32.5%和25.0%，且不需要它们使用的外部空间监督
  • 消融实验：去除反事实监督后Straw和LEGO任务成功率降至37.5%；去除分阶段训练降至62.5%；完整ActGaze为92.5%
  • 使用Ground-Truth Alignment Score评估空间对齐，手工标注200帧仅用于评估
  • 迭代精炼第一轮增益显著，之后增益边际，因此只用一轮
Limitations（局限）
  • 反事实分析在视觉层面而非物理环境中建立因果关系，干预响应可能受扰动引起的分布偏移影响，应解释为相关性估计而非强因果效应
  • 空间监督源自初始策略，注视学习受其已有知识和偏差约束，偏差无法通过蒸馏完全消除，可能持续限制进一步性能提升

该工作直接面向具身智能中的VLA模型，关注可执行动作生成中的视觉注意力分配、真实机器人高精度评测与策略优化，其从动作目标自监督导出空间监督的思路可迁移到世界动作模型与系统优化中的注意力效率与训练稳定性研究

Setting（研究设定）
自动驾驶闭环驾驶任务。数据为SimLingo语料（CARLA仿真，约140小时、约2M帧、4fps，每帧带HLC、CF、VQA、CoT四类语言标注），其中仅使用约5%的语言标注；评测使用闭环Bench2Drive基准（220条路线）。
Motivation（研究动机）
VLA可支持人类可操控的自动驾驶，但训练受限于与自然语言指令配对的帧极为稀缺，而摄像头流与专家轨迹却可大规模记录；获取语言标注（如高层指令、反事实指令、VQA、思维链）成本高昂，制约VLA规模化训练。
Insight（核心洞察）
大量无语言标注的观测-轨迹对本身已隐含驾驶意图；通过对全量语料上的轨迹做视觉条件离散瓶颈压缩，可在无语言监督下提取紧凑的车辆意图码本，再把少量语言标注映射到该低维离散潜动作空间，从而把语言监督的负担转移到丰富的无标注轨迹上。
Challenge（技术挑战）
  • 带语言标注的帧稀缺（N_l << N），直接在小标注集上训练会丢弃大量专家演示
  • 在极少样本上训练的逆动力学模型（IDM）泛化差，难以用于伪标注其余数据
  • 码本规模C与序列长度L的选择需要平衡：过大瓶颈会让编码器记忆路径，过紧会把不同意图坍缩到同一码本条目
  • 反事实监督依赖仿真器特权状态，难以在真实世界复现
Analyze（问题分析）
作者以语言标注稀缺为出发点，指出朴素做法（在标注子集上训练分类器/IDM再伪标注）因样本过少而泛化差；进而主张利用无标注观测-轨迹对隐含意图，通过全量语料上的视觉条件离散瓶颈提取意图码本，将问题转化为在离散码本上的C类分类，从而把语言监督需求压缩到约5%。
Method（方法）
  • Stage I：训练带向量量化瓶颈的潜动作模型，在全量无标注观测-轨迹对上提取紧凑的高层车辆意图码本；码本形状(C,L)=(25,1)为主实验设置，并作为设计维度做消融
  • Stage I 产出伪标注数据集 D_hat = {(o_i, z_i, tau_i)}，其中 z_i = psi(o_i, tau_i)
  • Stage II：训练视觉语言翻译器 VLM_translator: O × L → Z，将观测与语言指令（HLC）映射到离散码本，即C类分类问题；通过在语言空间加入哨兵符号∅，用共享参数联合拟合条件分布 p(z|o,l) 与边缘分布 p(z|o)，在 D_tilde 上最小化单一交叉熵目标 L_TR
  • Stage III：在全量无标注语料上以观测-潜动作对训练驾驶VLA，采用行为克隆，对两个头使用smooth-L1损失
  • 推理时组合两模块：tau = VLM_driving(o, VLM_translator(o, l))
Experiments（实验）
  • 将LADA接入当前闭环驾驶SOTA VLA——SimLingo骨干，在8块NVIDIA A100 GPU上用bf16混合精度训练14个epoch，有效批大小96
  • 评测基准为闭环Bench2Drive：驾驶分数（DS）为220条路线上的路线完成度与违规罚分的平均分；成功率（SR）为在时限内且无交通违规完成路线的比例；同时报告各ability指标
  • 对照四类SimLingo基线，仅语言信号来源不同：Heuristic（人工规则伪标签）、IDM（5%标注）、Anchor（5%）、5-HLC（5% HLC）、Full-HLC（100% HLC）、Full-language（100% HLC+CF+VQA+commentary）
  • LADA仅用5% HLC和5% CF、不使用CoT与VQA，取得DS 87.98、SR 70.46%（3个随机种子，DS标准差±1.01、SR±2.08），超过Full-HLC（DS 82.85，SR 61.36%）约5 DS和9 SR
  • LADA也超过原Full-language SimLingo（86.08/65.78），DS提升+1.90、SR提升+4.68
  • 预算消融显示：将标注预算提高到20%几乎没有额外收益，说明现有预算已足够翻译器学习合适映射；进一步收益可能更依赖驾驶模型本身能力
Limitations（局限）
  • 所有实验均在CARLA仿真器中完成，标注效率收益能否迁移到传感器噪声更大、域偏移更明显的真实世界语料尚未验证
  • 反事实监督依赖仿真器特权状态，在真实世界环境中复现该机制是开放问题
  • 丢弃VQA与CoT标注后LADA牺牲了可解释性：模型无法解释其决策或回答场景级问题；未来工作可考虑整合这些语言监督来源，以及使用与速度相关的意图（如减速）进行更精细的车辆控制
