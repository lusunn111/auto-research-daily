At each action prediction step, FastVLA estimates task-conditioned patch importance via attention, measures distributional uniformity over selected vision tokens, and dynamically adjusts the compression rate using an online sliding-window calibration. FastVLA: Task-Conditioned and Temporally Adaptive Visual Token Compression for Efficient Vision-Language-Action Models

Jiuyi Xu · Chengyuan Qian · Zhengzhong Tu · Yang Sui · Yangming Shi

核心洞察

视觉 token 的重要性应由任务到视觉的注意力决定，而非通用视觉显著性；且每步可保留的 token 数应随重要性分布的集中程度自适应变化，用 inverse-Simpson 均匀度指标加滑动窗口在线校准来设定压缩率。

为什么值得看：提供了免训练、任务条件化且压缩率逐步自适应的 VLA 加速方案，在三个主干、两个仿真基准与真实 Franka 上验证，并给出与多种压缩/缓存/学习式基线的效率-性能对比，对关注 VLA 实时部署与推理优化的研究者具有直接参考价值。

Setting（研究设定）
闭环机器人操作部署中，VLA 模型在每个控制步将高分辨率、常为多视角的图像编码为数百个视觉 token，主导 LLM 主干的计算与延迟；目标是免训练地在推理时减少视觉 token 数量而保持任务成功率。
Motivation（研究动机）
VLA 闭环部署受推理效率限制，视觉 token 数量远超短任务文本 token；现有 VLM 式 token 压缩面向单次视觉理解，忽略控制决策中 token 重要性由任务决定、且各步预算变化大这两点，静态指标与固定预算会浪费计算或丢弃控制关键 token。
Insight（核心洞察）
视觉 token 的重要性应由任务到视觉的注意力决定，而非通用视觉显著性；且每步可保留的 token 数应随重要性分布的集中程度自适应变化，用 inverse-Simpson 均匀度指标加滑动窗口在线校准来设定压缩率。
Challenge（技术挑战）
  • 决策关键 token 由任务而非通用显著性决定
  • 各步 token 预算差异大，静态指标和固定预算不合适
  • 复用/缓存方法有跨步状态与缓存管理开销，实际时延收益可能落后于 FLOPs 降低
  • 学习式方案需要训练且绑定特定主干
Analyze（问题分析）
论文指出 VLA 与单图 VLM、固定帧序列视频 VLM 不同：视觉 token 是序列决策过程的组成部分，其重要性随任务与动作变化；并对比三类压缩路线（剪枝、合并、复用/缓存），说明现有方法在免训练、任务条件化、自适应压缩率三方面的不足，据此提出两阶段框架。
Method（方法）
  • 第一阶段：用任务到视觉的注意力给每个视觉 token 打重要性分数（task-conditioned attention signal）
  • 第二阶段（核心贡献）：由重要性分布的集中程度决定每步保留多少 token，用 inverse-Simpson 均匀度指标度量
  • 用在线滑动窗口校准自适应压缩率，在决策需要处多花 token、不需要处更激进剪枝
  • 整体为免训练、每步独立剪枝、不使用缓存的 plug-and-play 框架
  • 在 VLA 模型的 LLM 主干前减少视觉 token 序列长度以降低计算与延迟
Experiments（实验）
  • 在 OpenVLA、OpenVLA-OFT（LIBERO）与 CogACT-base（SIMPLER）上评测，并在实体 Franka Research 3 机器人上验证
  • 仿真中 LLM 主干 FLOPs 降低 35-59%，动作延迟降低 9-32%（1.09×-1.46× 加速），同时保持任务成功
  • 与现有 plug-and-play token 压缩/剪枝/复用基线相比取得相当或更好的效率-性能折中
  • 真机上端到端延迟降低 20%（1.25× 加速），成功率相当；结论称控制频率最多提升 25%，与未压缩基线差距在 0.6 点以内
  • 多样性指标消融（LIBERO-Goal / LIBERO-10）：inverse-Simpson 在成功率与 token 用量上优于 Shannon 与 Gini
  • 部分对比方法（标 * 者）无法复现，引用原论文结果仅作参考；全部实验在单张 NVIDIA RTX 4090 上进行
Limitations（局限）
  • 作者提出将机器人特有结构（如 3D 几何或本体感知）纳入重要性估计是未来方向，暗示当前重要性估计未利用这些信息
  • 作者提出将自适应剪枝与复用或 early-exit 策略结合是未来方向，暗示当前方法未结合这些手段
  • 标 * 的对比方法未能在作者环境中复现，其结果仅引自原论文

VLA 闭环部署受推理效率限制，视觉 token 主导计算与延迟：closed-loop deployment is often limited by inference efficiency: at each timestep, high-resolution, often multi-view images are encoded into hundreds of visual tokens that dominate transformer computation and latency
决策关键 token 由任务决定且各步 token 预算变化大：decision-critical tokens are determined by the task, not generic visual saliency, and (2) the token budget varies substantially across steps
