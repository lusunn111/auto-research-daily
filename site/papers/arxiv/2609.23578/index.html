AR-WAM：面向机器人操作的一种视觉条件化、智能体就绪的世界动作模型

AR-WAM: A Visual-Conditioned Agent-Ready World Action Model for Robotic Manipulation

Yicheng Jiang · Zesen Gan · Xiaobo Wang · Tianlun He · Chenxu Zhao · Minghui Wu · Xinyue Wang · Jiaxu Wang · Junhao He · Jianan Wang · Qiming Shao

核心洞察

在智能体时代，策略真正需要的条件信号是空间可操作、可监督、可由外部智能体控制的视觉条件，而不是自然语言；语言理解、任务分解、记忆和错误恢复应交给智能体，策略只需负责精确动作生成。

为什么值得看：它提供了一种用空间视觉条件替代语言条件的智能体就绪接口，将记忆与错误恢复委托给智能体，同时以 0.5B 紧凑模型实现低延迟和真实机器人迁移，对研究可执行动作生成、长时序预测、推理效率与真实机器人评测的读者具有直接参考价值。

Setting（研究设定）
面向智能体驱动的机器人操作，用视觉定位框和可学习操作 token 替代自然语言指令，模型在紧凑潜在状态中预测场景演化并解码动作，通过检测、执行、查询三个原语与外部智能体交互，并在仿真基准与真实双臂平台上评估。
Motivation（研究动机）
现有视觉语言动作模型和世界动作模型仍依赖自然语言指令指定操作任务，这种接口在智能体驱动控制中不适用：指代模糊、空间不精确、与智能体自身的语言理解冗余，并且将意图与执行纠缠在一起。
Insight（核心洞察）
在智能体时代，策略真正需要的条件信号是空间可操作、可监督、可由外部智能体控制的视觉条件，而不是自然语言；语言理解、任务分解、记忆和错误恢复应交给智能体，策略只需负责精确动作生成。
Challenge（技术挑战）
  • 指代模糊
  • 空间不精确
  • 与智能体固有语言理解冗余
  • 将理解、规划、记忆和动作生成纠缠在一个不可检查的模型中导致故障无法归因
  • 长时序任务与记忆依赖
  • 真实机器人长时序任务与闭环错误恢复
  • 原子技能精度受训练数据限制
Analyze（问题分析）
作者通过分析智能体驱动控制中文本条件接口的四类问题（指代模糊、冗余、不精确、黑盒纠缠），提出将语言条件替换为视觉定位提示和可学习操作 token；并通过 RoboTwin 2.0、RMBench 与真实 Astribot S1 平台上的实验，围绕视觉定位能否替代文本指令、模型无关兼容层能否让不同 VLM/LLM 智能体驱动同一策略、以及条件与调制选择如何影响操作效率与性能三个问题进行分析。
Method（方法）
  • 用视觉定位提示（目标边界框）指代交互对象和位置，用可学习操作 token 指定要执行的原子技能，替代自然语言指令
  • 构建 0.5B 参数紧凑模型，使用冻结的预训练视觉编码器，不设置语言编码器
  • 在紧凑潜在状态中预测场景演化，同时解码动作，并通过显式、可监督的推理信号暴露策略意图
  • 提供模型无关兼容层，包含 detect、execute、query 三个原语，使本地 VLM 或在线智能体 API 可直接驱动策略
  • 将长时序记忆与闭环错误恢复委托给智能体侧，策略保持马尔可夫性，不引入循环状态
  • 通过失败检测与重试循环处理抓取失败或物体掉落，由智能体重新调用 detect 和 execute
Experiments（实验）
  • 在 RoboTwin 2.0 十个双臂长时序任务上，AR-WAM 在随机设置下取得最佳平均成功率 84.2%，在干净设置下为 87.2%，与最强基线 87.8% 相差 0.6% 以内
  • 在标准操作任务上取得 87.2% 平均成功率，与最强基线相当；在依赖记忆的任务和真实机器人长时序任务上分别提升 5.9% 和 36.7% 成功率，并保持最低推理延迟 14.1 ms
  • 消融实验比较文本条件与视觉提示条件、推理与预见组件、预见目标，以及调制机制，结果表明视觉提示条件在相同训练下优于语言条件
  • 在 RMBench 和真实 Astribot S1 双臂平台上验证了紧凑策略仅需少量演示即可迁移到真实硬件
Limitations（局限）
  • 原子技能的精度目前受限于有限的训练数据；作者提出通过智能体在环的真实机器人强化学习进行持续学习是有前景的方向
  • 传统规划仅处理辅助运动，在复杂接触或可变形物体下可能失效
与你的研究关系

现有视觉语言动作模型和世界动作模型仍依赖自然语言指令指定操作任务，不适合智能体驱动控制。：However, prevailing vision-language-action (VLA) models and world action models (WAMs) still rely on natural-language instructions to specify manipulation tasks, an ill-suited interface for agent-driven control: referentially ambiguous, spatially imprecise, redundant with the agent's inherent language understanding, and entangling intent with execution.
AR-WAM 用视觉定位提示和可学习操作 token 两个条件替代语言。：We present AR-WAM, a visual-conditioned, agent-ready world action model that replaces language with two complementary conditions: a visual grounding prompt (a bounding box of the target) denoting the interaction object and location, and a learnable operation token dictating the atomic skill to execute.
模型为 0.5B 参数，使用冻结视觉编码器且无语言编码器，预测场景演化并解码动作。：Our compact 0.5B-parameter model, with a frozen pretrained visual encoder and no language encoder, predicts scene evolution within compact latent states while decoding actions, exposing the policy's intent through explicit, supervisable reasoning signals.
兼容层提供 detect、execute、query 三个原语，将长时序记忆与闭环错误恢复委托给智能体。：A model-agnostic compatibility layer provides three primitives (detect, execute, and query) so that local VLMs or online agent APIs can drive the policy directly, with long-horizon memory and closed-loop error recovery delegated to the agent side.
在 RoboTwin 2.0、RMBench 和真实 Astribot S1 平台上，标准操作平均成功率 87.2%，记忆依赖和真实机器人长时序任务分别提升 5.9% 和 36.7%，推理延迟 14.1 ms。：On RoboTwin 2.0, RMBench, and a real Astribot S1 dual-arm platform, AR-WAM matches the strongest baselines on standard manipulation (87.2% average success) and outperforms them on memory-dependent and real-robot long-horizon tasks, improving success rates by 5.9% and 36.7%, respectively, while maintaining the lowest inference latency (14.1 ms).
