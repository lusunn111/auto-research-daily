Setting（研究设定）
面向接触丰富的单臂与双臂操作任务，在冻结的教师 VLA 策略（具有力条件模式与学习到的无力条件模式）之上，训练一个轻量级学生策略，用最近力历史与机器人状态对参考动作进行修正，而不重新生成完整动作块。
Motivation（研究动机）
力感知 VLA 策略能改善接触丰富操作，但通常把任务级运动与依赖接触的调整混在单一动作预测中；演示数据没有显式标签来把该预测分解为可复用的参考动作与修正量，因此难以获得可复用的修正信号并实现高效执行。
Insight（核心洞察）
可以通过冻结教师策略的力条件模式与学习到的无力条件模式之间的成对预测差，构造显式的力修正目标；并用单独的延迟修正目标补偿参考动作不匹配与参考状态变化，从而把修正学习从完整动作生成中解耦出来。
Challenge（技术挑战）
  • 演示数据缺乏将动作预测分解为参考动作与修正的显式标签
  • 参考动作不匹配与参考状态变化带来的延迟修正问题
  • 在执行期间需要缓存任务上下文以支持异步调度回放
  • 需在两次参考动作更新之间对接触变化做出响应而不重新生成完整动作块
Analyze（问题分析）
作者通过冻结教师策略的两种模式（力条件与学习到的无力条件）之间的成对预测来构造显式的力修正监督信号，并额外构造延迟修正目标来补偿参考动作不匹配和参考状态变化；摘要未进一步说明分析细节。
Method（方法）
  • 使用冻结教师的力条件模式与学习到的无力条件模式的成对预测构造显式力修正目标
  • 构造单独的延迟修正目标以处理参考动作不匹配和参考状态变化
  • 采用异步调度回放进行训练，并缓存在执行期间可用的任务上下文
  • 训练得到轻量级策略，用最近力历史与机器人状态调整参考动作
  • 在两次参考动作更新之间响应接触变化，而不重新生成完整动作块
Experiments（实验）
  • 在九个单臂与双臂接触丰富任务上评估，ForceDelta-VLA 达到 82.2% 平均成功率
  • 原始 ForceVLA 基线为 54.4% 平均成功率
  • 直接执行 Stage-1 Temporal Teacher 达到 70.6%
  • 相对于 ForceVLA，完整系统在两个平台上成功试验的平均峰值接触力降低约 26%
Limitations（局限）

与你的研究关系
该工作直接面向具身智能中的 VLA 策略，关注接触丰富操作下的可执行动作生成、力条件修正、轻量级策略的推理效率与实时响应（在参考动作更新之间调整而不重新生成完整动作块），并在单臂与双臂真实接触任务上评测，与世界动作模型和系统优化中的动作修正、效率与真实机器人评测主题高度相关。

轻量级策略用最近力历史与机器人状态调整参考动作，并在参考动作更新之间响应接触变化而不重新生成完整动作块：The resulting lightweight policy adjusts the reference actions using recent force history and robot state, responding to contact changes between reference-action updates without regenerating complete action chunks.
