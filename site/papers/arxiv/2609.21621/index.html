In contrast to category-level object manipulation, FO manipulation requires identifying and focusing on an object with specified attributes, category, brand, and model. Setting（研究设定）
真实机器人细粒度物体操作任务：机器人需从视觉相似物体和场景干扰物中区分并操作指定细粒度物体，涉及同类别内相似物体区分与新物体泛化。
Motivation（研究动机）
场景级视觉条件缺乏显式物体选择，而类别级引导无法可靠区分同一类别内的细粒度物体，导致机器人在相似物体和干扰物场景下难以可靠执行动作。
Insight（核心洞察）
通过冻结 SAM3 并学习可复用的细粒度物体记忆 token，结合 in-FO 局部外观特征与显式边界框坐标来条件化动作策略，可以在不微调 SAM3 的情况下实现持久的物体定位与相似物拒绝。
Challenge（技术挑战）
  • 场景级视觉条件缺乏显式物体选择
  • 类别级引导无法可靠区分同类别细粒度物体
  • 在有限多视角配准图像下学习可复用物体记忆
  • 在场景干扰物下保持操作鲁棒性
Analyze（问题分析）
材料未说明作者如何具体分析问题；摘要仅陈述问题设定与提出的方法，未提供误差来源或失败模式的形式化分析。
Method（方法）
  • 提出 FO Memory-driven SAM3（FOM-SAM3）：从有限多视角配准图像中学习可复用的细粒度物体记忆 token，同时保持 SAM3 完全冻结。
  • 采用 one-vs-rest 学习，使记忆 token 编码持久记忆，用于定位目标细粒度物体并拒绝相似替代物，记忆可存入记忆库。
  • 提出 Focused Spatial-Appearance Encoding（FSAE）：将 in-FO 局部外观特征与显式边界框坐标结合，用于条件化动作策略。
  • 将 FSAE 条件化应用于 Diffusion Policy（DP）和 Action Chunking with Transformers（ACT）等动作策略。
Experiments（实验）
  • 在 FO-30 数据集上验证 FOM-SAM3 的有效性，该数据集包含四个粗类别下的 30 个物理物体。
  • 在三个真实机器人细粒度物体操作任务中，FOM-SAM3 引导的策略表现出对干扰物的鲁棒性、对相似细粒度物体的区分能力，以及向新细粒度物体的可扩展性。

细粒度物体操作需要机器人区分指定物体与视觉相似物体，并在场景干扰物下可靠执行动作。：Fine-grained object (FO) manipulation requires robots to distinguish a specified FO from visually similar objects and execute actions reliably despite scene distractors.
场景级视觉条件缺乏显式物体选择，类别级引导无法可靠区分同类别细粒度物体。：However, scene-level visual conditioning lacks explicit object selection, while category-level guidance cannot reliably distinguish FOs within the same category.
FOM-SAM3 从有限多视角配准图像中学习可复用细粒度物体记忆 token，并保持 SAM3 完全冻结。：First, we introduce FO Memory-driven SAM3 (FOM-SAM3), which learns reusable FO memory tokens from limited multi-view registration images while keeping SAM3 fully frozen.
通过 one-vs-rest 学习，记忆 token 编码持久记忆以定位目标并拒绝相似替代物，且可存入记忆库。：Through one-vs-rest learning, these tokens encode persistent memories for localizing target FOs and rejecting similar alternatives, which can be stored in a memory bank.
FSAE 结合 in-FO 局部外观特征与显式边界框坐标来条件化 DP 和 ACT 等动作策略。：Second, we propose Focused Spatial-Appearance Encoding (FSAE), which combines in-FO local appearance features with explicit bounding-box coordinates to condition action policies including Diffusion Policy (DP) and Action Chunking with Transformers (ACT).
FOM-SAM3 在 FO-30 数据集上得到验证，该数据集包含四个粗类别下的 30 个物理物体。：The effectiveness of the proposed FOM-SAM3 was validated on the FO-30 dataset comprising 30 physical objects across four coarse categories.
在三个真实机器人细粒度物体操作任务中，FOM-SAM3 引导的策略表现出抗干扰、相似细粒度物体区分与新细粒度物体可扩展性。：Across three real-robot FO manipulation tasks, our FOM-SAM3-guided policies demonstrated robustness against distractors, discrimination ability among similar FOs, and extendibility to new FOs.
