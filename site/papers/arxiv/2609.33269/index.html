Q-WAM：面向世界动作模型的动作子空间保护 4 比特量化

Q-WAM: 4-Bit Quantization of World Action Models with Action-Subspace Protection

Arash Akbari · Arman Akbari · Jingwu Luo · Yuhao Lei · Yi Gao · Weiwei Chen · Xuan Zhang · Zhenman Fang · Geng Yuan · Yanzhi Wang

核心洞察

量化误差对最终动作的影响可以通过「层输入通道加权组合的舍入误差经全部去噪步骤传播后对最终动作的改变程度」来度量，即动作可观测性格拉姆矩阵（AOG）；因此只需保护少数对动作最敏感的通道组合，其余权重与激活可激进量化到 4 比特。

为什么值得看：它提出以动作敏感子空间为核心的量化保护机制，在保持动作生成精度的同时显著降低内存，并在仿真基准和真实人形/双臂机器人上验证，可为具身智能中世界动作模型的实时部署与模型压缩提供可直接借鉴的思路与评测范式。

Setting（研究设定）
针对联合生成视频与机器人动作、通过迭代扩散过程进行去噪的世界动作模型（WAM），在训练后量化（PTQ）场景下进行 4 比特权重-激活量化，并在仿真基准与真实机器人平台上评估。
Motivation（研究动机）
WAM 通过迭代扩散联合生成视频与机器人动作，在机器人操作中表现强，但其计算与内存开销极高，带来显著部署挑战；现有 PTQ 方法（如平滑与旋转）不足以保持动作生成的精度。
Insight（核心洞察）
量化误差对最终动作的影响可以通过「层输入通道加权组合的舍入误差经全部去噪步骤传播后对最终动作的改变程度」来度量，即动作可观测性格拉姆矩阵（AOG）；因此只需保护少数对动作最敏感的通道组合，其余权重与激活可激进量化到 4 比特。
Challenge（技术挑战）
  • WAM 计算与内存开销过大，难以部署
  • 现有 PTQ 的平滑与旋转方法无法保持动作生成精度
  • 需要在极低比特下同时保护动作质量并把额外开销控制在很小范围
  • 需要定位对生成动作最关键的专家（expert）以减少 ASP 的施加范围
Analyze（问题分析）
作者提出 Action Observability Gramian（AOG）来度量每层输入通道加权组合的舍入误差经由全部去噪步骤对最终动作的影响，据此识别动作敏感通道组合；并通过在各专家（expert）的各层上聚合 AOG 导出的「动作质量」来找出对生成动作最重要的专家。
Method（方法）
  • 提出 Action Observability Gramian（AOG），度量层输入通道加权组合的舍入误差经全部去噪步骤对最终动作的影响
  • 提出 Action-Subspace Protection（ASP），将少数最动作敏感的通道组合放入一个极小的 16 比特低秩分支
  • 将互补的权重与激活量化到 4 比特，两部分均实现为可在 GPU 上高效运行的稠密矩阵乘法
  • 通过聚合每个专家各层的 AOG 导出动作质量，识别对生成动作最重要的专家，仅对这些专家施加 ASP 以最小化额外开销
Experiments（实验）
  • 在三个 WAM 上评估 Q-WAM，涵盖仿真与真实世界部署
  • 在 RoboTwin 2.0 基准上达到 89.6--93.0% 平均成功率，与 16 比特模型相差 1.1 个百分点以内
  • 将量化块的内存减少 3.1--3.4 倍
  • 相比最强基线 SVDQuant 高出 2.5--8.7 个百分点
  • 在 Unitree G1 人形机器人与双臂 UR3 机器人上，成功率相比 SVDQuant 提升 12.8--17.6 个百分点

Q-WAM 是一种针对世界动作模型的 4 比特权重-激活训练后量化方法，旨在保持模型生成的动作精度。：we propose Q-WAM, a new 4-bit weight-activation quantization for WAMs that preserves the actions the model generates
AOG 度量每层输入通道加权组合的舍入误差经全部去噪步骤对最终动作的影响。：we introduce the \textit{Action Observability Gramian (AOG)}, which measures how much rounding errors in each weighted combination of a layer's input channels change the final action through all denoising steps
ASP 将少数最动作敏感的通道组合保留在 16 比特低秩分支中，其余权重与激活量化为 4 比特，并均以稠密矩阵乘法在 GPU 上高效运行。：Action-Subspace Protection (ASP), which keeps the few most action-sensitive channel combinations in a tiny 16-bit low-rank branch and quantizes the complementary weights and activations to 4 bits, both as dense matrix multiplications that run efficiently on GPUs
该方法仅对通过聚合 AOG 动作质量识别出的最重要专家施加 ASP。：we identify the experts that matter most for the generated action by aggregating the AOG-derived action mass across the layers of each expert and apply ASP only to those experts
在 RoboTwin 2.0 基准上达到 89.6--93.0% 平均成功率，与 16 比特模型相差 1.1 个百分点以内，量化块内存减少 3.1--3.4 倍。：On the RoboTwin 2.0 benchmark, it reaches 89.6--93.0\% average success rate, within 1.1 percentage points of the 16-bit models, while reducing the memory of the quantized blocks by 3.1--3.4$\times$
该方法比最强基线 SVDQuant 高 2.5--8.7 个百分点，并在 Unitree G1 与双臂 UR3 机器人上相比 SVDQuant 提升 12.8--17.6 个百分点。：Our method outperforms the strongest baseline, SVDQuant, by 2.5--8.7 percentage points. On a Unitree G1 humanoid and a bimanual UR3 robot, it improves success over SVDQuant by 12.8-17.6 percentage points.
