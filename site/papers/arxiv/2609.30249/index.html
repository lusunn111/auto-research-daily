Yuyao Liu · Jiayuan Mao · David Hsu · Leslie Pack Kaelbling · Tom\'as Lozano-P\'erez

核心洞察

迭代式智能体代码精炼需要三个关键要素：可测试的任务规范、机器人执行的动作原语、以及用于程序执行与验证的交互环境；RAPID 从单次演示中自动推断这三者。为使程序可复用，RAPID 采用以对象为中心的关系式程序表示，关注演示策略的底层结构而非具体运动，将动作原语表达为轨迹优化程序以实现对象级运动效果，并在运行时通过关系约束组合这些原语以捕捉场景特定几何

为什么值得看：论文提出了一条将编码智能体能力迁移到机器人系统的路线：从单次视觉人类演示自动获得任务规范、动作原语与验证环境，并用轨迹优化程序与关系约束构建可复用、可泛化的机器人程序。对关注可执行动作生成、长时序任务程序化表示、真实机器人评测以及智能体式闭环优化的研究者具有较高参考价值。

RAPID 从单次视觉人类演示自动生成、验证并精炼机器人程序：this work introduces Robot Agentic Programming from Demonstrations (RAPID), which automatically generates, verifies, and refines robot programs, given a single visual human demonstration.
迭代式智能体代码精炼需要三个关键要素：可测试任务规范、动作原语、交互验证环境：The iterative agentic loop of code refinement requires several key ingredients: (i) a testable task specification, (ii) action primitives for robot execution, and (iii) an interactive environment for program execution and verification.
RAPID 从演示中自动推断任务规范、动作原语和交互环境：RAPID infers all three from the demonstration automatically.
RAPID 使用以对象为中心的关系式程序表示，关注策略结构而非具体运动：RAPID uses an object-centric relational program representation that focuses on the underlying structure of the demonstrated strategy rather than the specific motion per se
动作原语被表达为轨迹优化程序，并通过运行时关系约束组合：it expresses the action primitives as trajectory-optimization programs that realize object-level motion effects, while composing them through relational constraints that capture scene-specific geometry at run time.
实验覆盖仿真中的八个接触丰富非抓取任务、LIBERO-Pro 抓取任务以及真实 Franka 机械臂上的八个非抓取任务：We evaluated RAPID in simulation on eight challenging contact-rich nonprehensile manipulation tasks as well as general prehensile manipulation tasks in the LIBERO-Pro benchmark. We also successfully deployed it on a real Franka arm and evaluated on all eight nonprehensile tasks.
作者称 RAPID 在所有实验中表现强劲，并泛化到物体位姿、形状、材质与环境变化：In all experiments, RAPID demonstrated strong performance, with generalization over object pose, shape, material, and environment.
