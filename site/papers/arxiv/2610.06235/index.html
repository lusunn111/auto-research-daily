被编码却不受控：揭示视觉-语言机器人策略中的接地鸿沟

Encoded but Not in Control: Revealing the Grounding Gap in Vision-Language Robot Policies

Shaohan Jiang · Jiahang Cao · Qiduo He · Fengting Deng · Kun Wu · Jingkai Sun · Jiaxu Wang · Qiang Zhang · Qihao Zheng · Chunfeng Song · Ping Luo · Andrew F. Luo

核心洞察

任务成功并不等同于指令跟随；被修改的指令确实被编码在表征中，却很少决定目标选择，存在从语言编码到视觉接地与动作控制之间的“接地鸿沟”。

为什么值得看：它提供了一个诊断框架和明确判据：策略应在用户意图发生有效变化时可靠跟随，即使该意图与场景偏好的行为冲突。对于关注 VLA/WAM 动作生成、语言接地、真实机器人评测和世界模型行为可控性的研究者，该工作揭示了名义成功率可能掩盖的系统性失效。

Setting（研究设定）
在仿真与真实世界实验中，对视觉-语言-动作（VLA）策略和世界动作模型（WAM）进行场景保持的指令干预：保持场景不变，替换为有效目标替换词、任意名词以及无关句子，以检验语言是否真正决定动作选择。
Motivation（研究动机）
指令跟随是语言条件机器人策略的核心：当同一场景允许多种有效动作时，语言应决定做什么。然而仅凭成功执行无法判断策略是在遵循指令，还是从场景中推断任务。作者希望揭示这种被名义成功率掩盖的模糊性。
Insight（核心洞察）
任务成功并不等同于指令跟随；被修改的指令确实被编码在表征中，却很少决定目标选择，存在从语言编码到视觉接地与动作控制之间的“接地鸿沟”。
Challenge（技术挑战）
  • 任务成功无法区分指令跟随与场景推断
  • 语言编码存在但不控制动作生成
  • 目标编码与视觉接地之间存在错配
  • 表征逐渐按场景身份组织，削弱了指令的作用
Analyze（问题分析）
作者通过场景保持的指令干预（有效目标替换、任意名词、无关句子）在仿真与真实实验中评估 VLA 策略与 WAM。分析围绕三个问题展开：(a) 任务成功是否意味着指令跟随；(b) 失败是否源于语言不敏感；(c) 为何被编码的语言无法控制动作。使用的分析工具包括逐层动作透镜、线性探针、注意力分析、UMAP 以及共享非负矩阵分解。
Method（方法）
  • 采用场景保持的指令干预：在固定场景下使用有效目标替换词、任意名词和无关句子
  • 在仿真与真实世界实验中评估 VLA 策略和 WAM
  • 使用逐层动作透镜观察中间动作预测对指令扰动的响应
  • 使用线性探针从表征中恢复被指令的目标
  • 通过注意力分析考察指令 token 对动作生成的贡献及目标 token 注意力的焦点
  • 使用 UMAP 与共享非负矩阵分解分析表征组织方式
Experiments（实验）
  • 当指令要求不同的可见物体时，所有被评估的策略主要接近并拾取与场景相关联的错误的原始目标
  • 指令扰动会影响任务表现
  • 逐层动作透镜显示中间动作预测会响应这些扰动
  • 线性探针能准确恢复被指令的目标，表明被修改的指令尽管很少决定目标选择，但仍被编码
  • 注意力分析表明指令 token 对动作生成的贡献较弱
  • 目标 token 注意力可能仍聚焦于原始物体，揭示目标编码与视觉接地之间的错配
  • UMAP 与共享非负矩阵分解显示目标信息在表征中仍可获取，而表征日益按场景身份组织
Limitations（局限）

与你的研究关系
该论文直接研究 VLA 与 WAM 中的可执行动作生成与语言接地问题，指出策略可能在编码指令的同时不依据指令选择动作，这对具身智能中真实机器人评测、世界动作模型的动作生成可靠性以及指令跟随评测标准具有核心意义。

任务成功并不必然意味着策略遵循了指令，可能存在从场景推断任务的情况：Instruction following is central to language-conditioned robot policies: language should determine what to do when the same scene permits multiple valid actions. Yet successful execution alone cannot establish whether a policy follows the instruction or infers the task from the scene.
当指令要求不同可见物体时，被评估策略主要拾取与场景相关的错误的原始目标：When instructions request a different visible object, all evaluated policies predominantly approach and pick up the incorrect original target associated with the scene.
被修改的指令确实被编码在表征中，但很少决定目标选择：Linear probes accurately recover instructed targets, indicating modified instructions are encoded despite rarely determining target selection.
