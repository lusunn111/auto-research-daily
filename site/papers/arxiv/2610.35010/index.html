JevVLA: Jev-Inspired Energy-Based Adaptation for Vision-Language-Action Policies

Wei Wang · Wenqiao Zhang · Zheqi Lv · Zheng Dong · Yingjie Niu · Jiaqi Zhu · Jun Xiao · Chao Li · Yueting Zhuang

核心洞察

动作的“提议”与“评估”可以分离：基础策略负责提议动作，轻量适配器只学习对动作相对质量的偏好。同一个标量能量函数既可作为离散候选的排序分数，也可对其求梯度得到连续动作空间中的局部修正方向，从而以单一可训练决策核心服务两类接口。

为什么值得看：提供了一种极小参数（约8万）即插即用的VLA适配范式，并用同一能量核心统一离散选择与连续引导，在五个主流操作基准上给出一致的成功率增益；其消融与对比设置对研究参数高效适配、动作评估器设计与真实部署前的轻量后处理具有直接参考价值。

Setting（研究设定）
在基础VLA策略完全冻结的前提下，为不同机器人操作基准学习一个约8万参数的可微标量能量函数；该函数以观测、任务上下文和动作为条件，其数值用于离散候选比较，其动作梯度用于连续动作的有界修正或生成引导。
Motivation（研究动机）
VLA策略虽能生成语义合理的动作，但细微几何误差即可导致执行失败；进一步的微调或全参数更新需要高昂计算成本与额外任务数据。由此作者提出：如何在保留基础策略动作生成能力的同时，以轻量方式提升动作决策质量，并统一支持离散候选选择与连续动作控制这两类不同动作接口。
Insight（核心洞察）
动作的“提议”与“评估”可以分离：基础策略负责提议动作，轻量适配器只学习对动作相对质量的偏好。同一个标量能量函数既可作为离散候选的排序分数，也可对其求梯度得到连续动作空间中的局部修正方向，从而以单一可训练决策核心服务两类接口。
Challenge（技术挑战）
  • 候选选择需要跨动作可比较的分数，而连续引导需要动作空间中有用的局部修正方向，对评估器的要求不同
  • 不同基础策略的原生动作表示与生成过程各异，需确定梯度插入位置与缩放方式
  • 在不更新基础策略的前提下同时提升两类决策，且不能破坏其原有生成能力
  • 执行反馈、专家纠正、示教偏好等监督信号形式不一，需统一为偏好学习目标
Analyze（问题分析）
作者将问题拆为动作提议与动作评估两部分，指出两类动作接口都对“相对动作质量评估”有需求，但分别侧重可比分数与局部梯度；并以Jev公开决策接口中的结构化概率选择/打分概念作为设计灵感，说明其机器人动作能量、训练目标与梯度引导机制均为独立开发。材料未给出更细的理论分析。
Method（方法）
  • 冻结基础VLA策略，仅训练一个轻量可微标量能量网络，输入为观测、任务上下文与动作，输出标量能量
  • 用执行反馈、专家纠正或示教派生偏好构造训练信号，学习动作相对质量的偏好
  • 离散接口：用能量值对有限动作候选进行比较与选择
  • 连续接口：用能量的动作梯度对连续动作做有界修正，或引导其生成
  • 各基准独立训练能量权重并使用固定输入输出编码，但共享同一核心网络结构（约8万可训练参数）
  • 依据基础策略接口决定梯度插入位置与缩放，并采用全局增益与间隔参数
Experiments（实验）
  • 在五个基准的留出测试集上，相对各自匹配的冻结基础策略控制（Direct），任务成功率分别提升：MetaWorld MT50 1.28、VIMA 2.31、LanguageTable 1.60、LIBERO Plus 1.52、CLIPort 1.28 个百分点
  • 核心网络可训练参数为79,817
  • 评测规模：MT50 50个任务各50例；VIMA 13个任务族各100例；LanguageTable 5个族各50例；CLIPort 18个变体各100例；LIBERO Plus 10,030个变体
  • CLIPort消融显示能量结构、偏好监督与打分输入的贡献；对比中Logistic回归与FT-Transformer分别获得623与624次成功，共享MLP与TabNet为617与614次；在线UA-CLIPort规则在同一任务组合上为607次成功，但因无匹配的在线Direct运行，未将其差值解释为成对效应
  • 执行示例展示了小幅修正如何改变一次rollout，以及候选排序如何改变最终结果
Limitations（局限）

JevVLA是面向VLA策略的轻量级能量适配框架，基础策略保持冻结：we propose JevVLA, a lightweight energy-based adaptation framework for VLA policies
同一能量函数同时用于离散候选比较与连续动作梯度修正：its values compare discrete candidates, while its action gradients correct continuous actions or guide their generation
核心网络约8万可训练参数，各基准独立训练权重：Each benchmark uses independently trained weights and fixed input/output encodings, while retaining the same core network with approximately 80,000 trainable parameters
五个基准上成功率相对冻结基线分别提升1.28、2.31、1.60、1.52、1.28个百分点：JevVLA improves task success over the respective matched base-policy controls by 1.28, 2.31, 1.60, 1.52, and 1.28 percentage points on MetaWorld MT50, VIMA, LanguageTable, LIBERO Plus, and CLIPort, respectively
核心网络可训练参数为79,817：The core has 79,817 trainable parameters, with weights learned separately for each benchmark
