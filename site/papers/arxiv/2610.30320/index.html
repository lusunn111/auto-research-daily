Setting（研究设定）
研究基于预训练视频扩散模型先验的通用机器人策略（世界动作模型）：冻结或复用视频模型，在单步去噪得到的中间未来视频表征上条件化一个独立动作解码器，从而避免迭代去噪，以实现高效推理；目标是提升该单步未来表征的质量。
Motivation（研究动机）
现有 WAM 通过单步去噪提取中间未来视频表征并驱动动作解码器以提升推理效率，但这使动作预测直接依赖这些未来表征的质量；单步从噪声预测的未来表征质量不足，制约了下游动作预测性能。
Insight（核心洞察）
可以用自蒸馏方式训练 WAM 直接从噪声在单步内预测高质量未来表征，并以真实未来观测提取的表征作为目标；同时把历史观测作为条件注入视频模型，为未来表征预测提供时序上下文。
Challenge（技术挑战）
  • 单步去噪难以从纯噪声得到高质量未来视频表征
  • 动作预测质量直接受未来表征质量制约，误差会传导到策略
  • 长时序任务与分布外环境下的零样本泛化困难
  • 人类视频到机器人技能的跨具身迁移困难
  • 在保持推理效率（避免迭代去噪）的同时提升表征质量
Analyze（问题分析）
材料未说明；摘要仅指出单步去噪设计使动作预测直接依赖未来表征质量，并据此提出改进未来表征质量的研究思路，未给出具体的问题分析过程。
Method（方法）
  • 提出 FRED 框架（Future REpresentation learning via self-Distillation with temporal context）
  • 用自蒸馏训练 WAM 从噪声在单步去噪中预测未来视频表征
  • 以真实未来观测提取的表征作为蒸馏目标
  • 将视频模型条件化于历史观测，为未来表征预测提供时序上下文
  • 保持单步表征+独立动作解码器的高效推理路线，避免视频生成的迭代去噪
Experiments（实验）
  • 在多种真实世界操作场景中，FRED 一致优于对比的 WAM
  • 在零样本环境泛化下的长时序与分布外任务上取得尤其大的提升
  • 显著改善人到机器人技能迁移：在机器人训练数据中不存在、仅在人类视频中演示的任务上达到 50.0% 任务成功率，最佳对比 WAM 为 19.4%
