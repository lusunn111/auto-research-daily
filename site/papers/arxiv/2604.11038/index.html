Figure 1 We present EgoFun3D : a coordinated task, dataset and benchmark for modeling interactive 3D objects from egocentric videos. Given an egocentric video as an input, the output is a simulation-ready interactive object (e.g., faucet handle starts water flow from faucet spout). We break down the task into 4 steps to propose a baseline approach using off-the-shelf components. Our function template representation, produced by the proposed system, can be compiled into executable code for a simulator of choice.

核心洞察

用「功能模板」（结构化计算表示）刻画跨部件的功能映射（例如旋转灶台旋钮控制灶台温度），从而支持精确评估，并可直接编译为跨仿真平台的可执行代码。

为什么值得看：该工作提供可仿真、可执行的交互物体表示与配套数据集/基准，对构建具身智能仿真环境、动作效果建模与真实世界视频到可执行资产的转换具有明确参考价值；其功能模板形式化方式可能启发世界模型中的因果/功能映射表示。

Setting（研究设定）
输入为真实世界第一人称（egocentric）视频，输出为仿真就绪（simulation-ready）的可交互3D物体；任务同时包含协调的任务定义、数据集与基准。
Motivation（研究动机）
交互物体对具身AI高度重要但数据稀缺，因此从易于获取的真实世界视频中建模交互物体具有价值；且已有工作多聚焦铰接（articulation），缺乏对一般跨部件功能映射的刻画。
Insight（核心洞察）
用「功能模板」（结构化计算表示）刻画跨部件的功能映射（例如旋转灶台旋钮控制灶台温度），从而支持精确评估，并可直接编译为跨仿真平台的可执行代码。
Challenge（技术挑战）
  • 从第一人称视频获取仿真就绪的交互3D物体本身困难
  • 需要超越单纯铰接，建模一般性的跨部件功能映射
  • 需要同时处理2D/3D分割、几何重建、铰接估计与功能模板推断的多阶段耦合问题

核心表示是功能模板，用于捕捉一般跨部件功能映射：we capture general cross-part functional mappings (e.g., rotation of stove knob controls stove burner temperature) through function templates, a structured computational representation

数据集包含517段第一人称视频及多类标注：we introduce a dataset of 517 egocentric videos featuring challenging real-world interactions with paired 3D geometry, segmentation over 2D and 3D, articulation and function template annotations
方法为四阶段流水线：we propose a 4-stage pipeline consisting of: 2D part segmentation, reconstruction, articulation estimation, and function template inference
基准显示该任务对现成方法具有挑战性：Comprehensive benchmarking shows that the task is challenging for off-the-shelf methods, highlighting avenues for future work.
