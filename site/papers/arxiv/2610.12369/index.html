具身图灵机：面向机器人递归自我改进的有状态代码

Embodied Turing Machines: Stateful Code for Robot Recursive Self-Improvement

Kairui Hu · Siyuan Hu · Fangzhou Hong · Zhaoxi Chen · Ziwei Liu

核心洞察

把具身世界看作图灵机——纸带是机器人与环境状态，规则是策略；若状态能被准确表示，决策即可完全写成代码，且同一代码跨回合复用、不同任务共享同一代码库。

为什么值得看：它提供了一个与 VLA、Agent Harness、WAM 并列的对照范式与强基线结果（70.24% vs 最强基线 +38.86），并且其“测试时无模型、决策廉价可复现”的结论可直接迁移到对推理效率与实时控制敏感的具身系统研究；此外其失败分类与上限讨论为状态表示精度研究提供了明确的问题清单。

Setting（研究设定）
在仿真基准 RoboDojo 的 42 个双臂操作任务上评测，测试时控制回路中不含 VLM 或 VLA，策略为离线由编码智能体开发的共享代码库。
Motivation（研究动机）
现有机器人策略（VLA、Agent Harness）在控制回路中保留模型：状态隐式编码于权重或存于模型上下文，导致每次调用有随机性、单回合成本高、决策不可复现。作者希望探索一种状态完全显式、决策完全由代码完成的范式。
Insight（核心洞察）
把具身世界看作图灵机——纸带是机器人与环境状态，规则是策略；若状态能被准确表示，决策即可完全写成代码，且同一代码跨回合复用、不同任务共享同一代码库。
Challenge（技术挑战）
  • 状态表示精度不足：仅用 RGB 输入时识别会出错，错误值会进入状态
  • 接触状态（尤其可变形物体）的表示目前较粗糙
  • 代码逻辑本身的鲁棒性有限
  • 需要少量任务特定代码逻辑，泛化能力受限
  • 离线 RSI 循环仍需进一步优化以让编码智能体写出更好的代码
Analyze（问题分析）
作者将现有策略按“状态存放位置”和“如何从状态选动作”分类（VLA 隐式编码于权重，Agent Harness 以文本存于模型上下文），据此论述代码策略在显式状态、执行可控、可扩展三方面的优势；并通过失败回合的最小修复类别统计来定位上限来源（状态测量与代码逻辑）。
Method（方法）
  • 将机器人与环境建模为具身图灵机：纸带为环境状态（物体位姿与空间关系）与机器人状态（关节角、手部位姿、夹爪开度、持物）
  • 提出 Code-Only-as-Policy：代码从相机图像与本体感知测量并跟踪机器人、环境与任务状态，并据此做出全部决策
  • 状态分为机器人状态、环境状态、任务状态，全部以物理单位存储在程序中
  • 同一代码跨回合复用，不同任务共享一个代码库，运行时不调用 VLM 或 VLA
  • 以代码为递归自我改进（RSI）的媒介：编码智能体在闭环内总结、编写、调试代码
  • RSI 规则：固定约束（禁止针对单回合的特化、测试时禁止使用 oracle 状态）、不使用基准测试集、无人在回路
  • 接受准则：兼容性条件保护未被 diff 针对的任务，接受规则确保被针对任务提升，使每一步被接受的改动单调不降、改进可累积
Experiments（实验）
  • 在 RoboDojo 的 42 个双臂任务上，COAP 达到 70.24% 成功率，比最强基线（state-of-the-art）高 38.86 个百分点（原文亦写 38.9%），并在全部五个维度领先
  • 分维度成功率：Memory 89.9、Precision 75.1、Open 64.1、Generalization 65.7、Long-Horizon 56.4；Score 为 75.45
  • 对比方法包括 Agent Harness（PhysicalRSI 37.3、GPT-6 Astra 22.48）、World Action Model 类（Awomo-0.5 29.64 等）与 VLA 类（Simate-beta 27.96、Rex-M1 Preview 27.44 等）
  • 代码库由编码智能体（Opus 5.5 Max）在作者设计的闭环 RSI 流程中开发，开发过程不涉及基准测试集
  • 开发记录显示：尝试两个或更多变体时，五次中有四次找到了被接受的改动
Limitations（局限）
  • 泛化能力较弱，因为它需要少量任务特定代码逻辑
  • 上限受状态表示精度与代码逻辑鲁棒性限制
  • 仅用 RGB 输入导致感知错误可能进入状态，在真实场景中此类错误可能更严重
  • 接触状态（尤其涉及可变形物体时）的表示较粗糙
  • 当前编码能力有局限，离线 RSI 循环仍需进一步优化
与你的研究关系
该工作直接挑战“控制回路中必须保留 VLA/VLA 模型”的假设，提出无模型运行时的代码策略，与具身智能中可执行动作生成、实时控制（决策廉价、可复现）和数据引擎方向相关；文中将 World Action Model（WAM）作为对比类别并给出其基准成绩，但未提出新的世界模型或长时序预测方法。

论文提出把具身世界视为具身图灵机，并据此提出 Code-Only-as-Policy。：We propose a different view: the embodied world is an Embodied Turing Machine, whose tape is the robot and environment state and rules are the policy.
COAP 在 RoboDojo 的 42 个双臂任务上达到 70.24% 成功率，且测试时无模型。：On RoboDojo’s 42 bimanual tasks, the resulting library reaches a success rate of 70.24% without a model at test time.
作者列出 COAP 相对 VLA 与 Agent Harness 的三个优势。：we analyze three advantages of COAP: (i) Explicit State: the state can be stored in code; (ii) Execution: code makes decision making controllable, recovers from failures flexibly, and runs fast and cheaply online; (iii) Extensibility: new tasks reuse, inherit, or extend the shared library, so capabilities can accumulate over tasks.
论文明确指出 COAP 的泛化弱点。：The weakness of COAP mainly lies in its generalization capabilities since it needs a small amount of task-specific code logic.
COAP 的结果比最强方法高 38.9%。：The resulting COAP policy reaches 70.24% success rate, 38.9% above the state-of-the-art method.
失败被归为状态测量与代码逻辑两类。：The failures fall into two groups: limits of state measurement and limits of the code logic.
