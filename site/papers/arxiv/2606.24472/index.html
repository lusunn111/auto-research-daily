Yue Peng · Yongzhe Zhao · Artur Habuda · Khuyen Pham · Yanheng Zhu · Tran Nguyen Le · Fares Abu-Dakka · Li Guo

核心洞察

把已标定的相机几何作为归纳偏置直接注入预训练 VLA 的视觉 token 流，可以在不改变动作空间和动作学习目标的前提下，获得跨视角几何一致的表示，从而提升多视角推理与未见视角鲁棒性。

为什么值得看：若研究者关注 VLA 的视觉表征、多相机多视角融合、相机标定与视角泛化，该工作提供了一个简单通用、可加装于预训练策略且不改变动作学习目标的几何归纳偏置方案，并覆盖 LIBERO、RoboCasa24、RoboTwin2.0 与真实机器人的评测，同时对标定误差的敏感性和监督来源（真值点图 vs. π³X 教师）做了对照分析，具有明确的迁移参考价值。

Setting（研究设定）
在预训练的 VLA 策略（π0、π0.5）上，以无需改动动作空间与原始动作学习目标的方式，将已标定的相机几何注入视觉 token 流；训练使用真值点图或置信度门控的 π³X 教师预测作为几何监督，不需要深度传感器或人工几何标注。
Motivation（研究动机）
现有 VLA 模型的视觉表征通常建立在 2D 图像坐标之上，而非经过标定的相机几何；在多相机系统中，各视角本由已知内参和外参耦合，却被当作独立图像处理，导致几何不一致、多视角推理弱和视角变化下鲁棒性差。
Insight（核心洞察）
把已标定的相机几何作为归纳偏置直接注入预训练 VLA 的视觉 token 流，可以在不改变动作空间和动作学习目标的前提下，获得跨视角几何一致的表示，从而提升多视角推理与未见视角鲁棒性。
Challenge（技术挑战）
  • 预训练 VLA 视觉表征缺乏标定相机几何，多视角被当作独立图像处理
  • 在不改动动作空间与原始动作学习目标的前提下注入几何结构
  • 在无深度传感器、无人工几何标注条件下获得几何监督
  • 几何增益依赖正确的相机标定，同时需对轻微标定扰动保持稳定
Analyze（问题分析）
摘要指出问题根源是视觉表征以 2D 图像坐标而非标定几何为基础，多相机视角虽由已知内参外参耦合却被独立处理；作者通过相机偏移的 LIBERO-Goal、真实机器人实验以及跨 π0 与 π0.5 的受控标定研究，分析增益与相机几何正确性之间的依赖关系。具体分析细节材料未说明。
Method（方法）
  • 提出相机感知几何模块 G$^3$VLA，注入预训练 VLA 的视觉 token 流
  • 不改动动作空间与原始动作学习目标
  • 结合内参条件化射线嵌入（intrinsic-conditioned ray embeddings）
  • 采用投影位置编码 PRoPE（projective positional encoding）
  • 进行双向跨视角融合（bidirectional cross-view fusion），建立跨相机视角的几何一致表示
  • 几何监督来自真值点图或置信度门控的 π³X 教师预测，无需深度传感器或人工几何标注
Experiments（实验）
  • 在 π0 上，G$^3$VLA 在 LIBERO 与 RoboCasa24 上于两种监督方式下均取得一致性能提升
  • 真值监督在带三个相机的五任务 RoboTwin2.0 平均值上有所提升
  • 在相机偏移的 LIBERO-Goal 与真实机器人上的实验显示对未见相机视角的鲁棒性提升
  • 在 π0 与 π0.5 上的受控标定研究表明，增益依赖正确的相机几何，且在轻微标定扰动下保持稳定

与你的研究关系
直接面向具身智能中的 VLA 模型与真实机器人操作评测，关注多相机几何一致性、视角鲁棒性与预训练策略的视觉表征；与视觉语言动作模型、真实机器人控制密切相关。其模块化注入方式不改变动作空间与动作学习目标，属于可迁移到现有 VLA 训练管线的方法，但摘要未涉及世界模型、长时序预测、推理效率、模型压缩或实时控制等方向。
