核心洞察

将异构控制证据转换为相机与时间标记的干净视觉状态，并通过冻结因果视频模型原生的自注意力读取，可在不训练的情况下实现多种控制任务。

Setting（研究设定）
在冻结的因果视频世界模型上，通过推理时接口实现对新视角的灵活控制与探索，无需额外训练或任务专用模块。
Motivation（研究动机）
自回归视频世界模型支持交互式长时序探索，但灵活控制困难：生成结果需与源视频事件同步、将观测内容置于指定视角、合理补全新暴露区域，并在回访时恢复先前生成的外观。现有方法依赖任务专用模块或额外训练。
Insight（核心洞察）
将异构控制证据转换为相机与时间标记的干净视觉状态，并通过冻结因果视频模型原生的自注意力读取，可在不训练的情况下实现多种控制任务。
Challenge（技术挑战）
  • 生成结果与源视频记录事件保持同步
  • 将观测内容置于请求视角
  • 合理补全新暴露区域
  • 回访时恢复先前生成的外观
  • 避免任务专用模块或额外训练
Analyze（问题分析）
材料未说明作者如何具体分析问题，仅从摘要可知其通过异构控制证据、token级支持与可用性调度、对应路由及证据级注意力CFG来应对上述要求。
Method（方法）
  • 训练无关的推理时接口，将异构控制证据转换为相机和时间标记的干净视觉状态
  • 通过冻结因果视频模型的原生自注意力读取这些状态
  • 证据来源包括源视频观测、目标视角场景投影、引导新暴露主体区域补全的几何渲染，以及滚动缓存之外的已生成状态检索
  • 每个证据源携带token级支持及其自身的可用性调度
  • 对应路由器结合持久点身份与几何建立token对应关系，引导有支持的查询指向匹配的源视频token
  • 证据级注意力CFG在同一个去噪前向传播中，利用注意力响应对每个辅助通道的额外贡献进行独立调节
  • 同一共享接口支持相机控制的重新渲染、长时序回访与人体动作迁移，且使用同一冻结主干
Experiments（实验）
  • 在相机控制的视频重新渲染任务上评估World in World，涵盖多样视角变化
  • 评估指标包括感知质量、时间一致性与相机跟随精度

论文提出一种训练无关的推理时接口，将异构控制证据转换为相机与时间标记的干净视觉状态，并通过冻结因果视频模型的原生自注意力读取。：We present World in World, a training-free inference-time interface that converts heterogeneous control evidence into camera- and time-labelled clean visual states, which are read through the native self attention of a frozen causal video model.
控制证据包括源视频观测、目标视角场景投影、几何渲染以及滚动缓存之外的已生成状态检索，每个证据源携带token级支持及其自身的可用性调度。：The evidence comprises source-video observations, target-view scene projections, geometry renderings that guide completion of newly exposed subject regions, and retrieved generated states beyond the rolling cache. Each evidence source carries token-level support and its own availability schedule.
对应路由器结合持久点身份与几何建立token对应关系，引导有支持的查询指向匹配的源视频token；证据级注意力CFG独立调节每个辅助通道的额外贡献。：A correspondence router combines persistent point identities with geometry to establish token correspondences, guiding supported queries towards matching source-video tokens. Evidence-wise attention CFG (EWA) then independently regulates each auxiliary channel's additional contribution using attention responses from the same denoising forward pass.
同一冻结主干与共享接口支持相机控制的重新渲染、长时序回访和人体动作迁移。：The shared interface supports camera-controlled rerendering, long-horizon revisiting, and human-motion transfer with the same frozen backbone.
在相机控制的视频重新渲染任务上评估，关注感知质量、时间一致性和相机跟随精度。：We evaluate World in World on camera-controlled video rerendering under diverse viewpoint changes, assessing perceptual quality, temporal consistency, and camera-following accuracy.
