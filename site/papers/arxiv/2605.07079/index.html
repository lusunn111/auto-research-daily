通过残差潜在动作学习基于视觉特征的世界模型

Learning Visual Feature-Based World Models via Residual Latent Action

Xinyu Zhang · Zhengtong Xu · Yutian Tao · Yeping Wang · Yu She · Abdeslam Boularias

核心洞察

一种新的潜在动作表示——残差潜在动作（RLA）——可以从 DINO 残差中轻松学习得到，并且 RLA 具有可预测性、可泛化性并编码时间进展；基于 RLA 用流匹配进行预测可构建更优的世界模型。

为什么值得看：论文提出基于 DINO 残差的 RLA 表示与流匹配世界模型，在特征空间高效预测未来并支持无动作视频学习与纯世界模型内强化学习，对具身智能、世界模型、VLA 提升和实时效率研究具有直接参考价值。

Setting（研究设定）
从观测和动作预测未来视觉特征（而非原始视频像素），并以此构建可支持策略学习的潜在世界模型；实验覆盖仿真与真实世界数据集以及机器人策略学习任务。
Motivation（研究动机）
现有世界模型多聚焦于图像生成；基于视觉特征的世界模型更高效且更不易产生幻觉，但当前特征方法依赖直接回归，在复杂交互中会导致预测模糊或坍缩，而在高维特征空间中进行生成式建模仍具挑战。
Insight（核心洞察）
一种新的潜在动作表示——残差潜在动作（RLA）——可以从 DINO 残差中轻松学习得到，并且 RLA 具有可预测性、可泛化性并编码时间进展；基于 RLA 用流匹配进行预测可构建更优的世界模型。
Challenge（技术挑战）
  • 直接回归特征在高维复杂交互中导致模糊或坍缩的预测
  • 在高维特征空间中进行生成式建模仍然困难
  • 如何从无动作视频中学习可用于策略提升的世界模型
Analyze（问题分析）
作者发现并验证了 RLA 可从 DINO 残差中学习，且具备可预测性、可泛化性和时间进展编码能力，并据此提出以流匹配预测 RLA 的世界模型 RLA-WM，但材料未说明更具体的理论或实验分析过程。
Method（方法）
  • 从 DINO 残差中学习一种新的潜在动作表示，称为残差潜在动作（RLA）
  • 提出 RLA 世界模型（RLA-WM），通过流匹配预测 RLA 值
  • 开发第一种机器人学习技术：基于 RLA 的极简世界动作模型，可从无动作视频中学习，并提升 LIBERO 和真实机器人上的 VLA
  • 开发第二种机器人学习技术：完全在仅从离线视频学习得到的世界模型内部训练的视觉强化学习框架，使用视频对齐奖励且无在线交互
Experiments（实验）
  • RLA-WM 在仿真和真实世界数据集上优于最先进的基于特征的世界模型和视频扩散世界模型
  • RLA-WM 比视频扩散快数个数量级
  • 第一种技术可提升 LIBERO 和真实机器人上的 VLA
  • 第二种技术是完全在世界模型内训练的视觉强化学习框架，仅使用离线视频、视频对齐奖励且无在线交互

当前基于特征的世界模型依赖直接回归，在复杂交互中会导致模糊或坍缩预测，而高维特征空间生成式建模仍然困难。：However, current feature-based approaches rely on direct regression, which leads to blurry or collapsed predictions in complex interactions, while generative modeling in high-dimensional feature spaces still remains challenging.
作者发现一种称为残差潜在动作（RLA）的新潜在动作表示可以轻松从 DINO 残差中学习得到。：In this work, we discover that a new type of latent action representation, which we refer to as Residual Latent Action (RLA), can be easily learned from DINO residuals.
RLA-WM 通过流匹配预测 RLA 值，并在仿真和真实数据集上优于最先进的基于特征和视频扩散世界模型，同时比视频扩散快数个数量级。：Building on RLA, we propose RLA World Model (RLA-WM), which predicts RLA values via flow matching. RLA-WM outperforms both state-of-the-art feature-based and video-diffusion world models on simulation and real-world datasets, while being orders of magnitude faster than video diffusion.
第一种技术是从无动作视频学习的极简世界动作模型，可提升 LIBERO 和真实机器人上的 VLA。：The first one is a minimalist world action model with RLA that learns from actionless videos, and improves VLA on LIBERO and real robot.
第二种技术是完全在仅从离线视频学习的世界模型内部训练的视觉强化学习框架，使用视频对齐奖励且无在线交互。：The second one is a visual RL framework trained entirely inside a world model learned from offline videos only, using a video-aligned reward and no online interactions.
