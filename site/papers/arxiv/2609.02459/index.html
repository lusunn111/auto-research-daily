Setting（研究设定）
在文明VI游戏环境中通过MCP协议评估语言模型智能体，每个回合超过300轮，产生数千次工具调用，部分可观测状态
Motivation（研究动机）
现有基准缺乏对长时序、工具介导环境中智能体持续规划、状态监控和执行能力的系统评估，需要新的基准和指标来刻画行为模式。
Insight（核心洞察）
在充分工具访问和明确指令下，智能体仍出现对战略性状态监控不足和短期承诺执行不一致的系统性偏差，这些偏差被解释为指令遵循下的偏离而非能力缺失。
Challenge（技术挑战）
  • 长时序任务中维持规划连续性
  • 部分可观测环境下主动监控关键状态
  • 执行自身规划承诺的可靠性
Analyze（问题分析）
摘要中通过提出接口级指标PMR和RAG@10来分析行为模式，揭示了智能体在监控和承诺执行上的规律性不足，未提供更深层分析，材料未说明。
Method（方法）
  • 提出CivBench开源基准，集成MCP协议，提供76个MCP工具和叙述层转换视觉游戏状态
  • 引入两个接口级指标：主动监控率（PMR）和RAG@10，量化智能体主动查询状态和短期承诺执行
  • 采用共享playbook协议，在四个模型家族上进行了23次可接受运行作为试点样本
Experiments（实验）
  • 试点运行涵盖四个模型家族，23次可接受运行
  • 尽管指导每20个回合查询胜利进度，智能体每30-75回合才查询一次
  • 在20次可检测失败中，有7次在游戏结束前20回合警告窗口内未查询
  • RAG@10指标范围在48.2%至65.8%之间
Limitations（局限）
  • 样本是试点，非模型排名，聚合结果不能可靠区分模型
  • 材料未明确陈述其他局限
与你的研究关系
该基准直接聚焦长时序工具介导智能体，其监控和承诺执行指标与具身智能中的长期规划、状态跟踪和执行一致性相关，可迁移到真实机器人系统和世界模型评估。

论文提出CivBench基准，用于评估长时序、工具介导环境中的语言模型智能体：We present CivBench, an open-source benchmark for evaluating language model agents in long-horizon, tool-mediated environments through the Model Context Protocol (MCP).
引入指标PMR和RAG@10来量化监控和承诺执行行为：we introduce two interface-level metrics that the environment makes measurable: Proactive Monitoring Rate (PMR), capturing whether agents actively query latent strategic state, and RAG@10, capturing whether commitments stated in structured planning reflections are executed within ten subsequent turns.
智能体在监控和承诺执行上显示出系统性不足：Agents under-monitor strategically relevant state that is available but requires explicit querying: despite playbook guidance to query victory progress every 20 turns, agents do so only every 30 to 75 turns, and in 7 of 20 detectable defeats they failed to query within the 20 turn warning window before game end.
