Setting（研究设定）
机器人操作中的部分可观测场景：机器人和场景运动导致先前观察到的区域移出相机视野，需要在仅有单目RGB、本体感受和任务指令的部署条件下，学习持久、3D感知的场景记忆并支撑控制。
Motivation（研究动机）
操作过程中已观察区域会离开视野，仅靠当前可见的几何感知RGB特征无法在部分可观测下完成控制；需要一种能整合观察历史并将推断内容锚定在当前证据上的场景记忆。
Insight（核心洞察）
通过多视图一致性学习场景token，再用rectified flow从单视图RGB和循环记忆补全场景token，并通过Anchor-Guided Cross-Attention将生成内容锚定到当前几何感知特征，从而在部署时仅需单目RGB、本体感受和任务指令。
Challenge（技术挑战）
  • 机器人与场景运动导致先前观察区域移出视野，形成部分可观测性
  • 需要整合观察历史并推断当前不可见区域的内容
  • 推断内容必须锚定在当前证据上，避免生成与当前几何不一致的幻觉
  • 训练可使用多视图与几何监督，但部署仅允许单目RGB、本体感受和任务指令
  • 紧凑的场景slot特征需要有效条件化视运动策略

Method（方法）
  • LIFD（Look, Imagine, Focus, and Do）框架，用于持久、3D感知的场景记忆
  • 通过多视图一致性学习场景token
  • 使用rectified flow从单一RGB视图和循环记忆补全场景token
  • Anchor-Guided Cross-Attention将生成锚定到当前几何感知特征
  • 紧凑的slot特征条件化视运动策略
  • 表示学习阶段使用多视图与几何监督
  • 部署阶段仅需一个RGB相机、本体感受和任务指令
Experiments（实验）
  • LIFD (Staged) 在LIBERO上达到91.6%平均成功率
  • LIFD (Staged) 在MetaWorld上达到79.8%平均成功率
  • 相比Joint training，LIBERO平均成功率提升11.1个百分点
  • 在每类任务家族用十个演示进行策略头适配后，LIFD在四个UR5e任务家族上达到56.0%平均成功率
  • 相同设置下OpenVLA-7B为40.5%平均成功率

论文提出LIFD框架，用于持久、3D感知的场景记忆：We introduce \lifd{} (Look, Imagine, Focus, and Do), a framework for persistent, 3D-aware scene memory.
LIFD通过多视图一致性学习场景token，并用rectified flow从单视图RGB和循环记忆补全：LIFD learns scene tokens through multi-view agreement, then completes them from a single RGB view and recurrent memory using rectified flow.
Anchor-Guided Cross-Attention将生成锚定到当前几何感知特征：Anchor-Guided Cross-Attention anchors generation to current geometry-aware features, and compact slot features condition a visuomotor policy.
部署仅需一个RGB相机、本体感受和任务指令：deployment requires one RGB camera, proprioception, and a task instruction.
LIFD (Staged) 在LIBERO上达到91.6%平均成功率，在MetaWorld上达到79.8%：LIFD (Staged) reaches 91.6\% average success on LIBERO and 79.8\% on MetaWorld, improving LIBERO average success by 11.1 percentage points over Joint training.
