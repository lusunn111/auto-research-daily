Figure 1 Overall architecture of World Dreamer v5-lite. Multi-robot images and language tokens enter the vision–language model (VLM) before the learnable agent queries, yielding a scene-prefix key/value (KV) cache and one hidden state per robot query. The video strip depicts a temporal window: observed video latents are encoded and combined with camera geometry to build the shared world state ϕ \boldsymbol{\phi} ; future latents supply training supervision only. The Action Decoder uses the VLM outputs, ϕ \boldsymbol{\phi} , proprioception, and multi-robot noisy actions to predict a flow velocity for each robot.

核心洞察

以一个所有机器人共同读取的共享世界状态φ作为团队的统一空间参照：由预训练视频编码器的标定特征在工作空间坐标中填充φ且其空间尺寸随视图增加保持固定，配合每个机器人一个查询、位姿感知的信息交换与各自独立的动作流，实现“多对一、一对多”的视觉信息流；再用掩码视图协同训练强制模型依赖队友观测。

为什么值得看：它提供了一个可迁移的“共享世界状态+每机器人查询”架构来解决多视图空间对应与跨机器人信息共享问题，掩码视图协同训练是提升机器人利用队友观测的通用训练技巧；同时在多机器人基准与真实机器人上给出相对强基线的大幅提升，对世界动作模型与多机器人VLA研究具有直接参考价值。

Setting（研究设定）
多机器人操作控制：每个机器人携带自身相机，观测分布式且可能被遮挡，各机器人动作空间可能不同，需在共享工作空间内预测各自独立的动作序列；预训练覆盖20种仿真机器人、RoboFactory与真实机器人轨迹。
Motivation（研究动机）
现有VLA与世界动作模型大多面向单机器人；仅拼接多相机token并不能在工作空间坐标上建立视图间的空间对应；独立策略虽保留机器人特定控制，却无法利用队友相机观测；即使具备跨机器人共享信息能力，完整观测训练下机器人也缺乏使用他者视角的动机。
Insight（核心洞察）
以一个所有机器人共同读取的共享世界状态φ作为团队的统一空间参照：由预训练视频编码器的标定特征在工作空间坐标中填充φ且其空间尺寸随视图增加保持固定，配合每个机器人一个查询、位姿感知的信息交换与各自独立的动作流，实现“多对一、一对多”的视觉信息流；再用掩码视图协同训练强制模型依赖队友观测。
Challenge（技术挑战）
  • 分布式观测：各相机随机器人移动且只覆盖部分工作空间，不同相机的图像块不对应同一物理位置
  • 控制分离但决策耦合：机器人具身与动作空间可能不同，但各自动作依赖其他机器人的位置与行为
  • 观测常不完整：一个机器人的相机可能被其他机器人或被操作物体遮挡
  • 视图拼接本身无法建立工作空间坐标下的对应关系
  • 完整观测训练下模型缺乏利用队友视角的激励
Analyze（问题分析）
作者从多机器人设定与单机器人控制的三个差异（观测分布、控制分离而决策耦合、观测不完整）出发，指出直接拼接相机token与独立策略各自的缺陷，并据此提出共享世界状态、位姿感知查询交换与掩码视图协同训练三项设计。
Method（方法）
  • 由预训练视频编码器产生标定特征，按工作空间坐标聚合为共享世界状态φ，其空间尺寸在增加视图时保持固定
  • 视觉语言模型提供场景上下文，并为每个机器人产生一个查询；查询读取共享φ并交换位姿感知信息
  • 各机器人动作流保持独立，由基于流的动作解码器结合VLM输出、φ、本体感知与多机器人噪声动作预测每个机器人的流速度
  • 掩码视图协同训练：从两个视觉分支中同时扣留选定相机视图，但保留所有机器人的动作目标，以暴露不完整视觉覆盖
  • 总损失为0.5倍动作损失、0.2倍未来视频潜变量损失与λ_field倍场损失的加权和，其中λ_field从0.1线性降至0.02
  • 视觉语言主干由Qwen3-VL初始化，视觉编码器与语言模型参与训练，输入嵌入与语言建模头冻结；使用bfloat16与DeepSpeed ZeRO Stage 2
  • 动作维度差异由动作掩码处理，缺失相机由视图掩码处理
Experiments（实验）
  • 预训练语料包含20种仿真机器人操作轨迹、RoboFactory轨迹与LeKiwi、OpenArm真实机器人轨迹，覆盖单臂与双臂配置、60余种任务、超过10,000小时交互
  • RoboFactory：在Place Food（两机器人）、Camera Alignment（三机器人）、Take Photo（四机器人）上平均成功率74.0%，比最强基线π0.5的50.3%高23.7个百分点；三项任务分别超出36、11、24个百分点
  • 真实机器人四项任务（Block transfer、Cap unscrewing、Starfruit bagging、Block passing）平均成功率78.8%，比π0.5的65.0%高13.8个百分点
  • RoboCasa365总体成功率58.08%，其中Atomic-Seen 80.8%、Composite-Seen 60.0%、Composite-Unseen 30.6%
  • RoboFactory按协议每任务评估100种场景配置，评估回合未包含在训练数据中

论文提出以共享世界状态φ为核心的多机器人世界动作模型：World Dreamer v5-lite is a multi-robot world-action model built around a shared world state
共享世界状态由预训练视频编码器的标定特征按工作空间坐标填充，且空间尺寸随视图增加保持不变：Calibrated features from a pretrained video encoder populate this state in workspace coordinates; its spatial size remains fixed as views are added.
每个机器人一个查询，查询读取共享状态并交换位姿感知信息，动作流保持分离：The queries read the shared state and exchange pose-aware information, while their action streams remain separate.
掩码视图协同训练从两个视觉分支扣留选定相机视图但保留所有动作目标：Masked-view cooperative training withholds selected camera views from both visual branches while retaining all action targets.
