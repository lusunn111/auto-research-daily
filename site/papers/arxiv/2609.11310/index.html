Your Model Already Knows Don't Teach It, Learn to Ask It: Soft Prompting for Few-Shot Adaptation of Vision-Language Models

Gautam Rajendrakumar Gare · Siyi Li · Hewei Wang · Cesar Daniel Hernandez · Wei Zhao · Wolfgang M. Pauli · John Galeotti · Deva Ramanan

核心洞察

现代 VLM 已编码了专业领域所需的大部分知识，关键不是教模型新权重，而是学会如何向它提问；提示 token 应放在视觉与文本 token 的跨模态边界，并从空空间 token 初始化，这样的 token 更像提示而非权重，可迁移、可言语化。

为什么值得看：对关注具身智能与 VLA 部署的研究者而言，该文提供了一条极低参数量的适应路径：无需微调主干即可在少样本下匹配 LoRA，并避免遗忘，还能把学到的 token 迁移到新模型或言语化为可读提示；其跨模态边界放置与空空间初始化的结论可直接迁移到 VLA 策略适应和系统优化中。

Setting（研究设定）
在域外场景（航拍、工业、医学影像）中用仅十张标注图像进行少样本目标检测；预训练 VLM 主干冻结，只优化少量连续提示 token；并进一步将该方法扩展到 RoboCasa 操作任务上冻结的 π₀.₅ 视觉-语言-动作策略。
Motivation（研究动机）
现有 VLM 适应方法主要是离散提示优化和 LoRA 微调；作者重新审视第三条路——软提示，希望在极少标注、跨域场景下以极小参数量获得与 LoRA 相当的性能，同时避免微调带来的预训练能力遗忘。
Insight（核心洞察）
现代 VLM 已编码了专业领域所需的大部分知识，关键不是教模型新权重，而是学会如何向它提问；提示 token 应放在视觉与文本 token 的跨模态边界，并从空空间 token 初始化，这样的 token 更像提示而非权重，可迁移、可言语化。
Challenge（技术挑战）
  • 软提示优化难度更高，跨随机种子方差更大
  • 需要确定提示 token 的最佳放置位置
  • 需要确定提示 token 的初始化方式
  • 在保持预训练能力不遗忘的同时匹配 LoRA 精度
Analyze（问题分析）
作者通过受控比较分析两个设计选择：一是提示 token 的放置位置，比较跨模态边界与其他位置（10.0 vs. 8.4 mAP）；二是初始化来源，比较空空间 token 与语义初始化、随机初始化，并据此固定配置后与最优 LoRA 配置对比参数量、方差和遗忘程度。
Method（方法）
  • 冻结预训练 VLM 主干，仅优化少量连续提示 token（平均 7,168 参数，1 至 3 个 token）
  • 将提示 token 放置在视觉与文本 token 之间的跨模态边界，而非其他位置
  • 使用空空间 token 初始化提示，而非语义或随机初始化
  • 与离散提示优化和 LoRA 微调进行对比
  • 在 RoboCasa 操作任务上把软提示应用于冻结的 π₀.₅ 视觉-语言-动作策略，并将 token 放在梯度瓶颈处
Experiments（实验）
  • 在 Roboflow20-VL 10-shot 上，1 至 3 个学习 token（平均 7,168 参数）达到 14.2 mAP，匹配最佳 LoRA 配置，训练参数量少 20,000 倍以上
  • 提示 token 放在跨模态边界时 10.0 mAP，优于其他放置方式的 8.4 mAP
  • 软提示方差高于 LoRA，跨随机种子更难优化
  • 与软提示精度相当的 LoRA 秩使 NaturalBench VQA 精度相对下降 35%，最大秩时下降 56%，而软提示不改变预训练性能
  • 学习到的 token 无需重训练即可迁移到更新的 Qwen3.5-9B 模型（+0.8 mAP）
  • 学习到的 token 可言语化为可读提示，与提示搜索方法竞争：匹配 DetPO，优于 GEPA
  • 在 RoboCasa 操作任务上，冻结的 π₀.₅ 策略受益于软提示，token 放在梯度瓶颈时在三个任务中的两个上匹配 LoRA 基线
Limitations（局限）
  • 软提示仍更难优化，跨随机种子方差更高
与你的研究关系
论文直接涉及视觉语言模型与视觉-语言-动作策略的参数高效适应：其软提示方法在冻结 π₀.₅ VLA 策略的 RoboCasa 操作任务上有效，与具身智能中的动作生成和真实机器人评测相关；方法以极少参数实现适应且不遗忘，对推理效率、模型压缩与实时控制场景中的部署有参考价值；但论文不涉及世界模型或长时序预测。
证据与不确定性

仅依据标题与摘要判断，未提供全文，无法确认实验细节、统计显著性、RoboCasa 任务的具体配置与评测协议，也无法核实参数量、mAP 与遗忘比例的完整上下文；分类包含 eess.IV 与医学影像，但摘要未给出医学影像的单独结果。

软提示在少样本检测中仅用极少参数即可匹配最佳 LoRA 配置：one to three learned tokens (7,168 parameters on average) match the best LoRA configuration on Roboflow20-VL (14.2 mAP, 10-shot) while training over 20,000x fewer parameters
提示 token 放置在视觉与文本 token 的跨模态边界效果最好：placing prompt tokens at the cross-modal boundary between visual and text tokens outperforms other placements (10.0 vs. 8.4 mAP)
从空空间 token 初始化优于语义与随机初始化：initializing prompts from the empty space token outperforms semantic and random initialization
软提示不造成预训练能力遗忘，而 LoRA 会显著降低 VQA 精度：the LoRA rank matching our accuracy reduces NaturalBench VQA accuracy by 35% relative, rising to 56% at the largest rank, whereas soft prompting leaves pretrained performance unchanged
软提示优化更难，方差更高：Soft prompting remains harder to optimize, exhibiting higher variance across random seeds
学习到的 token 可迁移到更新模型且可言语化：They transfer to a newer model without retraining (+0.8 mAP on Qwen3.5-9B) and can be verbalized into readable prompts competitive with prompt-search methods
方法可扩展到冻结的 VLA 策略操作任务：On RoboCasa manipulation tasks, the frozen $\pi_{0.5}$ vision-language-action policy benefits from soft prompting, matching the LoRA baseline on two of three tasks when tokens are placed at the gradient bottleneck
