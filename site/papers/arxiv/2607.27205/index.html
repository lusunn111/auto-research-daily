Setting（研究设定）
机器人操作任务中的视觉-语言-动作建模，目标是使用紧凑模型在消费级 GPU 上实现实时推理，并在 LIBERO 与 RoboTwin 2.0 基准上评测。
Motivation（研究动机）
主流 VLA 模型采用以 LLM 为中心的 V→L→A 路径，先通过大型语言模型处理视觉观测和语言指令再预测动作，虽然有效但带来大量计算与显存开销，限制了实时部署与资源受限场景的可用性。
Insight（核心洞察）
可以用直接的 V + L → A 映射替代以 LLM 为中心的 V→L→A 路径：独立编码视觉和语言，通过轻量双向视觉-语言交互直接交换信息，并用紧凑解码器预测连续动作块，从而在避免 LLM 执行路径开销的同时构建任务条件表示。
Challenge（技术挑战）
  • 避免以 LLM 为中心的 V→L→A 路径带来的高计算开销
  • 避免以 LLM 为中心的 V→L→A 路径带来的高显存开销
  • 在紧凑模型规模下保持高操作成功率
  • 实现实时推理延迟与低显存占用
  • 在视觉与语言之间进行轻量而有效的信息交互
Analyze（问题分析）
材料未说明作者如何具体分析问题，仅在摘要中说明观察到了以 LLM 为中心的 V→L→A 设计存在大量计算和内存开销，并提出直接的 V + L → A 映射作为替代。
Method（方法）
  • 提出 TurboVLA，一种建立在直接 V + L → A 映射上的紧凑 VLA 架构。
  • 不使用大型语言模型作为感知与动作之间的中心接口。
  • 独立编码视觉观测和语言指令。
  • 通过轻量级双向视觉-语言交互在视觉和语言表示之间直接交换信息。
  • 使用紧凑解码器预测连续动作块。
  • 该简单设计直接构建任务条件表示，避免以 LLM 为中心的执行路径开销。
Experiments（实验）
  • 在 LIBERO 上，TurboVLA 达到 97.6% 平均成功率，仅有 0.2B 参数，推理延迟 31.2 ms，在消费级 RTX 4090 上推理显存占用 0.9 GiB。
  • 一个 0.4B TurboVLA 在 RoboTwin 2.0 上达到 88.06% 成功率，甚至匹配或超过显著更大的 VLA 策略。
  • 结果说明，TurboVLA 的简单 V + L → A 设计无需以 LLM 为中心的执行路径即可实现高性能，为视觉、语言和动作如何连接以进行高效机器人操作提供了新视角。

主流 VLA 模型采用以 LLM 为中心的 V→L→A 路径，带来大量计算与显存开销。：Vision-language-action (VLA) models commonly adopt an LLM-centric $V \to L \to A$ pathway, processing visual observations and language instructions through a large language model before predicting robot actions. Although effective, this design incurs substantial computation and memory overhead.
TurboVLA 的核心设计是直接 V + L → A 映射，不使用大语言模型作为感知与动作之间的中心接口。：In this work, we introduce TurboVLA, a compact VLA architecture built on a direct $V + L \to A$ mapping. Instead of using a large language model as the central interface between perception and action, TurboVLA independently encodes visual observations and language instructions, directly exchanges information between them through lightweight bidirectional vision-language interaction, and predicts continuous action chunks with a compact decoder.
TurboVLA 在 LIBERO 上以 0.2B 参数达到 97.6% 平均成功率，推理延迟 31.2 ms，RTX 4090 上推理显存 0.9 GiB。：On LIBERO, TurboVLA achieves 97.6% average success with only 0.2B parameters, 31.2 ms inference latency, and 0.9 GiB inference VRAM on a consumer-grade RTX 4090.
