Setting（研究设定）
在预训练视觉-语言-动作模型之上，学习在精度关键的阶段由哪个强化学习专家接管控制，并在 LIBERO 多物体抓放任务与真实线缆拾取和端口插入任务上评测
Motivation（研究动机）
预训练 VLA 具备广泛操作能力，但在连接器插入、线缆管理等接触密集工业任务的精度关键阶段表现不佳；用 RL 微调虽可任务特异提升，但如何决定何时需要 RL 精修、由哪个专家接管，并保留通用行为，仍是开放问题
Insight（核心洞察）
可以通过学习式路由在部署时不访问特权阶段边界的情况下，识别精度关键阶段并切换至对应 RL 专家，从而在最有价值处施加精确适应，同时保留通用 VLA 行为
Challenge（技术挑战）
  • 判断何时需要 RL 精修
  • 在多个 RL 专家中选择正确的专家
  • 抑制切换过程中的瞬态抖动
  • 处理分块策略输出之间的动作边界与过渡
  • 部署时无法访问特权阶段边界
  • 保留通用行为并支持失败恢复
Analyze（问题分析）
材料未说明；摘要仅指出需要解决何时切换与选择哪个专家的问题，未描述具体分析手段
Method（方法）
  • RouteRLT 是一个路由框架，学习何时以及由哪个 RL 专家从通用 VLA 接管控制
  • RL 专家是为单个精度关键阶段训练的强化学习策略
  • 阶段选择器识别当前活动的控制器
  • 稳定器抑制瞬态切换
  • 动作边界管理器处理分块策略输出之间的过渡
Experiments（实验）
  • 在 LIBERO 的多物体抓放任务上进行仿真评测
  • 在真实世界线缆拾取和端口插入任务上评测，该任务包含多个精度关键阶段
  • 仿真中，学习到的路由优于基础 VLA，并与使用特权阶段边界的路由相匹配，且部署时不访问这些边界
  • 真实机器人评测在操作员对齐的交接协议下，验证了自动路由到拾取专家和插入专家
  • 结果表明学习式路由在精度适应最有价值处应用 RL 专家控制，同时保留通用 VLA 行为，包括从失败执行尝试中恢复

论文研究的问题是何时需要 RL 精修以及哪个专家策略应当接管：how to preserve its generalist behavior while deciding when RL refinement is needed and which specialized policy should act remains an open question
RouteRLT 是一个路由器框架，学习何时以及由哪个 RL 专家从通用 VLA 接管控制：we present RouteRLT, a routing framework that learns when and which RL specialist, an RL policy trained for a single precision-critical phase, should take control from a generalist VLA
方法包含阶段选择器、稳定器和动作边界管理器：A phase selector identifies the active controller, a stabilizer suppresses transient switches, and an action-boundary manager handles transitions between chunked policy outputs
在仿真中，学习到的路由优于基础 VLA 并与使用特权阶段边界的路由相匹配，且部署时不访问这些边界：In simulation, the learned routing improves over the base VLA and matches routing with privileged phase boundaries, without accessing those boundaries at deployment
真实机器人评测验证了自动路由到拾取和插入专家：The real-robot evaluation validates automatic routing to both the pickup and insertion specialists under an operator-aligned handoff protocol
结果支持在保留通用 VLA 行为的同时应用 RL 专家控制，包括失败恢复：learned routing applies RL specialist control where precise adaptation is most valuable while preserving generalist VLA behavior, including recovery from failed execution attempts
