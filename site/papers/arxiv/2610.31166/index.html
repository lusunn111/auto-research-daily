目标之前先有记忆：预历史记忆在人形全身操作中的作用

Memory before Goal: Role of Pre-History Memory for Humanoid Loco-Manipulation

Chenyuan Chen · Ran Ding · Lechen Zhang · Zewen He · Yoshihiko Nakamura

核心洞察

人只记住其关心事物发生变化的时刻，而非每一时刻；因此应由任务物体的事件因果地选择少量关键帧，在自适应预算内保留‘行动前’的物体先验历史，关键在于保留正确的帧，而不是保留更多的帧。

为什么值得看：论文给出记忆在全身 VLA 中作用的具体机制与量化收益：在动态、线索消失的真实场景下大幅提升成功率，同时不牺牲反应性技能，并附带仿真与真实机器人基准；对研究 VLA 长时序依赖、记忆设计、关键帧选择、推理成本与真实部署评测的读者具有直接参考价值。

Setting（研究设定）
动态场景下的人形机器人全身移动操作（loco-manipulation）；任务具有非马尔可夫性质：决策所需的线索在决策时刻已因物体状态改变、被遮挡，或随机器人转身行走而移出视野，因此仅凭当前观测无法确定正确动作。
Motivation（研究动机）
现有全身 VLA 策略大多仅依据当前观测行动，忽略时序依赖，在物体状态变化、隐藏、移动或移出视野的动态场景中失败；已有记忆策略多为桌面机械臂设计，存在保留长帧历史成本高且稀释短暂线索、压缩丢失细节、固定间隔采样漏掉短暂线索、事件帧绑定机器人自身操作等问题。
Insight（核心洞察）
人只记住其关心事物发生变化的时刻，而非每一时刻；因此应由任务物体的事件因果地选择少量关键帧，在自适应预算内保留‘行动前’的物体先验历史，关键在于保留正确的帧，而不是保留更多的帧。
Challenge（技术挑战）
  • 人形机器人头部相机随转身行走而移动，线索会离开视野，需补偿相机自身运动
  • 记忆需在全身控制运行的同时因果地在线更新
  • 线索短暂且很少重复，均匀采样或长历史保留都难以奏效
  • 即使双系统设计中 VLM 规划器能对历史推理，也需先定位关键帧
Analyze（问题分析）
作者将动态场景中的全身操作形式化为非马尔可夫问题，并定义‘记忆依赖任务’：情节分为线索阶段、保持阶段与决策阶段，线索可通过场景诱发或运动诱发两种方式在决策时刻不可观测，且要求指令与决策前运动不依赖答案、答案类别均衡，从而无记忆策略只能达到随机水平；据此把记忆决策准确率与操作成功率分开评分，并按‘物体记忆、空间记忆、时序记忆’区分所需记忆类型。
Method（方法）
  • 冻结 SAM3 作为可提示视频分割模型，在头部相机流中跟踪任务物体
  • 检测物体出现、消失、移动或形变事件，并补偿相机自身运动
  • 由物体事件因果地在自适应预算内选择关键帧
  • 用物体 token 编码外观、几何与时间，并与关键帧一起由动作专家通过交叉注意力读取
  • 提出 HuMeGo 人形记忆基准，含六个仿真与六个真实 Unitree G1 任务
  • 真实机器人上采用实时分块执行，SAM3 每执行一个动作块跟踪一帧
Experiments（实验）
  • 仿真中把基础策略成功率从 29.1% 提升到 72.6%
  • 真实机器人上从 36.7%（22/60）提升到 88.3%（53/60）
  • 标准 SIMPLE 任务从 70.2% 提升到 86.9%
  • 在 14 个 SIMPLE 任务上按 L0/L1/L2 随机化等级各 10 回合评测，逐任务报告成功数
  • 与无记忆基线（InternVLA-M1、Diffusion Policy、ACT、EgoVLA、π0.5、GR00T、Ψ0）及均匀记忆基线比较
Limitations（局限）
  • SAM3 在物体从未被检测到时漏掉线索
  • 在线跟踪带来额外推理成本
  • 渲染造成仿真到现实的差距
  • 仿真的演示是脚本化的
与你的研究关系
该工作直接面向全身 VLA 策略的可执行动作生成与真实机器人部署，通过物体事件驱动的关键帧记忆解决长时序依赖与非马尔可夫动态场景问题；SAM3 在线跟踪与每动作块一次的跟踪频率涉及推理效率与实时控制权衡；在 Unitree G1 上的真实评测契合真实机器人评测关注点，并对世界模型中长时序预测与状态记忆具有参考价值。

动态场景中的全身操作具有非马尔可夫性质，线索会随物体变化、隐藏或机器人转身行走而消失，而全身 VLA 策略只看当前。：Humanoid loco-manipulation in dynamic scenes is non-Markovian: cues vanish as objects change or are hidden, or leave the view as the robot turns and walks, yet whole-body vision-language-action (VLA) policies see only the present.
方法以 SAM3 跟踪任务物体，并由物体事件在自适应预算内因果选择关键帧，动作专家通过交叉注意力读取关键帧与物体 token。：SAM3 tracks the task objects, and their events causally select key frames within an adaptive budget, which the action expert reads by cross-attention together with object tokens encoding appearance, geometry and time.
作者提出包含六个仿真和六个真实 Unitree G1 任务的 HuMeGo 人形记忆基准。：We also contribute HuMeGo, a humanoid memory benchmark with six simulated and six real-world Unitree G1 tasks.
