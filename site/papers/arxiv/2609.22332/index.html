Setting（研究设定）
基于预训练视频扩散 Transformer 的生成式世界动作模型，通过单独参数化的 World 与 Action 专家经 Masked Joint Self-Attention 耦合，在统一流匹配目标下联合预测未来 RGB 观测、Scalar Affordance 场、Affordance Heatmap 与连续机器人动作。
Motivation（研究动机）
可泛化的机器人操作需要预测场景如何演变、识别何处可交互并决定如何行动；带动作标注的机器人视频直接监督控制但昂贵且多样性有限，而第一视角人类视频包含多样交互却缺乏机器人动作且存在本体与外观差异。
Insight（核心洞察）
将对象中心的时空可供性作为显式预测目标，通过 Scalar Affordance 与 Affordance Heatmap 在生成未来世界中表达，为动作生成提供共享交互目标，从而跨越人类与机器人视频实现无需人类动作标签或重定向的迁移。
Challenge（技术挑战）
  • 人类视频缺乏机器人动作标注且与本体的外观差异大
  • 以 RGB 或视觉隐 token 表示世界与动作生成存在语义错位
  • 动作级迁移依赖人体运动恢复与跨本体对齐质量
  • 在固定机器人监督下有效利用规模化人类视频
Analyze（问题分析）
摘要与引言指出，以 RGB 观测或视觉隐 token 表示预测世界虽能捕捉外观与场景演变，却不能显式识别决定操作任务的对象与交互区域；作者据此将可供性作为显式预测目标，并分析人类视频与机器人视频在动作标注与本体上的不对称性。
Method（方法）
  • 提出 AffordanceWAM，在生成未来 World 中以 Scalar Affordance 和 Affordance Heatmap 表示对象中心的时空可供性
  • 基于预训练视频扩散 Transformer，使用单独参数化的 World 与 Action 专家
  • 通过 Masked Joint Self-Attention 耦合专家：RGB 与 Scalar Affordance token 互相注意，Heatmap token 注意 RGB、Scalar Affordance 与自身，Action token 注意 RGB、Scalar Affordance 与自身，屏蔽 Action-to-World 信息流
  • 在统一流匹配目标下联合预测未来 RGB、Scalar Affordance、Affordance Heatmap 与连续机器人动作
  • 人类视频监督全部三个未来 World 流，机器人轨迹额外提供动作监督
Experiments（实验）
  • 在 RoboCasa、CALVIN ABC→D 及真实世界操作上，相比仅 RGB 与仅机器人数据基线取得一致增益
  • 真实世界任务中成功率从 42.7% 提升到 74.7%，抽屉关闭成功率从 46.7% 提升到 80.0%，三果放置成功率从 26.7% 提升到 53.3%，插花成功率从 6.7% 提升到 20.0%
  • 在固定机器人监督下，RoboCasa 性能随可供性标注人类视频规模单调提升

将对象中心的时空可供性表示为 Scalar Affordance 与 Affordance Heatmap：We introduce AffordanceWAM, an affordance-aware generative World Action Model that represents object-centric spatiotemporal affordance through Scalar Affordance and Affordance Heatmap, within the generated future World.
使用单独参数化的 World 与 Action 专家，并通过 Masked Joint Self-Attention 耦合：Built on a pretrained video diffusion Transformer, AffordanceWAM uses separately parameterized World and Action Experts, coupled through Masked Joint Self-Attention, to jointly predict future RGB observations, Scalar Affordance fields, Affordance Heatmaps, and continuous robot actions under a unified flow-matching objective.
人类视频监督三个未来世界流，机器人轨迹额外提供动作监督：Human videos supervise all three future-World streams, whereas robot trajectories additionally provide action supervision, enabling transfer without human action labels or retargeting.
在 RoboCasa、CALVIN ABC→D 与真实世界操作上一致优于基线：Experiments on RoboCasa, CALVIN ABC$\rightarrow$D, and real-world manipulation demonstrate consistent gains over RGB-only and robot-data-only baselines.
