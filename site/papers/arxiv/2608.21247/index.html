(1) Classical signal coding characterizes the trade-off between mathematical signal fidelity and signal-content change, where compression quality is usually evaluated using signal-level distortion. (2) Human-oriented JND introduces perceptual benefit zones, where signal changes remain unnoticeable to human observers despite measurable signal distortion. (3) Machine-oriented JND extends receiver-dependent tolerance to machine responses, where noticeability is determined by downstream task responses, such as classification and detection. (4) For embodied perception, we further instantiate the machine-oriented JND boundary with respect to action responses in a VLA-based embodied interaction environment, where noticeability is determined by whether changes in visual representations induce a tolerable deviation in the language-conditioned robot action during closed-loop control.

Setting（研究设定）
大基础模型在具身智能体中的推理成本优化：视觉-语言-动作（VLA）策略在延迟敏感的闭环机器人动作预测中使用令牌，针对此类模型进行令牌剪枝与 KV-cache 复用等压缩。
Motivation（研究动机）
现有令牌压缩方案依赖冗余或重要性线索（视觉相似度、注意力分数、显著性），这些线索只间接度量安全压缩的关键因素：令牌变化多少才会导致下游动作出现不可接受的偏差。这一接收者相关的容忍度与恰可察觉差异（JND）原理密切相关。
Insight（核心洞察）
将 JND 从人类视觉系统扩展到机器下游响应，提出 Action-JND：以 VLA 策略在闭环控制中语言条件化的动作响应来定义可察觉性，仅当令牌改变引发的动作偏差在容许裕度内时才视为可接受，从而以动作容忍度作为压缩准则。
Challenge（技术挑战）
  • 现有冗余/重要性线索无法直接衡量令牌变化导致的下游动作偏差容忍度。
  • 具身智能体中令牌既支撑感知与语义理解，又直接影响延迟敏感的闭环动作预测，压缩需兼顾安全性与实时性。
  • 需要在深度视觉特征空间中轻量预测保持策略响应前提下的最大可容忍扰动。
Analyze（问题分析）
作者指出既有压缩线索（视觉相似度、注意力分数、显著性）仅间接度量安全压缩的关键因素，即令牌可变化而不引起下游动作不可接受偏差的容忍度；据此引入 Action-JND，将可察觉性定义为闭环控制中 VLA 策略的语言条件化动作响应偏差是否在容许裕度内。材料未说明更具体的分析过程。
Method（方法）
  • 提出 Action-JND，将 JND 建模扩展到具身感知，以语言条件化的 VLA 策略动作响应定义令牌可察觉性：仅当诱导的动作偏差保持在容忍裕度内，令牌改变才被允许。
  • 开发轻量级的逐令牌 JND 估计器，在深度视觉特征空间中预测保持策略响应前提下的最大可容忍扰动。
  • 将得到的动作容忍度分数作为即插即用准则，用于 VLA 压缩范式，包括陈旧 KV 复用与令牌剪枝，优先压缩动作容忍的令牌。
Experiments（实验）
  • 在 LIBERO 基准上使用 OpenVLA 与 OpenVLA-OFT 进行实验。
  • 结果表明 Action-JND 持续提升压缩可靠性，尤其在激进压缩率下更为明显。摘要未给出具体数值。
