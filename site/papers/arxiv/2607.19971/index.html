Unified Prediction and Planning via Conflict-Aware Disjoint Parameter Training

Setting（研究设定）
资源受限边缘设备上的社交机器人导航
Motivation（研究动机）
在拥挤环境中，准确预测周围智能体运动和安全运动规划是两个紧密耦合的关键任务，但紧凑共享编码器中的统一模型常忽略预测与规划目标不同导致的表征冲突。
Insight（核心洞察）
识别出技能冲突现象，并提出分离参数训练框架（DPT），通过分布式参数学习分离各任务关键参数区域，并采用稀疏合并以提升性能。
Challenge（技术挑战）
  • 预测邻居行为与自我中心安全规划目标差异导致表征冲突
  • 紧凑共享编码器中参数重叠造成任务间竞争
  • 资源受限设备需同时保证性能和效率
Analyze（问题分析）
作者首先识别技能冲突现象，指出重叠参数分配导致不同任务竞争同一权重，阻碍模型专业化；观察到稀疏合并优于全参数合并，因其防止相邻特征干扰并集中表征能力。
Method（方法）
  • 提出模型合并框架Disjoint Parameter Training (DPT)
  • DPT通过分布式参数学习分离各任务关键参数区域，保留核心能力后合并
  • 采用稀疏合并仅整合对每个任务最有影响力的参数
  • DPT可并行应用于各种合并方法
Experiments（实验）
  • 在JRDB和JTA基准上评估，显示DPT优于现有方法，验证其多功能性和有效性
Limitations（局限）
  • 材料未说明
与你的研究关系
与具身智能和世界模型相关，因为其统一预测与规划，且关注资源效率，可迁移至真实机器人导航。

紧凑共享编码器中统一模型存在表征冲突：recent unified models often overlook severe representational conflicts that arise from the distinct objectives of predicting neighbor behaviors versus ego-centric safety planning.
DPT通过分离参数学习缓解技能冲突：DPT mitigates performance degradation caused by Skill Conflict through distributed parameter learning, which separates the key parameter regions of each task while preserving their core capabilities prior to merging.
稀疏合并优于全参数合并：we observe that sparse merging, which selectively integrates only the most influential parameters for each task rather than combining all task-specific parameters, yields optimal performance
