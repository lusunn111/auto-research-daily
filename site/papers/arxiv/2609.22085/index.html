Figure 1 SeeQ overview. We train a generalist Q-value function on diverse robot data using a pretrained vision-language model (VLM) backbone. The value function is then fine-tuned on a downstream task and used to steer a base policy at test time. To address the challenges of long-horizon value learning, we use temporal-difference (TD) learning to fit the Q-value of the currently active subtask rather than that of the entire task. To eliminate the need for humans to specify this subtask at deployment, we modify the Q-function architecture to first predict the active subtask in natural language and then predict its value, encouraging internal representations better aligned with subtask-level value estimation.

Setting（研究设定）
语言条件机器人操作，给定基础通用策略 π_base，在离线机器人轨迹数据上预训练通用 Q 函数，再微调用于下游任务，测试时用 Q 函数对策略提出的 N 个候选动作块打分并执行最高分动作（best-of-N 策略引导）。
Motivation（研究动机）
通用机器人策略在复杂长时序任务上仍然脆弱：包含多阶段或需要对同一阶段反复尝试与权衡；稀疏任务级奖励导致长信用分配、贝尔曼备份困难，且离线数据覆盖不足。学习 Q 函数可对候选动作排序或引导策略改进，但长时序下的价值学习本身不可靠。
Insight（核心洞察）
只对当前活跃子任务（currently active subtask）学习 Q 值，而不是对整个任务学习价值，从而缩短价值预测时域，使时间差分目标能有效学习；同时让 Q 函数自回归地先用自然语言预测当前子任务、再估计其价值，从而在测试时无需人工标注或独立子任务预测模块。
Challenge（技术挑战）
  • 长时序下 Q 估计误差随视野增长（材料引用 Park et al. 称在离线 RL 中近乎指数增长）
  • 离线数据集对长轨迹中众多状态-动作配置覆盖有限
  • 稀疏任务级奖励导致信用分配视野长、贝尔曼备份困难
  • 子任务标注在恢复行为或子任务边界附近存在歧义
  • 部署时子任务预测错误会让 critic 用错误目标评估动作
  • 优化当前子任务价值偏向局部进展，可能与整体任务目标不一致
Analyze（问题分析）
作者将长时序价值学习困难的根源归结为预测时域本身：标准 Q 函数估计整个任务的成功期望，随动作数增长而变得困难；离线设置进一步因数据覆盖有限而加剧。因此提出以子任务级价值作为学习目标，利用离线机器人数据中已有的子任务级标注提供分解，并用自然语言子任务预测替代部署时的子任务标注或模块化预测系统。
Method（方法）
  • 训练通用 Q 函数 Q_θ(s_t, a_{t:t+H-1}, l)，基于离线机器人轨迹数据集，使用预训练视觉语言模型作为主干。
  • 用时间差分（TD）目标拟合当前活跃子任务的 Q 值，而非整个任务的 Q 值，以缩短价值预测时域。
  • 训练阶段利用离线机器人数据中存在的子任务级标注提供分解，从而可利用广泛、可能次优的机器人数据。
  • 将 Q 函数架构改为自回归：先以自然语言预测当前活跃子任务，再估计该子任务的价值，使内部表示与子任务级价值估计对齐，并消除测试时对人工标注或模块化子任务预测系统的依赖。
  • 在多样开源机器人操作数据上预训练 SeeQ，再在下游任务上微调。
Experiments（实验）
  • 在两个双臂机器人平台上的四个真实世界操作任务中评估，SeeQ 价值函数显著改善 best-of-N 策略引导。
  • 结论部分报告：SeeQ 将平均成功率从 35.4% 提升到 66.7%（1.88 倍），并在不同数据组成上均有提升。
  • 消融实验强调机器人数据预训练、best-of-N 备份以及显式子任务条件的重要性。
Limitations（局限）
  • SeeQ 依赖训练时的子任务标注，而将操作轨迹分解为离散片段可能具有歧义，尤其在恢复行为或子任务边界附近。
  • 加入过去帧和更细粒度标注可能部分缓解歧义，但合适的子任务粒度仍依赖任务。
  • 部署时子任务预测错误会导致 critic 用错误目标评估动作。
  • 优化当前子任务价值偏向局部进展，可能与整体任务目标不一致。
与你的研究关系
该工作直接位于具身智能与机器人学习交叉处：以视觉语言模型为骨干学习通用价值函数，服务于长时序操作中的可执行动作选择与策略引导（best-of-N），与 VLA/世界动作模型中的动作评估、长时序预测和真实机器人评测高度相关；其子任务分解与 TD 学习思路对推理效率与实时控制中的候选动作排序也有迁移价值。
证据与不确定性

输入材料为节选，方法细节、网络结构、训练超参、四个任务的具体定义与逐任务数字、消融的完整设置等未完整给出；实验数字仅来自摘要与结论中的汇总，未提供逐任务表格，因此对方法可复现细节和结论普适性的判断存在不确定性。

SeeQ 只对当前活跃子任务学习 Q 值，以缩短价值预测时域。：We introduce SeeQ (Subtask-elicited Q-functions), which instead learns Q-values for the currently active subtask. This shortens the value-prediction horizon and enables effective learning with temporal-difference (TD) objectives.
Q 函数架构自回归地先预测自然语言子任务再估计其价值，从而无需测试时人工标注或模块化子任务预测系统。：To eliminate the need for human annotations or modular subtask prediction systems at test time, our Q-function architecture is trained to autoregressively predict the active subtask in natural language before estimating its value.
SeeQ 用视觉语言骨干在多样开源机器人操作数据上预训练，再在下游任务微调。：We instantiate SeeQ using a base vision-language backbone, pretrain it on diverse open-source robot manipulation data, and finetune it on downstream tasks.
在两个双臂机器人平台的四个真实世界操作任务上，SeeQ 显著改善 best-of-N 策略引导。：Across four real-world manipulation tasks on two bimanual robot platforms, the SeeQ value function substantially improves best-of-N policy steering.
SeeQ 将平均成功率从 35.4% 提升到 66.7%（1.88 倍）。：SeeQ raises the average success rate from 35.4% to 66.7% ( 1.88 × 1.88\times ), with improvements on various data compositions.
