SeeQ: Training Generalist Value Functions for Long-Horizon Robotic Manipulation

Figure 1 SeeQ overview. We train a generalist Q-value function on diverse robot data using a pretrained vision-language model (VLM) backbone. The value function is then fine-tuned on a downstream task and used to steer a base policy at test time. To address the challenges of long-horizon value learning, we use temporal-difference (TD) learning to fit the Q-value of the currently active subtask rather than that of the entire task. To eliminate the need for humans to specify this subtask at deployment, we modify the Q-function architecture to first predict the active subtask in natural language and then predict its value, encouraging internal representations better aligned with subtask-level value estimation.

核心洞察

与其学习整个任务的价值，不如只为当前激活的子任务学习 Q 值；这缩短了价值预测视野，使时序差分目标有效，同时可利用离线数据中已有的子任务标注，并在测试时由模型自回归预测当前子任务以避免人工标注或模块化子任务预测系统。

为什么值得看：它为长时序机器人操作中的信用分配与价值学习提供了一种可迁移思路：将任务级价值学习降为子任务级价值学习，并用视觉语言模型自回归预测当前子任务以消除测试期人工标注。对研究可执行动作生成、策略引导、视觉语言动作模型和真实机器人长时序评测的研究者具有参考价值。

Setting（研究设定）
在离线机器人数据上学习通用价值函数，用于长时序、多阶段或需反复尝试的机器人操作任务；测试阶段在真实双臂机器人平台上进行策略引导。
Motivation（研究动机）
通用机器人策略在复杂长时序任务上仍然脆弱；稀疏的任务级奖励导致信用分配视野过长、Bellman 备份困难且数据覆盖要求高，因此直接学习任务级 Q 值函数效果受限。
Insight（核心洞察）
与其学习整个任务的价值，不如只为当前激活的子任务学习 Q 值；这缩短了价值预测视野，使时序差分目标有效，同时可利用离线数据中已有的子任务标注，并在测试时由模型自回归预测当前子任务以避免人工标注或模块化子任务预测系统。
Challenge（技术挑战）
  • 长时序任务中稀疏任务级奖励带来的长信用分配视野
  • 困难的价值函数 Bellman 备份
  • 广泛的数据覆盖要求
  • 测试阶段避免依赖人工子任务标注或额外模块化子任务预测系统
  • 在真实双臂机器人长时序任务上稳定改善策略
Analyze（问题分析）
摘要指出任务级 Q 值学习因稀疏奖励导致信用分配视野长、Bellman 备份困难且数据覆盖要求高；作者据此主张改为对当前激活子任务学习 Q 值以缩短预测视野，并利用离线数据中的子任务级标注进行分解学习。材料未提供更详细的理论或实证分析。
Method（方法）
  • 提出 SeeQ（Subtask-elicited Q-functions），为当前激活子任务学习 Q 值而非直接学习任务级 Q 值
  • 利用离线机器人数据中存在的子任务级标注提供任务分解，从而可从不完美的大规模机器人数据中学习
  • 采用时序差分（TD）目标学习子任务价值函数
  • Q 函数架构基于视觉语言骨干，训练时先以自然语言自回归预测当前激活子任务，再估计其价值
  • 在多样化开源机器人操作数据上预训练，再在下游任务上微调
Experiments（实验）
  • 在两种双臂机器人平台的四个真实世界操作任务上评估
  • SeeQ 价值函数显著改善了 best-of-N 策略引导

通用机器人策略在复杂长时序任务上仍然脆弱：Despite rapid progress, generalist robot policies remain brittle on complex, long-horizon tasks that comprise multiple stages or require repeated attempts and deliberation on the same underlying stage before success.
任务级 Q 值学习面临长信用分配视野、Bellman 备份困难和数据覆盖要求高的问题：learning from sparse task-level rewards entails long credit-assignment horizons, difficult Bellman backups, and broad data-coverage requirements
SeeQ 为当前激活子任务学习 Q 值，从而缩短价值预测视野并支持 TD 学习：We introduce SeeQ (Subtask-elicited Q-functions), which instead learns Q-values for the currently active subtask. This shortens the value-prediction horizon and enables effective learning with temporal-difference (TD) objectives.
训练时利用离线机器人数据中的子任务级标注进行分解学习：During training, subtask-level annotations present in offline robot data provide the decomposition and enable learning from broad, potentially suboptimal robot datasets.
测试时模型自回归预测自然语言子任务再估计其价值，无需人工标注或模块化子任务预测系统：To eliminate the need for human annotations or modular subtask prediction systems at test time, our Q-function architecture is trained to autoregressively predict the active subtask in natural language before estimating its value.
方法基于视觉语言骨干，先在开源机器人操作数据上预训练，再在下游任务上微调：We instantiate SeeQ using a base vision-language backbone, pretrain it on diverse open-source robot manipulation data, and finetune it on downstream tasks.
在两种双臂机器人平台的四项真实世界操作任务上显著改善 best-of-N 策略引导：Across four real-world manipulation tasks on two bimanual robot platforms, the SeeQ value function substantially improves best-of-N policy steering.
