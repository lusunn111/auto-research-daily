Figure 1 Test time memory (T²Mem): learning to remember for memory-dependent robot manipulation. (a) Tasks such as recalling hidden objects, counting repeated actions, and reproducing action sequences require information beyond the current observation. (b) T²Mem integrates fast-weight memory into a single VLA policy through an observation-grounded interface, making vision–language history information available to the action expert. Alternating memory–policy learning develops the ability to retain and use history, without external model calls or memory-specific annotations. (c) During a rollout, the policy uses test-time training (TTT) to encode observation history in fast weights through self-supervised updates. It retrieves this information to guide actions when relevant evidence is no longer visible.

Setting（研究设定）
面向依赖历史信息的机器人操作任务；在一个预训练视觉语言动作策略内部开发记忆能力，不使用外部推理模型或记忆专用标注，仅依赖动作示范。
Motivation（研究动机）
依赖记忆的机器人操作需要策略利用当前观测已不可得的信息；仅保留历史不够，记忆必须保留并利用支持未来动作的信息。核心问题是：无记忆的基础模型能否仅从动作示范中学会保留和使用历史信息。
Insight（核心洞察）
通过测试时训练将观测历史编码为紧凑的快权重，可避免重复处理完整历史；由动作监督塑造记忆应保留和使用的内容，同时交替优化记忆与策略组件。
Challenge（技术挑战）
  • 无外部记忆支持和记忆专用标注条件下学习记忆
  • 记忆需保留对未来动作有用的信息而非全部历史
  • 避免重复处理完整历史以提升推理效率
  • 在交替优化中为每个组件提供固定对照
Analyze（问题分析）
摘要说明其聚焦于无记忆基础模型能否仅从动作示范中学习记忆能力，并通过与无记忆基础策略及基准中循环记忆方法的对比来分析有效性；更详细的问题分析材料未说明。
Method（方法）
  • 在预训练视觉语言动作策略内部开发记忆能力，不依赖外部推理模型或记忆专用标注
  • 使用测试时训练，通过在线自监督更新将观测历史编码为紧凑快权重，避免重复处理完整历史
  • 使用观测接地的接口提取视觉语言信息用于记忆形成，并向动作专家提供检索到的上下文
  • 利用动作监督塑造记忆学习保留和使用的内容
  • 采用交替记忆-策略学习，使每个组件在优化期间有固定对照
Experiments（实验）
  • 在16个RoboMME任务上，T²Mem将平均成功率从无记忆基础策略的17.93%提升至56.83%，并优于基准中报告的循环记忆方法
  • 受控性能分析表明，相比显式方法至少有3倍推理加速
Limitations（局限）
  • 材料未说明
与你的研究关系
该工作直接面向具身智能中的视觉语言动作模型，通过测试时训练与快权重实现记忆增强，兼顾长时序历史利用与推理效率，属于可执行动作生成、长时序预测和实时控制方向的交叉研究，与系统优化中的推理加速也有明确关联。
