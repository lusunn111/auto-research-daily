Given a stereo image pair, it constructs four orthogonal views of the scene with metric 3D coordinates. Setting（研究设定）
在预训练的二维视觉-语言-动作模型（π0.5 与 SmolVLA）上增加一个立体模块 ExStereo，利用立体图像对和预训练冻结的立体基础模型重建场景几何，并渲染多视角观测作为显式立体表征，通过动作-立体交叉注意力将立体 token 注入动作专家。评估在 RoboTwin 双臂 PiPER 仿真基准及真实世界双臂 PiPER 平台上进行。
Motivation（研究动机）
多数视觉-语言-动作模型仅依赖单目 RGB 观测，而单目 RGB 恢复度量深度和精确三维物体位置本质上是病态问题，难以满足高精度机器人操作对空间关系和遮挡鲁棒性的需求；已有三维注入方法依赖 RGB-D 传感器，存在标定和噪声敏感问题。
Insight（核心洞察）
显式立体表征（而非隐式立体特征）与动作专家的选择性交叉注意力结合，可以在不重新预训练基座策略的情况下，有效为任意二维视觉-语言-动作模型赋予度量三维感知。
Challenge（技术挑战）
  • 单目 RGB 恢复度量深度和精确三维物体位置本质上是病态问题
  • RGB-D 传感器依赖精确标定，对传感器噪声和点云伪影敏感，且在透明、反射表面性能下降
  • 现有隐式立体方法或需从头训练视觉-语言-动作模型，或对预训练模型仅带来有限提升
  • 在预训练后引入新模块时，如何让其有效适配策略学习
Analyze（问题分析）
作者指出多数视觉-语言-动作模型仅使用单目 RGB 观测，缺乏精确深度和几何信息；已有三维注入方法依赖 RGB-D 传感器存在标定和噪声问题；而 StereoVLA 需从头训练、StereoPolicy 仅提供有限提升。因此提出使用显式立体表征来为预训练二维视觉-语言-动作模型赋予度量三维感知，并通过仿真和真实世界实验验证。
Method（方法）
  • ExStereo 是一个立体模块，利用预训练、冻结的立体基础模型从立体图像对预测视差图，结合相机内参和基线转换为度量深度图与三维点云。
  • 将三维点云从四个正交视角（Top、Front、Left、Right）渲染为多视角观测，作为显式立体表征用于立体特征提取。
  • 提出动作-立体交叉注意力机制，使动作专家的动作 token 选择性地关注立体 token，从而基于三维场景信息生成机器人动作；该机制不修改视觉-语言模型前缀 token 或权重，因此与骨干无关。
  • 采用两阶段训练：中间训练和后续训练。中间训练在任务特定后训练之前，在大规模立体数据上使用自监督掩码自编码目标学习鲁棒三维表征；后训练使用任务演示进行适配，此时 MAE 目标不使用且 MAE 解码器被丢弃，保持 ExStereo 冻结。
  • 中间训练数据由 StereoEngine 生成，可将已有单目演示提升为立体对或直接生成立体视图。
Experiments（实验）
  • 在开源 RoboTwin 双臂操作基准上选取十个代表性任务进行仿真评估，平均时间步数为 147。
  • 仿真基线包括 ACT、DP3、π0.5、SmolVLA 和 StereoVLA。
  • 在真实世界双臂 PiPER 平台上进行评估。
  • 在两个设定中，使用 ExStereo 微调的视觉-语言-动作模型持续优于基线，表明立体感知对机器人操作的有效性。
  • 作者称显式立体表征在直接微调时比标准隐式立体几何方法更有效。
Limitations（局限）
  • 渲染的多视角在遮挡区域会出现空洞，因为点云中这些区域缺失。
  • 多视角渲染假设平面表面（如桌面）来定义世界坐标系，在杂乱或非桌面场景中可能不成立。
  • 中间训练数据来自单一基准和单一双臂本体，扩展到更大的立体机器人数据集和更多样化的本体是未来重要方向。
