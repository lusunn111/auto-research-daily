GAWM：面向多任务机器人操作的紧凑潜在世界动作模型

GAWM: A Compact Latent World-Action Model for Multi-Task Robot Manipulation

Yang Liu · Xiaoli Liu · Liuzhao Li · Yuduo Song · Muyuan Liu · Xiang Gao

核心洞察

在封闭任务集上，一个少于 1 亿参数、无机器人或视频预训练的任务条件化潜在预测器，即可为反应式策略提供现有 WAM 从十亿参数骨干中获得的前瞻能力；关键在于在冻结编码器的潜在空间中预测未来 token 并以稠密 patch 特征监督，而非生成未来视频帧。

为什么值得看：为世界动作模型提供了一条紧凑、低延迟、无需大骨干的替代路线，并给出参数—成功率、延迟与真实机器人闭环证据；其消融表明世界模型在数据或训练时间受限时收益显著，对关注世界模型效率、模型压缩与实时机器人部署的研究者具有直接参考价值。

Setting（研究设定）
在封闭任务集上的多任务模仿学习：策略由任务码而非语言指令条件化，在冻结的DINOv3编码器潜在空间中预测未来观测，并直接从当前与预测 token 回归动作块；在 LIBERO、RoboTwin 2.0 仿真基准与双臂真实机器人上评测。
Motivation（研究动机）
现有世界动作模型多建立在十亿参数级视觉语言或视频生成骨干上，训练成本高、推理延迟大（如 LingBot-VA 每次查询 4.5 s），难以部署到机载计算机；而许多实际部署机器人只执行固定任务集，更看重可靠、低延迟执行，因此需要紧凑的多任务 WAM。
Insight（核心洞察）
在封闭任务集上，一个少于 1 亿参数、无机器人或视频预训练的任务条件化潜在预测器，即可为反应式策略提供现有 WAM 从十亿参数骨干中获得的前瞻能力；关键在于在冻结编码器的潜在空间中预测未来 token 并以稠密 patch 特征监督，而非生成未来视频帧。
Challenge（技术挑战）
  • 十亿参数级 WAM/VLA 训练成本高、推理延迟大，难以机载部署
  • 视频生成式 WAM 将大量容量耗费在与控制无关的外观细节上，且需迭代去噪
  • 紧凑模型需在不依赖大规模预训练的情况下同时保证多任务成功率与低延迟
  • 潜在预测需编码未来场景空间布局，才能有效支撑动作解码
  • 真实双臂平台上动作预测精度与推理实时性的平衡
Analyze（问题分析）
作者将现有 WAM 归纳为依赖 5B 参数 Wan 2.2 视频生成器或 2.1B 参数 VLA 骨干，指出其成本与延迟问题，并以模型规模—成功率对比图（图1）说明紧凑方法在固定任务集上的可行性；通过消融量化世界模型贡献，并用 per-patch 余弦相似度与动作解码器跨注意力分析预测内容与使用时序。
Method（方法）
  • 冻结 DINOv3 编码器加查询适配器，将每个相机视角压缩为 64 个视觉 token 并堆叠为 z_t
  • 轻量潜在预测器以任务码 g_k（而非动作）为条件，预测两个未来时间视野的 token
  • 训练时用未来帧的稠密 patch 特征经 patch 解码器监督预测，要求其编码未来场景空间布局
  • 动作解码器从当前 token、预测 token、机器人状态与任务码直接回归一段未来动作块
  • 总参数少于 100M，且不使用机器人或视频预训练
Experiments（实验）
  • RoboTwin 2.0：GAWM-S 在干净与随机化设置下成功率分别为 93.9% 与 93.1%，优于十亿参数 WAM；在图中为最小且表现最好的方法
  • LIBERO：GAWM-S 以 38M 参数达到 95.6%，高于 3.2B 参数的 π0（使用 Extended 数据）
  • 真实双臂机器人（天机 Marvin Pro，每臂 7 自由度，头相机加两个腕相机，四任务仅目标瓶不同，340 条遥操作示教，15 Hz）：在留出示教上动作预测误差低于微调的十亿参数 VLA，推理延迟显著更低；全动作块误差 0.088 rad（16 步），低于 π0.5 的 0.101–0.106 rad（20 步）；黄瓶任务 50 次闭环试验成功 46 次（92%），π0.5（60k）为 39 次（78%）；GAWM-S 77M 参数每次查询 9.3 ms，π0.5 为 3.4B 参数 63.8 ms
  • 消融：世界模型在训练数据或训练时间受限时带来大幅性能提升
  • 预测分析：解码预测与真实未来特征的 per-patch 余弦相似度在 +16 帧为 0.970、+32 帧为 0.967，当前帧为 0.929 与 0.892；预测在 75% 与 91% 的锚点上更接近真实未来
  • 注意力分析：动作块首步主要关注当前 token，h1 附近步骤关注近端预测，末步远端预测占比从首步 20% 升至 44%，且对每个锚点成立
Limitations（局限）
  • GAWM 面向封闭任务集，每个任务由来自其示教的码标识，不解释语言指令；作者计划结合大语言模型将开放指令映射到已知任务
与你的研究关系
直接对应世界动作模型（WAM）与物理人工智能方向：以 JEPA 式潜在世界模型替代视频生成骨干，兼顾长时序潜在预测（两个未来视野）与推理效率、模型压缩（<100M 参数）和真实机器人实时控制（9.3 ms/查询），并给出真实双臂机器人闭环评测，与可执行动作生成、实时控制与真实机器人评测的研究重点高度重合。

GAWM 在冻结 DINOv3 编码器潜在空间中预测未来观测，并以任务而非动作作为预测器条件：GAWM (Geometry-Aware World Model), a compact multi-task WAM that predicts future observations in the latent space of a frozen DINOv3 encoder.
