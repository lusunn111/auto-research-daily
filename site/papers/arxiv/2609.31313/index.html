Towards VLA-Dreamer: Refining VLA Behavior Using World Models

Parsa Mastouri Kashani · Jan-Gerrit Habekost · Stefan Wermter

核心洞察

VLA 视觉编码器产生的嵌入可能是动作相关的，可作为世界模型的潜在空间，从而让同一编码器支撑动作生成、未来预测与目标指定；若嵌入能够基于动作预测未来，则说明 VLA 隐含可用的世界模型，反之则暴露当前架构缺乏非有损隐式世界模型的关键局限。

为什么值得看：该文提出在 VLA 冻结语言对齐视觉编码器嵌入空间上训练世界模型并用于 RL 精炼，直接触及 VLA 样本效率与隐式世界模型能力这一核心问题，且提供可检验的假设（嵌入是否动作相关且可预测未来），对关注世界模型、VLA 行为精炼与样本效率的研究者有明确参考价值。

Setting（研究设定）
概念论文，提出在 VLA 冻结的、语言对齐的视觉编码器嵌入空间上训练预测世界模型，并在此世界模型内用强化学习精炼微调后的 VLA，用于机器人控制（NICOL 机器人模仿学习数据）。
Motivation（研究动机）
VLA 虽然展现出机器人控制潜力，但需要大量高质量模仿学习数据，且缺乏显式世界模型，使其控制能力受到质疑。V-JEPA 2-AC 等方法虽在嵌入空间预测，但依赖昂贵的 MPC 规划且需要目标图像或子目标帧，限制可用性和任务时域；而轻量 MLP 策略缺乏语言条件所需的语义先验且奖励设计困难。
Insight（核心洞察）
VLA 视觉编码器产生的嵌入可能是动作相关的，可作为世界模型的潜在空间，从而让同一编码器支撑动作生成、未来预测与目标指定；若嵌入能够基于动作预测未来，则说明 VLA 隐含可用的世界模型，反之则暴露当前架构缺乏非有损隐式世界模型的关键局限。
Challenge（技术挑战）
  • VLA 视觉编码器嵌入是否足够丰富且可预测，能作为世界模型的潜在空间
  • 嵌入预测误差与探针保真度如何随想象时域增长，量化想象的未来是否保持几何一致以支持规划与 RL
  • 避免世界模型嵌入与 VLA 视觉编码器之间的错位
  • 在 RL 微调中避免丢失语义知识
  • VLA 依赖大量高质量模仿学习数据，样本效率低
Analyze（问题分析）
作者通过概念性论证分析问题：指出像素空间生成式世界模型迫使模型“在像素中思考”并关注不必要细节；V-JEPA 2-AC 虽在嵌入空间工作但依赖昂贵 MPC 与目标图像；轻量 RL 策略缺乏语言条件语义先验且奖励设计困难。据此提出在 VLA 冻结的语言对齐视觉编码器嵌入空间上训练世界模型，并通过探针和嵌入预测误差评估嵌入丰富性。
Method（方法）
  • 选择 π0-FAST 与 OpenVLA 作为 VLA，因其基于 token 概率而非扩散或流匹配，便于构建更简单的 RL 流程，且 OpenVLA 使用 DINOv2 与 SigLIP 融合的视觉编码器。
  • 在 NICOL 机器人的模仿学习数据集（含语言指令、遥操作数据、本体感知关节位置与各时间步相机帧）上微调预训练 VLA。
  • 冻结视觉编码器以避免世界模型嵌入与 VLA 视觉编码器之间的错位，并应用强正则化以避免丢失语义知识。
  • 在 VLA 冻结的语言对齐视觉编码器嵌入空间上训练预测世界模型，损失来自嵌入空间而非像素空间，类似联合嵌入预测架构。
  • 利用训练好的世界模型通过采样给定目标图像下的 VLA 动作进行短期规划，并在该世界模型内用 RL 精炼微调后的 VLA。
Experiments（实验）
  • 论文为概念论文，全文节选未提供已完成的实验数字与结果。
  • 作者计划训练世界模型与探针，测量随着想象时域增长时的嵌入预测误差与探针保真度，以量化想象的未来是否在几何上足够一致以支持规划与 RL。
  • 计划研究 VLA 视觉嵌入的丰富性，并通过世界模型降低其高数据需求，同时在推理时生成计划。
Limitations（局限）
