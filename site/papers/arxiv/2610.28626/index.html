Figure 1 (a) UniWALM is a unified World Action Language Model that extends a single video-model backbone to act and reason by co-generating video, action, and language through one shared diffusion process — no separate language model fused onto a world-action model. This supports (b) single and (c) bimanual dexterous manipulation with (d) multi-stage manipulation and (e) memory-dependent reasoning . Prior work (f) composes a VLM with a VLA and a video model in pipeline or parallel; UniWALM (g) tunes a single unified representation end-to-end. Each manipulation example displays the input task instruction at the bottom and the generated video, action, and subtask at the top. In (e) the predicted subtask and textual memory (shown as ‘ subtask || memory ’) are re-consumed as the next-step prompt.

Rahul Sajnani · Diego Romeres · Mingyuan Zhang · Kai Gao · Carl Qi · Baichuan Huang · Srinath Sridhar · Dylan Randle · Lillian J. Ratliff · Jose Barreiros · Manikantan Nambi · Jeroen Vanbaar

核心洞察

把语言生成内嵌进世界-动作骨干，以同一前向过程同时解出子任务与文本记忆，并将生成的语言在下一步重新消费，形成无需外部规划器或记忆库的“语言即记忆”闭环。

为什么值得看：提供统一多模态骨干与语言即记忆闭环的清晰设计，附组合操作、记忆任务与真实机器人多层级证据，且无需外部规划器或预训练语言模型，对世界动作模型架构与长时序记忆研究有直接参考价值。

Setting（研究设定）
在单一共享表示中联合学习视频、动作与语言，每类模态既作为条件信号又作为监督目标；面向组合式操作与依赖记忆的机器人任务。
Motivation（研究动机）
受人类整合语言、感知与动作经验的启发，探索联合生成语言能否丰富共享表示、改善操作并支撑依赖记忆的行为。
Insight（核心洞察）
把语言生成内嵌进世界-动作骨干，以同一前向过程同时解出子任务与文本记忆，并将生成的语言在下一步重新消费，形成无需外部规划器或记忆库的“语言即记忆”闭环。
Challenge（技术挑战）
  • 三类模态在同一骨干中同步去噪与解码
  • 丰富目标下保持动作流可靠
  • 无需外部规划或记忆模块即可支撑长时序记忆行为
  • 在无预训练语言或推理模型的条件下取得强表现
Analyze（问题分析）
材料未说明作者如何具体分析问题；摘要仅提出问题并对比分阶段式先验方法。
Method（方法）
  • 构建单一 mixture-of-transformers 骨干，各模态扩散头同步协同去噪
  • 同一遍解码子任务与文本记忆及动作，不设独立规划阶段
  • 生成语言在下一步重新输入，闭合语言即记忆回路
  • 提出 Flow Matching with Correction（FMC），训练时学习从受扰动动作轨迹恢复，且无推理时开销
Experiments（实验）
  • 与同骨干基线（如 FastWAM）对比，在 MolmoSpaces 组合式拾放任务上持续提升
  • RMBench 依赖记忆子集达到 34.5%，无任何预训练语言或推理模型
  • 仅用单张锚点帧超过 Mem-0 配关键帧的设置（28.5%）
  • 真实世界 Find-the-Item 任务中生成文本记忆将成功率从 11.1% 提升到 61.1%
  • 同一真实任务中先进 VLA 方法处于或低于随机水平（≤33.3%）
Limitations（局限）
  • 材料未说明
与你的研究关系
直接关联具身智能与世界动作模型：把世界预测、动作生成与语言推理统一进单骨干，并以语言作为记忆支持长时序行为，同时 FMC 在不增加推理成本下提升动作可靠性，契合可执行动作生成与实时控制关注点。
证据与不确定性

仅有标题与摘要，缺少骨干规模、训练数据、推理效率、消融细节与失败案例分析；相关性判断基于摘要所述统一世界-动作-语言框架。

模型在单一共享表示中联合学习视频、动作与语言，每类模态既是条件也是监督目标：a unified world-action-language model that learns video, action, and language in a single shared representation, where each modality is both a conditioning signal and a supervision target
语言生成与动作在同一遍解码，生成语言在下一步被重新消费，无需外部规划器或记忆库：the generated language is re-consumed on the next step, closing a language-as-memory loop without an external planner or memory bank
FMC 训练目标使动作流从扰动轨迹中恢复且不增加推理成本：Flow Matching with Correction (FMC), a training objective that teaches recovery from perturbed action trajectories at no inference-time cost
RMBench 记忆子集达 34.5%，超过 Mem-0 的 28.5%：it reaches 34.5% without any pretrained language or reasoning model and exceeds Mem-0's keyframe-equipped setup (28.5%) using only a single anchor frame
真实 Find-the-Item 任务中生成文本记忆将成功率从 11.1% 提升到 61.1%：generating textual memory lifts success from 11.1% to 61.1%, while state-of-the-art VLAs stay at or below chance (<=33.3%)
