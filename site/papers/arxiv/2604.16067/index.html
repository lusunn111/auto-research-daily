Setting（研究设定）
在预训练视觉-语言模型上微调用于机器人操作的连续流匹配动作专家，同时保持预训练的视觉问答能力
Motivation（研究动机）
为机器人操作微调预训练VLM时存在稳定性-可塑性困境：连续流匹配动作专家将集中的低秩回归梯度反传到基于高维交叉熵目标训练的transformer骨干网络，这种跨模态梯度不对称会迅速破坏预训练的视觉推理能力
Insight（核心洞察）
任务梯度与预训练表示保持方向性冲突时，可将任务梯度投影到锚点恢复向量的正交补空间，从而在保持连续梯度流的同时隔离预训练表示
Challenge（技术挑战）
  • 连续流匹配梯度与离散交叉熵预训练目标之间的跨模态梯度不对称
  • 现有stop-gradient方案切断连续梯度流
  • LoRA限制更新秩但对语义破坏方向不敏感
  • 混合批次VQA联合训练使训练计算量翻倍
Analyze（问题分析）
作者将问题分析为跨模态梯度不对称导致的稳定性-可塑性困境，指出stop-gradient、LoRA和混合批次联合训练各自的不足，并基于逐层高斯激活统计和Wasserstein-2传输建立正交投影的理论能量保持界限
Method（方法）
  • AEGIS是一种无缓冲、逐层正交梯度投影框架
  • 训练前从预训练数据估计逐层高斯激活统计作为静态参考锚点
  • 微调时通过闭式Wasserstein-2传输惩罚通过活跃计算图生成锚点恢复梯度
  • 顺序双反向传播应用逐层Gram-Schmidt正交化
  • 在方向冲突时将任务梯度投影到恢复向量的正交补空间
Experiments（实验）
  • 建立了逐层正交投影的精确能量保持界限，实证显示AEGIS仅舍弃0.62%的梯度能量同时阻止累积特征漂移
  • 在LIBERO操作基准上微调PaliGemma2-3B，AEGIS完全保持预训练视觉问答性能和基线留出损失，同时匹配连续动作收敛
  • 无需回放缓冲区、教师模型或联合训练数据
Limitations（局限）

为机器人操作微调预训练VLM时存在稳定性-可塑性困境，连续流匹配动作专家的梯度会破坏预训练视觉推理：Fine-tuning pre-trained Vision-Language Models (VLMs) for robotic manipulation introduces a fundamental stability-plasticity dilemma: continuous flow-matching action experts backpropagate concentrated, low-rank regression gradients into transformer backbones trained on high-dimensional cross-entropy objectives.
现有stop-gradient、LoRA和混合批次VQA联合训练方案各有不足：Existing solutions either disconnect continuous gradient flow via stop-gradients or constrain updates via LoRA, which restricts update rank but remains directionally blind to semantic corruption; both typically rely on mixed-batch VQA co-training, doubling training compute.
AEGIS是一种无缓冲、逐层正交梯度投影框架，可连续微调同时隔离预训练表示：We introduce AEGIS (Anchor-Enforced Gradient Isolation System), a buffer-free, layer-wise orthogonal gradient projection framework enabling continuous flow-matching fine-tuning while isolating pre-trained representations from destructive parameter updates.
AEGIS仅舍弃0.62%的梯度能量同时阻止累积特征漂移：showing that AEGIS sheds only 0.62% of gradient energy empirically while halting cumulative feature drift
在LIBERO基准上微调PaliGemma2-3B，AEGIS完全保持预训练视觉问答性能同时匹配连续动作收敛：On PaliGemma2-3B fine-tuned on the LIBERO manipulation benchmark, AEGIS fully preserves pre-trained Visual Question Answering performance and baseline holdout loss while matching continuous action convergence
