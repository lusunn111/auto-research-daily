Setting（研究设定）
在视觉-语言-动作（VLA）策略上，通过动作条件路由动态选择 VLM 各层表征混合与复用中间动作状态，用于机器人操作任务的仿真与真实基准评测。
Motivation（研究动机）
VLM 提供的层级视觉-语义表征从局部视觉几何到抽象语言对齐语义逐层演化，不同操作任务可能需要不同层表征组合；同时动作模块的中间表征在动作计算中演化，可能对后续决策有用。但现有 VLA 接口灵活性有限：VLM 信息以固定层分配暴露给每个动作层，动作中间状态仅通过残差流隐式传播而无显式复用。
Insight（核心洞察）
通过动作条件自适应路由，可以动态形成缓存 VLM 表征的混合，并显式复读早期动作表征，从而在极小参数开销下提升 VLA 策略性能。
Challenge（技术挑战）
  • 现有 VLA 接口对 VLM 层表征访问为固定层分配，缺乏灵活性
  • 动作中间状态仅通过残差流隐式传播，未显式复用
  • 不同操作任务可能依赖不同层表征组合，需要自适应选择机制
Analyze（问题分析）
材料未说明作者对问题的具体分析方式；摘要仅指出固定层分配和隐式传播的局限，并说明路由分析揭示了跨动作层与任务设置的结构化分配模式。
Method（方法）
  • 提出 LayerRoute，一种动作条件的表征路由接口，支持自适应访问 VLM 层与动作表征
  • Layer Mixture Router：动态形成缓存的 VLM 表征混合
  • Action-State Reread：复用较早的动作表征
Experiments（实验）
  • 在多种仿真与真实世界基准上，LayerRoute 持续提升 StarVLA-π 与 π0.5
  • 在 LIBERO Long 上取得最高 7.2 的提升
  • 仅增加 0.31% / 3.87% 额外参数
  • 消融研究验证了动作条件层级路由的好处
  • 路由分析揭示了跨动作层与任务设置的结构化分配模式

现有 VLA 接口对 VLM 信息暴露为固定层分配，动作中间状态仅隐式传播：existing VLA interfaces offer limited flexibility in representation access: VLM information is exposed through fixed layer assignments for each action layer, while intermediate action states are only propagated implicitly through residual streams without explicit reuse.
提出 LayerRoute 动作条件表征路由接口，包含 Layer Mixture Router 与 Action-State Reread：We introduce LayerRoute, an action-conditioned representation routing interface that enables adaptive access to VLM layers and action representations. The Layer Mixture Router dynamically forms mixtures of cached VLM representations, while Action-State Reread reuses earlier action representations.
在多种仿真与真实基准上持续提升 StarVLA-π 与 π0.5，LIBERO Long 上最高提升 7.2，仅增加 0.31% / 3.87% 额外参数：Across diverse simulation and real-world benchmarks, LayerRoute consistently improves StarVLA-$\pi$ and $\pi_{0.5}$, achieving up to 7.2 gains on LIBERO Long with only 0.31% / 3.87% additional parameters.
消融验证动作条件层级路由收益，路由分析显示结构化分配模式：Ablation studies validate the benefit of action-conditioned layer routing, while routing analyses reveal structured allocation patterns across action layers and task settings.
