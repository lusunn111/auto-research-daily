Setting（研究设定）
具身导航任务（R2R-CE），使用低层SLAM控制器，训练数据为90k条轨迹
Motivation（研究动机）
现有方法将VLM直接部署于具身导航时，常迫使模型进入与其2D预训练先验不匹配的动作空间，推理调度僵化且记忆管理低效，导致部署困难。
Insight（核心洞察）
通过将导航动作重构为2D像素选择并投影至3D，能够自然对齐VLM的2D视觉能力；结合动态推理与关键节点记忆压缩，可在保持性能的同时提升效率。
Challenge（技术挑战）
  • VLM动作空间与具身执行不匹配
  • 推理调度固定导致效率低
  • 长时导航历史记忆管理低效
Analyze（问题分析）
作者分析问题在于动作空间错位、推理调度僵化、记忆冗余，因此设计统一框架分别应对。
Method（方法）
  • Pixel-to-3D动作公式化：VLM选择2D像素，投影至3D坐标供SLAM控制器执行
  • 选择性推理与锚点轨迹记忆：动态触发思维链，仅在关键节点保留高保真记忆，压缩冗余轨迹为轻量时空指示器
  • 两级对齐范式：通过GRPO叠加全局结果奖励和细粒度过程奖励，实现密集监督
Experiments（实验）
  • 在R2R-CE上达到66.2%的成功率（SR），仅需90k训练轨迹，展现出高运行时和样本效率
Limitations（局限）

TAMP-Nav通过像素到3D动作公式将导航重构为2D视觉提示，对齐VLM的2D能力：we introduce a Pixel-to-3D Action Formulation (Point) that reformulates navigation into 2D visual prompting. Specifically, the VLM merely selects 2D pixels, which are then projected into 3D coordinates for a low-level SLAM controller.
TAMP-Nav采用集成选择性推理与锚点轨迹记忆机制，压缩冗余轨迹为轻量指示器：we propose an integrated Selective Reasoning and Anchor-Trajectory Memory mechanism (Think and Memorize), which dynamically triggers Chain-of-Thought and retains high-fidelity memory only at critical nodes, compressing redundant trajectories into lightweight Space-Time Indicators
TAMP-Nav通过GRPO的两级对齐范式，叠加全局和过程奖励实现密集监督：we design an efficient Two-Level Alignment Paradigm (Align) via Group Relative Policy Optimization (GRPO). By superimposing global outcome rewards with fine-grained process rewards
TAMP-Nav在R2R-CE上达到66.2%成功率，仅需90k训练轨迹：TAMP-Nav achieves state-of-the-art performance (e.g., 66.2% SR on R2R-CE) with high runtime and sample efficiency (requiring only 90k training trajectories).
