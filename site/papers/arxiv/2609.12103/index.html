Setting（研究设定）
毫米级直径、配合间隙极小的细长杆插入任务；细长杆在操作中可能弯曲，杆尖位姿不再相对夹爪固定，因此传统刚性轴孔装配假设失效。方法包含粗接近与预测插入两个阶段，并可组合为端到端设计。
Motivation（研究动机）
传统轴孔装配方法假设刚性物体且杆尖相对夹爪位姿固定；对高长径比的细长杆，这一假设不成立，杆尖运动会受杆构型、抓取方式、材料属性与接触影响，因此需要能预测杆-孔对齐效果的学习框架。
Insight（核心洞察）
将细长杆插入分解为视觉伺服驱动的粗接近和基于预测的精细插入；在执行前用动作条件世界模型评估扩散策略生成的多条候选动作块对杆-孔对齐的影响，并根据预测的倾斜与径向误差选择最优动作块。
Challenge（技术挑战）
  • 细长杆易弯曲，杆尖位姿不固定，传统刚性假设失效
  • 毫米级直径与极小间隙要求高精度感知与控制
  • 杆尖运动依赖构型、抓取、材料与接触，建模复杂
  • 需要在执行前评估候选动作块的效果以降低失败风险
Analyze（问题分析）
材料未说明作者如何分析问题；摘要仅说明传统刚性轴孔装配假设在细长杆上失效，并据此提出两阶段分解与执行前预测评估。
Method（方法）
  • 两阶段分解：粗接近阶段使用视觉伺服将多样初始构型映射到紧凑的孔附近交接区域
  • 预测插入阶段进行精细对齐并完成插入
  • 两阶段可封装为端到端设计
  • 插入过程中扩散策略生成候选动作块
  • 动作条件世界模型预测候选动作块对杆-孔对齐的影响
  • 基于预测的倾斜和径向误差在执行前选择最佳动作块
Experiments（实验）
  • 实验考察不同阶段的性能以及端到端设置
  • 与扩散策略等基线方法相比，RodForesight 将成功率从 88.9% 提升到 96.7%

传统轴孔装配假设刚性物体且杆尖相对夹爪位姿固定，该假设对高长径比细长杆失效：Conventional peg-in-hole methods assume a rigid object whose tip pose is fixed relative to the gripper. This assumption breaks down for a high aspect ratio rod, which can bend during manipulation
方法将任务分解为粗接近与预测插入两个阶段，并可封装为端到端设计：factorises the task into two stages: 1) coarse approaching, which uses visual servoing to map diverse initial configurations into a compact near hole hand-off region; and 2) predictive insertion, which performs fine alignment and completes the insertion. It is worth noting that the two stages can be wrapped into an end-to-end design.
扩散策略生成候选动作块，动作条件世界模型预测其对杆-孔对齐的影响，并基于预测倾斜与径向误差执行前选择最佳动作块：During insertion, a diffusion policy generates candidate action chunks, while an action conditioned world model predicts their effects on rod-hole alignment. This pre-execution evaluation enables RodForesight to select the best action chunk based on predicted tilt and radial errors before execution.
与扩散策略等基线相比，RodForesight 将成功率从 88.9% 提升到 96.7%：RodForesight improves the success rate from 88.9% to 96.7%, compared to baseline methods such as diffusion policy.
