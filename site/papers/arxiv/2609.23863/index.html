锚定动作模型：以三维锚定作为机器人学的基础

Grounded Action Model: 3D Grounding as a Foundation for Robotics

Gehao Zhang · Weikai Huang · Shailesh Shailesh · Yiyan Peng · Jiafei Duan · Ranjay Krishna

核心洞察

物体定位与度量几何是可以（且应当）作为动作学习预训练基础的一种先验，它比语言语义或视频外观先验更直接地指向操作所需的任务相关物体及其三维位置与范围。

为什么值得看：对关注可执行动作生成、长时序操作与真实机器人评测的研究者而言，GAM 给出了一个明确且可复现的范式答案：预训练该学什么才能最好地支持泛化动作学习。其 55.3% 平均成功率、随机化下 47.6%、LIBERO-PRO 61% 以及真实机器人 17/20 与 4/20 的对比，提供了关于“显式度量锚定是否优于隐式学习”的强证据；同时其局限（锚定错误传播、物体中心过滤丢失上下文）为系统优化与失败恢复研究指出了具体切入点。

Setting（研究设定）
把语言、二维点或二维框提示经一个冻结的可提示三维锚定骨干（WildDet3D）解析为共享的以物体为中心的表示（物体视觉特征与度量三维几何），再与机器人状态历史通过多流 Transformer 混合，用流匹配预测关节位置动作块；既可作为自主策略运行，也可作为高层规划器的低层控制器。
Motivation（研究动机）
当前机器人基础模型所依赖的预训练骨干（VLA 的语言目标、WAM 的视频生成目标）并不直接要求显式的度量锚定，任务相关物体及其几何只能从有限的机器人演示中隐式学得，导致在有限环境与布局下学到的连接依赖视觉外观，难以应对任务相关物体的空间变化。
Insight（核心洞察）
物体定位与度量几何是可以（且应当）作为动作学习预训练基础的一种先验，它比语言语义或视频外观先验更直接地指向操作所需的任务相关物体及其三维位置与范围。
Challenge（技术挑战）
  • 语言生成目标可在不要求精确三维位置与范围的情况下识别物体并描述关系
  • 视频生成目标偏向与交互无关的外观、纹理与背景变化
  • 锚定错误会传播到动作且无法恢复
  • 以物体为中心的过滤会漏掉未选中的障碍物等上下文
Analyze（问题分析）
作者以“预训练骨干决定机器人基础模型在学会行动之前知道什么”为出发点，对比语言与视频预训练目标，指出二者的目标函数并不直接要求显式的度量锚定，因此动作学习器必须靠机器人演示把这些预训练表示接到空间精确的运动行为上，而当演示只覆盖有限环境与布局时，这种连接会依赖视觉变化。
Method（方法）
  • 用语言、二维点或二维框作为任务提示；语言输入由基于冻结 Flan-T5 编码器的 span-tagging 头抽取任务相关物体短语（如“pick up the sponge and place it in the bowl”得到 sponge 与 bowl），点与框输入直接指定物体。
  • 把查询送入可提示三维锚定骨干 WildDet3D，为每个被查询物体输出二维检测框与度量三维框，并从 RGB 图预测稠密度量深度图、暴露稠密特征。
  • 由这些输出构建以物体为中心的观测：限制在任务物体与机械臂上的图像 token、编码每个物点点云与位姿的检测 token、以及状态历史 token。
  • 用多流 Transformer（MM-DiT）以这些 token 为条件，并通过自适应层归一化注入语言嵌入，用流匹配预测一段关节位置目标。
  • 锚定骨干保持冻结；在 RoboTwin 2.0 上先仅用模拟器直接导出的二维框、三维框与深度（无需人工标注）单独微调骨干以适配渲染域，不涉及任何策略。
Experiments（实验）
  • RoboTwin 2.0：50 个任务平均成功率 55.3%（对比 Spatial Forcing 的 52.0%）；场景随机化下 47.6%（对比 Abot-M0 的 30.4%），且动作策略仅在干净场景演示上训练。
  • RoboTwin 2.0 分项：GAM Easy 62.96、Hard 47.62；Spatial Forcing Easy 77.20、Hard 26.70；π0.5† Easy 64.00、Hard 25.90；Abot-M0 Easy 57.40、Hard 30.40。
  • LIBERO-PRO：在 16 种扰动设置下取得 61% 的最优平均成功率（对比 π0.5 的 53%），在目标被重新安置或新指定时增益最大。
  • 真实机器人：双臂 YAM 上在视觉偏移下保持 17/20 成功（对比 π0.5 的 4/20）；与 Molmo2 规划器组合后在 Franka 上长时序与依赖记忆任务达到 64.7% ID 与 49.8% OOD 步骤完成率。
  • 消融问题设置包括：收益是否来自把观测限制到任务物体，以及策略是否同时需要物体外观与度量三维几何。
Limitations（局限）
  • GAM 依赖其锚定观测的质量与完整性：锚定错误会传播到动作且无法恢复。
  • 以物体为中心的过滤可能漏掉未选中的障碍物等相关上下文。
  • 所用三维包围框只是锚定的一种形式；作者提出稠密三维实例分割等替代可能提供更细粒度的几何监督。
  • 作者提出未来需要更多样化的三维锚定数据集与模型、锚定感知的失败恢复与自适应上下文选择。
与你的研究关系
该工作直接落在具身智能与机器人基础模型的核心议题上：它把可提示三维锚定作为动作学习的基础，用流匹配实时生成动作块并保证推理时骨干冻结，支持作为低层控制器接入高层规划器以完成长时序与依赖记忆的操作，并在两台真实机器人（YAM、Franka）上做视觉偏移与 OOD 评测；其“用物体级几何表示替代纯语言/视频先验”的思路对世界模型、物理人工智能与 WAM 的表示选择与真实机器人评测设计具有直接迁移价值。
