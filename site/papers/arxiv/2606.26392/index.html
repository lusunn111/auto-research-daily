MPC-Injection: Biasing Off-Policy Locomotion RL Toward Controller-Induced Behavior Basins

Roy Xing (Dartmouth College) · Seyoung Ree (Harvard University) · Brian Plancher (Dartmouth College)

核心洞察

通过注入由 MPC 在同环境中生成的转接来偏置离策略学习，可以无需重新设计奖励、无需判别器、无需运动学重定向和辅助目标项，就能将策略引导到纯 RL 在简单奖励下难以到达的行为区域。

为什么值得看：对于关注具身智能与真实机器人运动的读者，该工作提供了一种低开销的行为引导方法，不需要修改奖励或引入额外网络，且包含四足机器人 sim-to-real 验证，方法思路可迁移到其他需要从次优 RL 行为中恢复可部署策略的控制任务。

Setting（研究设定）
在相同的仿真环境中，将模型预测控制器（MPC）生成的转接（transition）注入到离策略强化学习训练中，以引导策略收敛到设计者偏好的行为模式。评估包括 2D walker 仿真和 Go2 四足机器人的 sim-to-real。
Motivation（研究动机）
运动强化学习常常收敛到局部最优但不可部署的行为，例如肢体振动或用躯干滑行，这些策略最大化回报但并不产生可用的步态。
Insight（核心洞察）
通过注入由 MPC 在同环境中生成的转接来偏置离策略学习，可以无需重新设计奖励、无需判别器、无需运动学重定向和辅助目标项，就能将策略引导到纯 RL 在简单奖励下难以到达的行为区域。
Challenge（技术挑战）
  • 如何在离策略强化学习中注入 MPC 转接而不引入额外判别器或辅助损失
  • 奖励塑造需要重新设计任务奖励且可能引入偏差
  • 对抗模仿学习需要判别器与运动学重定向，流程复杂
  • 纯 RL 在简单奖励函数下难以到达设计者期望的行为盆地
  • sim-to-real 迁移中保持步态质量
Analyze（问题分析）
摘要说明作者分析了注入转接如何偏置学习过程，使策略收敛到纯 RL 在简单奖励函数下可能失败的行为；但具体分析方法的细节材料未说明。
Method（方法）
  • 使用模型预测控制器（MPC）在同一环境中生成转接
  • 将这些转接插入到离策略强化学习的经验回放中，以偏置学习过程
  • 不重新设计任务奖励，不引入判别器、运动学重定向或辅助目标项
  • 通过改变注入的 MPC 数据来选择不同的步态（如小跑或弹跳）
Experiments（实验）
  • 在 2D walker 仿真中验证：MPC-Injection 产生的步态在质量上与奖励塑造和对抗运动先验相当
  • 在 Go2 四足机器人上进行 sim-to-real 评估：MPC-Injection 产生的步态在质量上与奖励塑造和对抗运动先验相当
  • MPC-Injection 可以完成纯 RL 在相同简单奖励下未能实现的后空翻（barrel roll）
  • 通过仅改变注入的 MPC 数据，可以在小跑（trotting）和弹跳（bounding）步态之间选择
Limitations（局限）

论文提出 MPC-Injection，通过注入 MPC 生成的转接来引导离策略运动强化学习。：We present MPC-Injection, a low-overhead method that steers RL toward a designer-preferred behavior by inserting transitions generated in the same environment by a model predictive controller (MPC).
方法不需要重新设计奖励，也不需要判别器、运动学重定向或辅助目标。：Unlike reward shaping, MPC-Injection does not require redesigning the task reward, and unlike adversarial imitation learning, it adds no discriminator, no kinematic retargeting, and no auxiliary objective.
在 2D walker 和 Go2 四足机器人上验证，步态质量与奖励塑造和对抗运动先验相当。：On a 2D walker in simulation and with sim-to-real evaluation on a Go2 quadruped, we show that MPC-Injection produces gaits qualitatively comparable to those of reward shaping and adversarial motion priors.
MPC-Injection 可以完成纯 RL 在相同简单奖励下未能实现的后空翻，且仅改变注入数据即可选择小跑或弹跳步态。：We also show that MPC-Injection can complete a barrel roll that pure RL fails to achieve under the same simple reward and can select between trotting and bounding gaits only through changing the injected MPC data.
