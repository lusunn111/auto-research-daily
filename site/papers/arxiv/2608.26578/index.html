TrapVLA：将视觉-语言-动作模型困于配置的故障模式中

TrapVLA: Trapping Vision-Language-Action Models in Configured Failure Modes

Jun-Hui Liu · Kun-Yu Lin · Yi-Lin Wei · Xu-Han Chen · Yinghao Li · Zhuohao Li · Yuan-Ming Li · Qing Zhang · Xiaoyi Fan · Dongmei Jiang · Yan Li · Wei-Shi Zheng

核心洞察

核心洞察：配置失败陷阱（Configured Failure Trapping）要求攻击者控制特定失败模式（如提前关闭抓爪、抓取偏移、提前打开、释放偏移），通过文本触发器激活，且这些失败模式在正常执行中也可能出现，使得攻击难以被察觉。识别出'稀疏动作偏差'（sparse action deviation）是关键挑战——目标偏差数据的监督信号被大量保持任务一致动作的触发数据所淹没。提出的TrapVLA方法通过学习触发器诱导的动作残差（action residuals）来引导策略向配置的失败行为偏移。

为什么值得看：本文为VLA模型的安全性提供了一个新视角，定义了更细粒度的攻击任务，并提出了有效的攻击方法和评估基准。对于研究VLA模型的鲁棒性、安全部署以及构建可信具身智能系统具有重要参考价值。其方法论（动作残差训练）和评估工具（TrapEval）可扩展到其他VLA变体。

Setting（研究设定）
研究设定：针对VLA模型的对抗攻击，提出新型后门攻击任务，在仿真（Trap-LIBERO, Trap-RoboTwin）和真实机器人（Eggplant, Cup任务）上进行评测。
Motivation（研究动机）
现有关VLA安全的研究主要聚焦于引发通用任务失败（如对抗扰动、后门注入、语义越狱），这些工作将失败视为二元结果，只关注任务是否失败，忽略了一个细粒度的威胁：攻击者可能控制机器人如何失败（例如以指定的位置偏移抓取）。这种配置的故障模式更隐蔽、更难检测。
Insight（核心洞察）
核心洞察：配置失败陷阱（Configured Failure Trapping）要求攻击者控制特定失败模式（如提前关闭抓爪、抓取偏移、提前打开、释放偏移），通过文本触发器激活，且这些失败模式在正常执行中也可能出现，使得攻击难以被察觉。识别出'稀疏动作偏差'（sparse action deviation）是关键挑战——目标偏差数据的监督信号被大量保持任务一致动作的触发数据所淹没。提出的TrapVLA方法通过学习触发器诱导的动作残差（action residuals）来引导策略向配置的失败行为偏移。
Challenge（技术挑战）
  • 配置失败模式需指定具体的失败方式，而非仅使任务失败
  • 必须保持清洁数据上的任务性能，防止攻击被检测
  • 存在稀疏动作偏差问题：目标偏差数据稀少，监督被大量正常动作数据淹没
  • 攻击必须隐蔽且难以检测，失败行为需在正常执行中合理出现
Analyze（问题分析）
作者分析了配置失败陷阱任务中的关键挑战，即稀疏动作偏差，指出在训练中目标偏差数据稀少，导致模型难以建立触发器与配置失败行为之间的强关联。为此，他们提出目标残差引导（Target Residual Steering），直接监督触发器诱导的动作残差，以增强触发器与失败行为的关联。
Method（方法）
  • TrapEngine：数据引擎，合成高质量的目标轨迹（配置失败轨迹）
  • TrapEval：自动化评估套件，衡量攻击成功率和失败保真度，提出配置攻击成功率（C-ASR）和攻击有效性与有效性（AVE）指标
  • Trap-LIBERO 和 Trap-RoboTwin：构建两个基准，实例化四种代表性故障模式
  • TrapVLA：方法，显式学习触发器诱导的动作残差以引导策略朝配置的失败行为偏移，解决稀疏动作偏差问题
Experiments（实验）
  • 在仿真基准（Trap-LIBERO, Trap-RoboTwin）和真实机器人设置上评估TrapVLA，并对比DropVLA。真实实验（π0.5模型）中，Eggplant任务AVE为97.0，Cup任务AVE为99.2，分别超过DropVLA 44.7和43.3个百分点，且在清洁指令下SR保持在93.3%和100.0%。

本文是首个引入配置失败陷阱后门攻击任务的研究。：This work introduces Configured Failure Trapping, a novel backdoor attack task against Vision-Language-Action (VLA) models, which aims to activate attacks through stealthy textual triggers and induce configured failure modes.
配置失败陷阱与先前攻击不同，要求控制失败方式而非仅使任务失败。：Unlike prior backdoor attacks that treat any task failure as a successful attack, Configured Failure Trapping requires the attacker to control how the robot fails (e.g., causing the robot to grasp with a specified positional offset), making it substantially more challenging and hard to detect.
作者提出了TrapEngine数据引擎和TrapEval评估套件。：To support the new task, we propose an effective data engine for synthesizing high-quality target trajectories and an automated suite for measuring configured-failure fidelity.
作者构建了Trap-LIBERO和Trap-RoboTwin两个基准，实例化四种故障模式。：Then, based on this foundation, we construct two new benchmarks, namely Trap-LIBERO and Trap-RoboTwin, that instantiate Configured Failure Trapping across four representative failure modes.
作者识别出稀疏动作偏差为关键挑战，并提出TrapVLA方法。：To address this task, we identify sparse action deviation as a critical challenge and accordingly propose a novel method named TrapVLA, which explicitly learns trigger-induced action residuals to steer the policy toward the configured failure behavior.
TrapVLA在仿真和真实机器人设置上有效注入配置失败模式，同时保持清洁数据性能。：Extensive experiments across simulation benchmarks and real-world robotic settings show that TrapVLA effectively injects configured failure modes into VLA models while largely preserving performance on clean data.
