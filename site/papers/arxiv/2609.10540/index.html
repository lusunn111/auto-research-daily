Setting（研究设定）
自然语言指令驱动的交互式视频世界模型，智能体将指令翻译为可执行程序，显式维护全局持久世界状态（含屏幕外实体与非视觉属性），再由预训练视频模型作为生成式渲染器产生像素级观测，支持可玩游戏式长时序交互。
Motivation（研究动机）
近期视频世界模型虽能生成越来越真实且可交互的视觉体验，但缺乏在长时间交互中维持持久世界状态与施加可编程规则的可靠机制。
Insight（核心洞察）
将世界状态演化与视觉观测生成解耦：用显式、持久、可编程的全局状态（由轻量引擎执行规则更新）承载世界逻辑，再由渲染器负责像素生成，从而实现对单个实体及其交互的直接控制并保持长时序一致性。
Challenge（技术挑战）
  • 在扩展交互中维持持久的世界状态
  • 对世界施加可编程规则
  • 将符号化世界状态与视觉生成相连接（跨模态状态到像素的条件对齐）
  • 支持长时序连贯生成
Analyze（问题分析）
材料未说明作者如何具体分析问题；仅从摘要可知其将问题归结为状态维护与规则约束的缺失，并提出解耦状态演化与视觉生成的设计。
Method（方法）
  • 智能体将自然语言指令翻译为可执行程序，程序规定实体状态与状态转移规则
  • 轻量引擎执行这些程序，更新并维护显式、持久的全局世界状态，包括屏幕外实体与非视觉属性
  • 引入状态增强的 3D 有向包围盒（OBBs）作为中间表示，连接世界状态与视觉生成
  • 将该表示与目标相机轨迹确定性地编译为像素对齐的时空条件信号
  • 以预训练视频模型作为生成式渲染器，消费上述条件信号生成观测
  • 整体设计使用户可创建具有预定义机制的可玩游戏，直接控制单个实体并贯穿游玩过程保持持久世界状态
Experiments（实验）
  • 提出 CombatStateBench 基准，用于评估可编程世界模型
  • 在 CombatStateBench 上，该方法达到 94% Count Accuracy 与 98% State Accuracy
  • 摘要称其显著优于现有交互式视频世界模型，并支持连贯的长时序生成
