Setting（研究设定）
视觉-语言-动作（VLA）模型在仅有初始观测的开环规划场景下，需要内部模拟动作条件下的状态转移，以完成长时序规划任务（FrozenLake、Maze、MiniBehavior）。
Motivation（研究动机）
现有推理范式（文本空间、像素空间、潜在空间）在开环规划中存在根本性的状态表示失配：文本和像素推理分别受损失的空间压缩与误差累积的视觉生成影响，潜在空间推理则绕过中间潜在token，均削弱可靠的长时序规划能力。
Insight（核心洞察）
将静态视觉上下文、语言约束与一个循环潜在状态解耦：初始图像与指令只编码一次，每个动作预测以潜在状态为条件，并通过动作条件GRU更新该状态，从而以紧凑的循环状态替代误差累积的视觉生成或信息丢失的文本推理。
Challenge（技术挑战）
  • 开环设定下模型必须内部模拟动作条件状态转移，缺乏环境反馈
  • 文本空间推理有损压缩空间信息
  • 像素空间推理存在误差累积的视觉生成问题
  • 潜在空间推理绕过中间潜在token
  • 长时序规划需在准确性与推理效率之间取得平衡
Analyze（问题分析）
材料未说明作者具体的分析过程，仅指出现有文本、像素、潜在空间推理范式分别存在有损空间压缩、误差累积视觉生成和绕过中间潜在token的问题。
Method（方法）
  • 提出状态空间视觉推理（SSVR），将静态视觉上下文、语言约束与循环潜在状态解耦
  • 对初始图像和指令仅编码一次，保持静态视觉-文本上下文复用
  • 每个动作预测以潜在状态为条件，并用动作条件GRU更新潜在状态
  • 以Qwen2.5-VL作为骨干模型
Experiments（实验）
  • 在FrozenLake、Maze和MiniBehavior上评估，EM/PR分别达到99.5/99.6、96.3/98.0、83.9/90.6，大幅优于先前方法
  • 实验支持循环状态建模在输入变换和迁移设定下对VLA开环规划的有效性
  • 复用静态视觉-文本上下文并更新紧凑循环状态，支持高效多步推理，在预构建前缀缓存的情况下Maze解码rollout比所评估的基线快达98.58倍

现有VLA推理范式在开环规划中存在状态表示失配：Despite rapid progress in vision-language-action (VLA) models, existing reasoning paradigms still face a fundamental \emph{state-representation mismatch} in open-loop planning.
文本、像素和潜在空间推理分别存在有损空间压缩、误差累积视觉生成和绕过中间潜在token的问题：text-, pixel-, and latent-space reasoning can suffer from lossy spatial compression, error-accumulating visual generation, and bypass of intermediate latent tokens, respectively, undermining reliable long-horizon planning.
SSVR解耦静态视觉上下文、语言约束和循环潜在状态：We propose \textbf{State-Space Visual Reasoning} (SSVR), which decouples static visual context, language constraints, and a recurrent latent state.
SSVR对初始图像和指令仅编码一次，每个动作预测以潜在状态为条件并用动作条件GRU更新：SSVR encodes the initial image and instruction once, then conditions each action prediction on the latent state and updates it with an action-conditioned GRU.
以Qwen2.5-VL为骨干，在三个基准上取得显著性能：Using Qwen2.5-VL as the backbone, SSVR achieves 99.5/99.6, 96.3/98.0, and 83.9/90.6 EM/PR on FrozenLake, Maze, and MiniBehavior, substantially outperforming prior methods.
复用静态上下文和更新紧凑循环状态支持高效多步推理，Maze解码rollout加速达98.58倍：By reusing static visual-textual context and updating a compact recurrent state, SSVR supports efficient multi-step inference, achieving up to $98.58\times$ faster Maze decoding rollouts than the evaluated baselines with the prefix cache prebuilt.
