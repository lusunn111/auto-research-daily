Setting（研究设定）
面向多样操作任务的具身通用策略，联合建模未来世界演化与机器人动作；重点研究长时序操作中，相似观测-动作片段跨任务与阶段重复出现时的生成引导问题。
Motivation（研究动机）
表示多样的未来只是第一步；有能力的 WAM 还必须生成符合当前任务需求与执行进度的未来。现有方法在长时序操作中可能产生局部可信但方向错误的 rollouts，从而漂移到错误的任 务阶段，即 Stage Confusion。
Insight（核心洞察）
通过用 Mode Tokens 表示细粒度任务需求、用 State Tokens 跟踪执行进度，构成结构化任务状态，可在闭环中把世界-动作生成引导向预期未来，从而缓解阶段混淆。
Challenge（技术挑战）
  • 长时序操作中相似观测-动作片段跨任务与阶段重复出现，导致阶段歧义
  • 局部可信的未来 rollout 可能在全局任务进度上方向错误
  • 需要在闭环中同时表达任务需求与执行进度
  • 需跨异构 WAM 架构与多种机器人本体实现即插即用迁移

Method（方法）
  • 提出 TaskWAM：闭环、阶段感知框架
  • 使用 Mode Tokens 表示细粒度任务需求
  • 使用 State Tokens 跟踪执行进度
  • 将 Mode Tokens 与 State Tokens 组成结构化任务状态，用于引导世界-动作生成朝向预期未来
  • 提出 StageBench：受控多阶段操作基准，具有参数化阶段变化与自动评估

现有 WAM 在长时序操作中可能生成局部可信但方向错误的 rollouts，漂移到错误任务阶段（Stage Confusion）：existing approaches may generate locally plausible yet misdirected rollouts to drift toward wrong task stage, i.e., a phenomenon we term Stage Confusion.
TaskWAM 使用 Mode Tokens 表示任务需求、State Tokens 跟踪执行进度，形成结构化任务状态以引导生成：we propose TaskWAM, a closed-loop, stage-aware framework that represents fine-grained task requirements with Mode Tokens and tracks execution progress with State Tokens, forming a structured task state to steer world--action generation toward intended future.
提出 StageBench 多阶段操作基准：We further introduce StageBench, a controlled multi-stage manipulation benchmark with parameterized stage variations and automated evaluation.
在仿真与真实任务上有效减少混淆并取得有竞争力的性能，且支持跨架构与跨本体迁移：Extensive experiments on both simulation benchmarks and real-world tasks demonstrate that TaskWAM effectively reduces confusion and achieves competitive performance with state-of-the-art methods.
