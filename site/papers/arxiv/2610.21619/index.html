Setting（研究设定）
在已完成视觉语言特征蒸馏的三维高斯语言地图上进行部署阶段精炼：给定少量用户指定目标，需要可靠定位这些目标，同时保持对其他开放词汇文本的查询能力；方法不需要额外训练。
Motivation（研究动机）
现有蒸馏得到的语言地图在开放词汇查询上可用，但在实际部署中对用户指定的一小部分目标经常定位失败；而如果直接向地图注入目标先验，又可能覆盖外观线索并破坏对其他词的一般查询能力，因此需要在两者之间取得平衡。
Insight（核心洞察）
对每个目标检测区域，仅将区域内视觉嵌入与目标文本嵌入做凸组合，并寻找仍能让该目标胜出的最小注入系数；该系数可闭式求得，无需调超参。同时，文本嵌入共享的公共分量会使标准余弦读出对查询不敏感，需要在读出阶段做中心化。
Challenge（技术挑战）
  • 目标先验注入过强会覆盖外观线索并削弱开放词汇通用查询能力
  • 注入过少则无法让指定目标可靠胜出
  • 注入文本嵌入后，共享公共分量导致余弦读出变为查询无关
  • 需在开放词汇分割与语言目标定位两类任务上同时不退化
Analyze（问题分析）
材料未说明作者对失败案例的具体分析过程；摘要仅指出蒸馏地图在部署中常漏检用户指定目标，并识别出文本嵌入共享公共分量导致余弦读出查询无关这一注入失败模式。
Method（方法）
  • 以文本提示分割器引导，检测用户指定目标区域
  • 在每个目标区域内将视觉嵌入与目标文本嵌入做凸组合，系数控制注入先验量；非目标区域保持不变
  • 对每个目标求解仍能使其胜出的最小系数，并以闭式解获得全部系数，无需超参调优
  • 在读出阶段引入中心化步骤，去除文本嵌入公共分量造成的查询无关性
  • 作为插件可迁移到现有 field-based 与 object-level 语言地图
Experiments（实验）
  • 在三个基准上，精炼持续提升开放词汇分割，Replica 上基础 mIoU 约翻倍
  • 语言目标定位比基础地图更可靠
  • 作为插件迁移到现成 field-based 与 object-level 语言地图
  • 真实世界演示中四足机器人导航至自然语言目标

论文研究对已蒸馏三维高斯语言地图进行免训练、目标感知的精炼：We propose a training-free, target-aware refinement of an already-distilled language map.
方法在每个目标区域将视觉嵌入与目标文本嵌入做凸组合，非目标区域不变：the visual embedding inside each detected target region is blended with the target text embedding, a convex combination whose coefficient sets the amount of injected prior, while non-target regions are left untouched
对每个目标求最小胜出系数并以闭式解获得，无需调超参：we seek, for each target, the smallest coefficient that still lets it win, and we obtain every coefficient in closed form, leaving no hyperparameters to tune
识别出文本嵌入共享公共分量导致余弦读出查询无关，并用中心化步骤消除：Text embeddings share a common component, and injecting them makes the standard cosine read-out query-agnostic, which a centering step in the read-out removes.
Replica 上基础 mIoU 约翻倍，并作为插件迁移且支持四足机器人真实演示：roughly doubling the base mIoU on Replica
