Triggering Generalist Reasoning via Predictive Uncertainty for Dual-System VLA

核心洞察

在缓存的通用模块上下文下，未来动作分块槽位处动作重预测的跨步离散度可作为预测不确定性信号，反映新观测到来时未来动作计划的偏移程度；该信号可由架构已有前向计算获得，无需人工阶段标签或额外不确定性模型。

Setting（研究设定）
双系统VLA模型由慢速通用推理模块与快速专家动作模块组成，现有方法以固定频率调用通用模块，本文研究在机器人执行轨迹中自适应决定何时调用通用推理模块。
Motivation（研究动机）
固定频率调用通用模块忽略了决策复杂性在轨迹中的变化，在简单阶段浪费计算，在场景意外变化时又延迟重新推理。
Insight（核心洞察）
在缓存的通用模块上下文下，未来动作分块槽位处动作重预测的跨步离散度可作为预测不确定性信号，反映新观测到来时未来动作计划的偏移程度；该信号可由架构已有前向计算获得，无需人工阶段标签或额外不确定性模型。
Challenge（技术挑战）
  • 决策复杂性随执行过程变化，固定调用频率无法匹配
  • 简单阶段过度调用造成计算浪费，场景变化时重新推理延迟
  • 需要无需人工阶段标签和辅助不确定性模型的自适应判据
  • 需在调用预算、成功率与实时开销之间取得更好权衡
Analyze（问题分析）
作者将问题分析为固定频率通用模块调用在轨迹不同阶段的错配，并提出用缓存的通用上下文下未来动作分块槽位重预测的跨步离散度作为预测不确定性信号，以此判断是否需要调用通用模块。
Method（方法）
  • 提出TUD，一种自适应推理框架，选择性跳过不必要的通用模块调用
  • 在当前缓存的通用模块上下文下，对即将到来的动作分块槽位进行动作重预测
  • 计算这些重预测的跨步离散度作为预测不确定性信号
  • 该信号刻画新观测到来时未来动作计划的偏移程度
  • 信号来自架构已经执行的前向计算，不依赖人工阶段标签或辅助不确定性模型
  • 基于该信号决定是否触发通用推理
Experiments（实验）
  • 在VLA-Arena上，TUD在相同调用预算下取得比替代不确定性基线更高的成功率，同时保持较低墙钟开销
  • TUD更一致地区分成功与失败的轨迹
  • 通过变化单一阈值，TUD描绘出完整运行曲线，相比非自适应基线具有更有利的成本-成功率权衡
  • 在相同成功率下，TUD大幅减少VLM调用次数
  • 在真实机器人实验中，TUD相对最强固定间隔基线将通用模块调用减少75%，同时取得更高成功率

该信号无需人工阶段标签或辅助不确定性模型，且来自架构已有前向计算。：This signal captures how much the future action plan shifts as new observations arrive and is computed from forwards the architecture already runs, requiring neither manual phase labels nor an auxiliary uncertainty model.
