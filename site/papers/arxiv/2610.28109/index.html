FIT-MAC：面向鲁棒视觉语言动作模型的闭环多智能体框架

FIT-MAC: A Closed-Loop Multi-Agent Framework for Robust Vision-Language-Action Models

Jiatong Li · Jisheng Dang · Qiangqiang Ma · Bimei Wang · Jingwen Zhao · Wenjun Ma · Juncheng Li · Hong Peng · Bin Hu

核心洞察

可以在不改动预训练 VLA 参数的前提下，通过推理时的闭环多智能体层把故障区分为目标绑定错误与局部执行失败，并只对允许的情形施加有针对性的纠正，从而提升鲁棒性。

为什么值得看：提供了一个不重训、模型无关的推理时控制层范式，把 VLA 鲁棒性问题转化为可诊断、可分类型恢复的闭环系统问题，对关注 VLA 部署可靠性、运行时监控与恢复策略以及干预开销优化的研究者有直接参考价值。

Setting（研究设定）
在冻结的预训练 VLA 策略之上增加推理时控制层，在 LIBERO-PRO 扰动的机器人操作任务上评估鲁棒性，并与 OpenVLA、π0、π0.5 等骨干结合。
Motivation（研究动机）
VLA 模型在标准基准上表现强，但当物体位置或任务指令等偏离名义设定时可靠性显著下降，甚至完全失败；现有 VLA 策略缺乏显式的运行时机制来区分失败模式并选择恢复策略。
Insight（核心洞察）
可以在不改动预训练 VLA 参数的前提下，通过推理时的闭环多智能体层把故障区分为目标绑定错误与局部执行失败，并只对允许的情形施加有针对性的纠正，从而提升鲁棒性。
Challenge（技术挑战）
  • 扰动下目标绑定错误与局部执行失败的区分
  • 运行时判断何时需要干预而不损害默认策略
  • 针对不同失败类型选择重绑定或有界抓取/放置恢复
  • 在多种 VLA 骨干上保持通用性
  • 干预开销与长时序可靠执行
Analyze（问题分析）
作者将问题归结为 VLA 策略缺少运行时失败模式区分与恢复选择机制，并把鲁棒性问题拆解为目标解析/绑定、阶段化执行进度跟踪与失败类型区分、以及按失败类型路由纠正；通过干预率与恢复成功率等指标刻画运行时行为。
Method（方法）
  • 在预训练 VLA 策略上增加推理时控制层，VLA 保持默认动作生成器
  • Planner Agent 将语言指令解析为包含操作目标与空间约束的结构化任务规范
  • Grounder Agent 将指令级指称解析为视觉目标
  • Verifier Agent 跟踪分阶段执行进度，区分目标绑定错误与局部执行失败并判断是否需要干预
  • Correction Agent 按失败类型路由到目标重绑定或有界抓取/放置恢复
  • 在策略查询边界进行接地、故障诊断、目标纠正与执行纠正，且不修改 VLA 参数
Experiments（实验）
  • 在 LIBERO-PRO 上按五种扰动类型 Pos、Task、Env、Obj、Sem 评估，主指标为成功率 SR，并报告干预率 IR 与恢复成功率 RSR
  • 以相同任务分配、回合预算和随机种子对比 OpenVLA 有无 FIT-MAC；受控对比在五个随机种子 7、11、13、17、23 上平均
  • 平均 SR 达 78.7%，比 OpenVLA 高 32.8%；在十个扰动设置中的八个取得最优 SR
  • 在 LIBERO-Object 上 SR 为 93.4% 和 87.2%，分别比最强竞品 RATs 高 32.4% 和 24（原文数值被截断）
  • 与 π0 和 π0.5 集成且骨干参数冻结，并进行模块消融及对干预准则、恢复时机与执行时域的敏感性分析
  • 敏感性分析显示执行时域 1/2/3 时平均 SR 为 70.0/77.7/78.6
Limitations（局限）
  • 未来工作聚焦于降低干预开销并改进语义与空间接地，以支持可靠的长时序执行
  • 案例显示空间接地与抓取执行仍是剩余局限：目标重绑定错误会抓错物体，抓取停滞会在正确识别目标后反复抓取失败
与你的研究关系
直接面向具身智能中的 VLA 可执行动作生成与真实机器人操作可靠性，涉及推理时闭环控制、故障诊断与恢复决策；与系统优化中的运行时开销与实时干预相关，但未涉及世界模型或长时序预测建模。
证据与不确定性
