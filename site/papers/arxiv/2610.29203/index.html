Setting（研究设定）
视觉语言动作（VLA）导航模型：输入视觉观测与导航指令，输出局部动作序列；在固定智能体状态与导航历史的前提下，施加不同指令，并比较动作输出的概率分布与视觉注意力变化。
Motivation（研究动机）
导航成功率只能反映是否到达目标，无法说明模型究竟是遵循指令，还是依赖视觉线索或导航历史；因此需要一个诊断协议，检验指令改变是否真的影响动作分布。
Insight（核心洞察）
把“指令是否被真正使用”转化为在导航上下文固定条件下的反事实比较：同一路线已走过部分、不同分支指令下，动作分布、参考动作序列似然与视觉注意力/归因应当随指令变化。
Challenge（技术挑战）
  • 导航成功与指令遵循之间存在度量脱节
  • 在保持智能体状态与导航历史不变的同时，隔离出指令变量的因果影响
  • 构造共享已走过路线描述、仅在分支处不同的指令对
  • 从动作序列、似然与注意力/归因多角度刻画绑定
Analyze（问题分析）
作者指出导航成功率评估的歧义，并据此设计控制变量的诊断：基于 R2R-CE 与 RxR-CE 的路段对齐指令片段重组出 3,252 个路线分叉上下文，使成对指令仅在分支指定上不同，从而在相同状态与历史下比较模型行为。
Method（方法）
  • 提出 NavBind 诊断框架，用于检验指令-动作绑定
  • 从 R2R-CE 和 RxR-CE 重组路线对齐指令片段，构造 3,252 个路线分叉上下文
  • 每个上下文配对完整指令：已走过路线的描述相同，但指定不同分支
  • 在同一智能体状态与导航历史下评估成对指令
  • 比较生成的局部动作序列
  • 比较固定参考动作序列在两种指令下的似然
  • 分析视觉注意力与归因的变化
Experiments（实验）
  • 在所评估的模型中，更高的报告导航成功率并不意味着模型更忠实地遵循指令

与你的研究关系
直接服务于具身智能中 VLA 导航模型的可执行动作生成与真实行为评测：它把评测从“到达目标”推进到“指令是否因果地影响动作分布”，与 VLA 的指令遵循、动作生成可靠性及面向真实机器人部署的评测密切相关；对世界模型/长时序预测与系统优化的关联较弱。

论文提出 NavBind 用于诊断指令-动作绑定，即在导航上下文固定时改变指令是否影响动作概率分布。：We introduce NavBind to diagnose instruction-action binding: whether changing the instruction influences the probabilistic distribution of the actions, with the navigation context fixed.
作者基于 R2R-CE 与 RxR-CE 重组指令片段，构造 3,252 个路线分叉上下文。：We construct 3,252 route-fork contexts by recombining route-aligned instruction segments from R2R-CE and RxR-CE.
成对指令共享已走过路线的描述，但指定不同分支，并在相同状态与历史下评估。：Each context pairs full instructions that share the description of the route already traveled but specify different branches. Both are evaluated under the same agent state and navigation history.
评估比较生成的局部动作序列、参考动作序列似然以及视觉注意力与归因变化。：We compare generated local action sequences, the likelihoods of fixed reference action sequences under both instructions, and changes in visual attention and attribution.
在所评估模型中，更高的导航成功率不代表更忠实的指令遵循。：Across the evaluated models, higher reported navigation success does not imply that the model more faithfully follows the instructions.
