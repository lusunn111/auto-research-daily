Setting（研究设定）
智能体在由模拟器/游戏引擎与共享神经渲染器耦合构建的实时交互式虚拟世界中，通过视觉观测感知环境、实时交互，并将每轮经验蒸馏为可继承和精炼的策略手册（playbooks）。
Motivation（研究动机）
交互式虚拟世界让智能体通过探索与交互学习，但智能体能学到什么受限于其所处环境：环境必须既忠实（状态、规则、动力学一致）又真实（观测符合真实世界视觉分布），而在多样化世界中同时实现二者仍是瓶颈。
Insight（核心洞察）
将模拟后端（维护持久世界状态并执行程序定义的交互规则）与共享神经渲染器解耦并通过公共接口连接，可以在保持状态与规则一致性的同时生成符合真实视觉分布的观测；同时通过 Adversarial Forcing 使历史预填充可微并引入真实数据对抗监督，兼顾渲染质量与实时性。
Challenge（技术挑战）
  • 在多样化世界中同时实现环境的忠实性（状态、规则、动力学一致）与真实感（观测符合真实世界视觉分布）
  • 使神经渲染器支持实时交互推理
  • 让损失能够通过历史预填充影响渲染器对先前观测的编码方式
  • 提升渲染视觉质量
Analyze（问题分析）
摘要指出智能体能学到什么受环境约束，环境需同时满足忠实性与真实感，而跨多样世界同时实现两者是瓶颈；据此提出用模拟后端保证忠实性、用共享神经渲染器保证真实感，并通过 Adversarial Forcing 与推理优化解决渲染质量与实时性问题；实验上以学习效率对比说明效果。材料未说明更细粒度的分析过程。
Method（方法）
  • 将模拟器与游戏引擎作为模拟后端，维护持久世界状态并执行程序定义的交互规则
  • 通过公共接口导出结构化条件，由共享神经渲染器从这些条件生成视觉观测
  • 将预训练视频模型适配到几何条件以构建神经渲染器
  • 提出 Adversarial Forcing：通过精确重放使历史预填充可微，使后续预测上的损失能更新渲染器对先前观测的编码方式
  • 加入真实数据对抗监督以提升渲染视觉质量
  • 针对实时交互优化推理
  • 智能体通过视觉观测感知世界、实时交互，并将每轮经验蒸馏为后续智能体可继承和精炼的策略手册
  • 新世界可写成代码并经由同一接口渲染，使环境在数量与难度上随智能体扩展
Experiments（实验）
  • 实证研究显示学习效率有显著提升：智能体仅需 4 轮学习，而传统强化学习对照需要数百万轮
  • 新世界可写成代码并通过同一接口渲染，环境可在数量与难度上随智能体扩展

环境需同时满足忠实性与真实感，而跨多样世界实现二者是瓶颈，这是研究动机：What agents can learn is bounded by the environments they practice in, which must be faithful, with consistent state, rules, and dynamics, and realistic, with observations that follow the real-world visual distributions. Achieving both across diverse worlds remains a bottleneck.
该框架将模拟器与游戏引擎同共享神经渲染器耦合以构建实时交互环境：We introduce AgentGarten, a framework that couples simulators and game engines with a shared neural renderer to build real-time interactive environments.
模拟后端维护持久世界状态并执行程序定义的交互规则，渲染器从结构化条件生成观测：Its simulation backends maintain persistent world state and execute program-defined interaction rules, while the renderer generates visual observations from structured conditions exported through a common interface.
Adversarial Forcing 使历史预填充通过精确重放可微，并加入真实数据对抗监督：Adversarial Forcing makes history prefilling differentiable through exact replay, so that losses on later predictions update how the renderer encodes prior observations, and adds real-data adversarial supervision to improve its visual quality.
智能体通过视觉观测感知世界、实时交互，并把每轮经验蒸馏为可继承和精炼的策略手册：agents perceive the world through visual observations, interact with it in real time, and improve by distilling each round of experience into playbooks that subsequent agents inherit and refine
实验显示学习效率显著提升，仅需 4 轮，而传统强化学习对照需要数百万轮：demonstrates a substantial gain in learning efficiency, with agents learning from just 4 rounds compared with millions for a conventional reinforcement learning counterpart
新世界可写成代码并经同一接口渲染，环境可随智能体在数量与难度上扩展：As new worlds can be written as code and rendered through the same interface, environments can scale in both number and difficulty alongside their agents
