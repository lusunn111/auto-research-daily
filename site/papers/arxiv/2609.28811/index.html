Setting（研究设定）
利用预训练视频生成器迁移视觉与运动先验进行机器人控制；在双臂操作任务上，训练时联合建模视觉动态与动作，推理时进行少步动作生成，并在仿真基准与真实机器人上评测。
Motivation（研究动机）
现有 WAM 在训练时预测密集未来帧，反复建模大量基本不变的内容，并将动作条件动态与无关的外观变化耦合；推理时又需用重型视频专家处理每个完整观测，导致少步动作生成成为瓶颈。
Insight（核心洞察）
视觉动态中真正与动作相关的部分可以用稀疏的视觉增量表达，而非重复预测密集完整帧；同时推理时可只对增量做流式缓存更新，从而减少重型视频专家的重复计算。
Challenge（技术挑战）
  • 如何避免在密集未来帧预测中重复建模基本不变的内容
  • 如何解耦动作条件动态与无关的外观变化
  • 如何在推理时避免用重型视频专家处理每个完整观测
  • 如何在减少训练与推理计算的同时保持或提升操作成功率
Analyze（问题分析）
材料未说明作者如何具体分析问题，摘要仅指出问题来源与提出方法，未描述分析过程。
Method（方法）
  • 提出 DeltaWAM，联合预测视觉增量与动作，使用密集锚点流、稀疏增量流与动作流三种流。
  • 给出三种架构，区别在于表示与计算共享方式。
  • 提出 Streaming Delta Memory（SDM），用紧凑的已观测增量更新缓存的锚点上下文。
  • SDM 减少重型视频专家的处理量。
  • 推理时进行少步动作生成。
Experiments（实验）
  • 在 RoboTwin 上，DeltaWAM 配合 SDM 将平均成功率从 Fast-WAM 的 81.3% 提升到 85.4%（clean 设置）。
  • 在视觉随机化下，从 75.8% 提升到 83.9%。
  • 三种架构将训练 FLOPs 降低 17.78%–23.77%。
  • SDM 将单步推理延迟和 FLOPs 分别降低 36.57% 和 31.55%。
  • 真实世界评测显示，在评测的策略中获得最高的总体成功率和归一化进度。

DeltaWAM 联合预测视觉增量与动作，使用密集锚点、稀疏增量与动作流，并提供三种架构。：we propose DeltaWAM, which jointly predicts visual deltas and actions using dense-anchor, sparse-delta, and action streams, with three architectures that differ in representation and computation sharing.
SDM 用紧凑的已观测增量更新缓存的锚点上下文以减少重型视频专家处理。：We further develop Streaming Delta Memory (SDM), which updates cached anchor context with compact observed deltas, reducing heavy video-expert processing.
