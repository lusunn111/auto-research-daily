核心洞察

世界表示的有效性依赖于所采用的集成范式，而 2D 语义表示能带来跨范式的稳健增益；不存在普适最优范式，但解耦式的 MoT 未来专家在整体性能和域外鲁棒性上表现有竞争力；世界建模对基于标准 VLM 的策略持续有益，解耦设计则与预训练 VLA 兼容性更好。

为什么值得看：它提供了对世界模型如何集成进 VLA 的受控比较框架和四条可操作的实证结论，能帮助研究者在架构选型（隐式/显式/解耦/外部预测器）、世界表示选择（尤其 2D 语义表示）以及面向长时序、动态和域外场景的优化上做出更有依据的决策，并为真实机器人评测提供参考。

Setting（研究设定）
在统一框架下实例化四类世界模型集成范式（隐式未来对齐、显式未来查询、MoT 未来专家、外部世界预测器），并搭配不同的世界表示与策略骨干网络，在域内、域外、长时序、动态、少样本及真实世界等多种设定下进行系统评测。
Motivation（研究动机）
现有将世界模型集成进 VLA 的方法在世界表示、集成范式和策略骨干上同时存在差异，导致难以判断哪些因素对有效的世界模型集成真正重要，因此需要解耦这些因素进行受控比较研究。
Insight（核心洞察）
世界表示的有效性依赖于所采用的集成范式，而 2D 语义表示能带来跨范式的稳健增益；不存在普适最优范式，但解耦式的 MoT 未来专家在整体性能和域外鲁棒性上表现有竞争力；世界建模对基于标准 VLM 的策略持续有益，解耦设计则与预训练 VLA 兼容性更好。
Challenge（技术挑战）
  • 世界表示、集成范式与策略骨干三类因素相互纠缠，难以单独归因
  • 不同范式在不同任务设定（域外、长时序、动态、少样本）下各有优劣，缺乏普适最优方案
  • 解耦设计虽提升兼容性与鲁棒性，但可能带来额外的推理或训练开销
Analyze（问题分析）
作者通过将现有工作归纳为四种代表性范式，并在统一框架下分别实例化，再结合多种世界表示与策略骨干进行跨设定（域内、域外、长时序、动态、少样本、真实世界）的系统对比来解耦各因素的影响。
Method（方法）
  • 把现有世界模型集成 VLA 的工作归纳为四种范式：隐式未来对齐、显式未来查询、MoT 未来专家、外部世界预测器
  • 在统一框架内分别实例化这四种范式
  • 为每种范式搭配多种世界表示与多种策略骨干网络
  • 在域内、域外、长时序、动态、少样本和真实世界等多类设定下进行系统评测
Experiments（实验）
  • 在域内、域外、长时序、动态、少样本和真实世界设定下对四种范式、多种世界表示与策略骨干进行了系统评测
  • 发现一：世界表示有效性依赖范式，2D 语义表示提供稳健的跨范式增益
  • 发现二：没有单一范式普适最优，解耦的 MoT 未来专家整体性能有竞争力，尤其在域外鲁棒性上
  • 发现三：世界建模持续有益于基于标准 VLM 的策略，解耦设计与预训练 VLA 兼容性更好
  • 发现四：世界建模在多种设定下优于仅动作基线，在长时序和动态任务上增益显著
