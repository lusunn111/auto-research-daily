记住你做过什么：面向长时序视觉-语言-动作策略的动作历史记忆与双专家去噪

Remember What You Did: Action-History Memory with Dual-Expert Denoising for Long-Horizon Vision-Language-Action Policies

Yaxin Zhao · Dianye Huang · Chenwei Wang · Chenguang Yang · Zhongliang Jiang

核心洞察

已执行的动作历史而非冗余的历史视觉观测，可作为紧凑且与进度相关的记忆信号；通过轻量记忆条件专家在早期高噪声去噪阶段进行历史感知引导，再把中间动作状态交给冻结的Action Expert进行低噪声细化，可在不重新训练基座策略的情况下实现即插即用的时序适应。

为什么值得看：论文提出一种参数高效、即插即用的动作历史记忆机制，仅训练Mamba与轻量PAE即可为冻结的流匹配视觉-语言-动作策略注入时序进度信息，并给出仿真与真实机器人上的成功率提升结果，对研究长时序视觉-语言-动作策略、记忆增强、推理效率与真实机器人评测具有直接参考价值。

Setting（研究设定）
在冻结的已微调流匹配视觉-语言-动作基座策略（π0.5）上，以插件形式增加由Mamba执行记忆模块与轻量PreAction Expert组成的记忆模块；仅训练Mamba与PAE，基座视觉-语言模型与原Action Expert保持冻结；在LIBERO-Mem十个仿真任务和四个真实世界任务上评测。
Motivation（研究动机）
许多现有视觉-语言-动作模型无法显式访问交互历史，容易受到感知混叠影响：不同任务阶段中相似的当前观测与机器人状态会导致动作歧义并降低成功率；现有通过特征条件、动作先验修改或采样引导注入时序或进度线索的方法，若联合微调记忆模块与基座视觉-语言-动作模型会带来额外策略训练成本，因此需要将可训练的历史条件引导与冻结的基座策略细化分离。
Insight（核心洞察）
已执行的动作历史而非冗余的历史视觉观测，可作为紧凑且与进度相关的记忆信号；通过轻量记忆条件专家在早期高噪声去噪阶段进行历史感知引导，再把中间动作状态交给冻结的Action Expert进行低噪声细化，可在不重新训练基座策略的情况下实现即插即用的时序适应。
Challenge（技术挑战）
  • 相似当前观测与机器人状态在不同任务阶段重复出现，导致动作歧义与成功率下降
  • 直接处理多帧历史观测会显著增加计算成本与推理延迟，妨碍实时控制
  • 历史帧在时间相邻帧之间以及每帧静态像素之间存在大量冗余，可能掩盖真正刻画交互进度的任务相关变化
  • 联合微调记忆模块与基座视觉-语言-动作模型会带来额外策略训练成本，限制已有视觉-语言-动作模型扩展记忆的灵活性
Analyze（问题分析）
作者将问题形式化为对当前观测非马尔可夫的长时间操作任务：相似观测可能出现在不同任务阶段却需要不同后续动作，仅凭当前观测无法区分，因此需要动作历史提供进度信息；同时指出现有历史表示方法存在计算成本高、历史帧冗余以及记忆建模与动作生成紧耦合导致额外训练成本的问题，进而提出以已执行动作历史作为紧凑进度信号，并分离可训练引导与冻结策略细化。
Method（方法）
  • ActMem-VLA采用双专家交接架构，在冻结的已微调视觉-语言-动作模型上增加记忆插件，插件包含基于Mamba的记忆模块与轻量PreAction Expert（PAE）
  • Mamba将已执行动作历史编码为记忆，并与当前上下文共同条件化PAE
  • PAE在早期高噪声去噪阶段引导任务进展，然后将部分去噪的动作传递给冻结的Action Expert（AE），由其在剩余低噪声步骤中细化动作细节
  • 训练期间微调后的基座视觉-语言-动作模型保持冻结，仅Mamba模块与PAE被联合优化
  • 为加速训练，可从冻结视觉-语言模型中选择前缀KV并预计算和复用
Experiments（实验）
  • 在LIBERO-Mem十个记忆依赖操作任务上，ActMem-VLA取得80.8%平均成功率，而π0.5为65.2%，MemoryVLA为49.5%，同时仅引入3.45%额外参数
  • 在四个真实世界任务上，ActMem-VLA相比π0.5将平均成功率提升28.8%；真实任务平均成功率从35.0%提升到63.75%
  • 真实世界任务中R1两轮碗归位达到100%成功率，而R3三次按钮按压为35%，R4三轮碗归位为55%
  • 组件消融支持执行记忆与可训练早期去噪专家的组合使用，同时揭示任务相关收益差异

证据与不确定性

全文节选省略了部分方法公式、消融细节、基线设置与真实任务完整数据，因此对具体实现、消融结论与统计显著性的判断存在不确定性；作者未在材料中明确陈述局限。

论文提出ActMem-VLA，一种双专家交接架构，在冻结的已微调视觉-语言-动作模型上增加包含Mamba记忆模块与轻量PreAction Expert的记忆插件。：We propose ActMem-VLA, a dual-expert handover architecture that augments a frozen, fine-tuned VLA with a memory plugin comprising a Mamba-based memory module and a lightweight PreAction Expert (PAE).
训练期间基座视觉-语言-动作模型保持冻结，仅Mamba模块与PAE被联合优化。：The fine-tuned base VLA remains frozen throughout training, while only the Mamba module and PAE are jointly optimized.
在LIBERO-Mem上取得80.8%平均成功率，仅引入3.45%额外参数。：On LIBERO-Mem, ActMem-VLA achieves 80.8\% average success across all ten tasks, compared with 65.2\% for $\pi_{0.5}$ and 49.5\% for MemoryVLA, while introducing only 3.45\% additional parameters.
在四个真实世界任务上相比π0.5提升平均成功率28.8%。：Across four real-world tasks, it improves the average success rate over $\pi_{0.5}$ by 28.8\%.
现有视觉-语言-动作模型缺乏显式交互历史，易受感知混叠影响。：However, many existing VLAs lack explicit access to interaction history, making them vulnerable to perceptual aliasing: similar current observations and robot states at different task stages may induce action ambiguity and lower success rate.
