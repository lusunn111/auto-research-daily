Setting（研究设定）
目标导向的机器人操作任务；在仿真 Push-T 与真实机器人上评测；模型从零训练，先随机交互转移预训练，再在专家演示上联合训练动作与状态。
Motivation（研究动机）
学习动作如何改变场景几何可以为目标导向操作提供互补监督，作者希望用统一框架同时获得动作生成与动作条件未来状态预测能力。
Insight（核心洞察）
用共享的离散坐标与语义 token 词表表示场景轮廓、目标、动作目标与未来状态，并通过任务特定语法组织成空间序列，从而让同一个自回归 Transformer 以共同的下一个 token 目标学习动作生成与状态预测。
Challenge（技术挑战）
  • 将动作与状态统一为离散空间语言序列
  • 在预训练中让动作坐标条件化后续状态预测但不计入预测损失
  • 控制时只解码可执行动作目标并用新观测状态更新历史
  • 在真实机器人上取得优于基线策略的任务成功率与目标覆盖率
Analyze（问题分析）
材料未说明作者如何具体分析问题，仅说明通过训练消融验证联合动作与状态序列、随机交互预训练对控制性能的作用。
Method（方法）
  • 提出 Spatial Language Modeling，用共享的离散坐标与语义 token 词表表示场景轮廓、目标、动作目标和未来状态。
  • 用任务特定语法将这些元素组织为空间序列。
  • 使用一个自回归 Transformer，以共同的下一个 token 目标同时学习动作生成和动作条件状态预测。
  • 从零训练，先进行随机交互转移预训练，再在专家演示上进行动作与状态的联合训练。
  • 预训练时，记录的动作坐标条件化后续状态预测，但被排除在预测损失之外。
  • 控制阶段只解码可执行的动作目标，并用新观测的状态更新历史。
Experiments（实验）
  • 在仿真 Push-T 和真实机器人上评估。
  • 模型取得有竞争力的仿真性能，并在真实机器人上取得比所评估的基线策略更高的任务成功率和目标覆盖率。
  • 训练消融显示，联合动作与状态序列改善控制，随机交互预训练带来进一步增益。
  • 给定动作轨迹时，同一模型也能预测连续场景状态，捕捉推动带来的几何效果。
