Setting（研究设定）
通用视觉语言模型（VLM）驱动的机器人操作，通过多智能体框架让 VLM 在视觉动作工作空间中直接操控机器人，并支持技能演化与小型 VLM 训练。
Motivation（研究动机）
现有系统要么间接使用 VLM（预测约束或编写程序），要么仅让 VLM 看到场景而非在其中行动的世界，未能充分发挥 VLM 的操作潜力。
Insight（核心洞察）
通过构建具有接触视图、动作预演和视图内修正三种属性的视觉动作工作空间，使 VLM 能在其中直接行动并预演、修改动作，同时通过同一工作空间获取具身程序性知识并训练更小的 VLM。
Challenge（技术挑战）
  • 如何让 VLM 直接从场景几何中选择接触视图以呈现交互周围场景
  • 如何将动作转化为可编辑提案并在执行前通过规划反馈进行预演与修改
  • 如何闭合观察、预演与底层执行之间的循环以消除残余偏移
  • 如何在证据审查下从专家视频与人类示教中演化多模态技能
  • 如何利用交互轨迹训练更小的 VLM 以驱动相同框架

Method（方法）
  • 构建多智能体框架 World Action Agent（WAA），让 VLM 使用基本工具操控机器人，所有决策在视觉动作工作空间中进行。
  • 工作空间属性一：接触视图——根据场景几何自动选择，呈现当前交互周围的场景。
  • 工作空间属性二：动作预演——将每个动作转化为可编辑提案，智能体单独或通过 Imagination Agent 在规划反馈下预览并修改后再执行。
  • 工作空间属性三：视图内修正——闭合观察、预演与底层执行之间的循环，让智能体在观察到残余偏移的视图中将其消除。
  • 通过同一工作空间获取具身程序性知识：在基于证据的审查下从专家视频和人类示教中演化多模态技能，并通过 Skill Agent 咨询这些技能。
  • 利用交互轨迹训练更小的 VLM，使其能够驱动相同的框架。
Experiments（实验）
  • 在 LIBERO-Pro 上，仅从 LIBERO-90 演化技能后，WAA 达到最先进的 75.6% 平均成功率，优于端到端 VLA、代码即策略智能体以及相同骨干的视觉框架基线。
  • 相同技能在 robosuite 上无需进一步学习仍然有效。
  • 在框架轨迹上微调 Qwen3.5-9B 将其域外成功率从 1.7% 提升至 43.3%。
