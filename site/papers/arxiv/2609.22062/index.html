Setting（研究设定）
在真实 Franka Emika Panda 机械臂上，对 3D 打印的扁平、弯曲和凹形物体集合以及 YCB 物体子集进行自动密集装箱；系统融合感知、抓取器感知的放置优化与力引导执行。
Motivation（研究动机）
仓库作业中自动密集装箱需求广泛，但现有不规则物体装箱工作主要面向理想接触的仿真，将物体视为孤立刚体，抓取器最多作为离散的事后可行性检查，且未处理执行过程中累积的感知与接触漂移。
Insight（核心洞察）
将物体与抓取器建模为单一复合刚体（分层球树），可让放置优化直接考虑抓取器占位；配合力监测下降与释放后推挤整合，并在每次放置后重新感知容器，可缓解漂移并提升真实场景的装箱密度与成功率。
Challenge（技术挑战）
  • 不规则物体在真实操作中的密集装箱
  • 抓取器与物体共同占位对放置可行性的影响
  • 执行过程中感知与接触漂移的累积
  • 抓取器感知规划留下的残余侧向间隙
  • 在真实机械臂上实现闭环感知与力引导执行的集成

Method（方法）
  • 闭环流水线集成感知、抓取器感知放置优化与力引导执行。
  • 优化器将物体与抓取器表示为单一复合体，采用分层球树结构。
  • 在 GPU 上以 CMA-ES 框架搜索五个自由度，竖直坐标根据当前高度图解析地确定。
  • 执行阶段采用力监测的竖直下降，在首次接触时停止。
  • 释放后进行整合推挤，以消除抓取器感知规划留下的残余侧向间隙。
  • 每次放置之间重新感知容器，避免漂移累积。
Experiments（实验）
  • 在 Franka Emika Panda 机器人上验证系统，装箱对象包括 3D 打印的扁平、弯曲和凹形物体集合以及 YCB 物体子集。
  • 消融研究隔离抓取器感知优化、整合推挤和网格派生几何对端到端成功率、达到的密度和计算成本的贡献。
  • 以高度图最小化方法作为先前不规则物体装箱工作的基线进行对比。

现有不规则物体装箱工作多面向理想接触仿真，将物体视为孤立刚体，抓取器最多作为事后可行性检查。：Existing work on irregular-object packing largely targets simulation with idealized contact, treating the object as an isolated rigid body. The gripper often enters as a discrete, post-hoc feasibility check, if considered at all
论文提出闭环流水线，集成感知、抓取器感知放置优化与真实机械臂上的力引导执行。：We present a closed-loop pipeline that integrates perception, gripper-aware placement optimization, and force-guided execution on a real manipulator.
优化器将物体与抓取器表示为单一复合体，使用分层球树，并在 GPU 上以 CMA-ES 搜索五个自由度。：The optimizer represents the object together with the gripper as a single composite body of hierarchical sphere trees. It searches over five degrees of freedom on a GPU within a CMA-ES framework
执行阶段采用力监测的竖直下降并在首次接触停止；释放后进行整合推挤以消除残余侧向间隙；每次放置之间重新感知容器。：During execution, a force-monitored vertical descent stops on first contact. A post-release consolidation push then closes the residual lateral clearance that gripper-aware planning leaves behind. The container is re-perceived between placements so that drift does not accumulate.
在 Franka Emika Panda 机器人上验证，并对抓取器感知优化、整合推挤和网格派生几何进行消融，同时与高度图最小化基线对比。：We validate the system on a Franka Emika Panda robot packing a 3D-printed set of flat, curved, and concave objects, and a YCB object subset. An ablation study isolates the contribution of gripper-aware optimization, the consolidation push, and mesh-derived geometry to end-to-end success, achieved density, and computational cost. We further benchmark against the heightmap-minimization method as a baseline representative of prior irregular-object packing work.
