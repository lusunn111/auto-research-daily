Are Frontier VLM Agents Ready to Be Robot Generalists? An Empirical Study with the Embodied Agent Arena

Haojian Huang · Pukun Zhao · Zexi Li · Yehang Zhang · Yangkai Wei · Wenqian Li · Han Yang · Kaiwen Zhou · Ying-Cong Chen · Yinchuan Li

核心洞察

闭源权重模型在五个领域全面领先，开源权重模型空间推理尚可用但规划与操作成功率明显偏低；平均分数掩盖了质的不同失败模式——相似几何误差背后是尺度与形状扭曲的差异，有效区域估计不等于可用的动作点；执行中会出现早期子目标达成却丢失物体控制、把动作绑定到错误接收区域、或在所需物理状态成立前停止。

为什么值得看：该文给出系统性的智能体级失败分类学，有助于研究者在设计 VLA 与世界动作模型时明确“感知正确≠可执行”的落差，并提示推理时计算扩展与自我复核的风险；其 GeoProbe 与匹配轨迹方法也可迁移到自身评测体系设计中。

Setting（研究设定）
构建名为 Embodied Agent Arena 的评测场，覆盖几何、空间推理、可供性、任务规划与操作五个领域，评测十个 VLM 智能体；共 1000 个用例，整合 32 个已有来源与自建的 GeoProbe（168 例，针对相机、运动、深度与尺度估计）；采用最小化测试框架，任务决策交由模型通过源生接口完成。
Motivation（研究动机）
机器人通才需要理解场景、据此行动并满足任务的全部条件，作者想实证检验前沿 VLM 在多大程度上满足这些要求，以及额外计算能否弥补失败。
Insight（核心洞察）
闭源权重模型在五个领域全面领先，开源权重模型空间推理尚可用但规划与操作成功率明显偏低；平均分数掩盖了质的不同失败模式——相似几何误差背后是尺度与形状扭曲的差异，有效区域估计不等于可用的动作点；执行中会出现早期子目标达成却丢失物体控制、把动作绑定到错误接收区域、或在所需物理状态成立前停止。
Challenge（技术挑战）
  • 几何估计中的尺度与形状扭曲难以从平均误差中区分
  • 区域有效性与可操作动作点之间的鸿沟
  • 长时序执行中物体控制丢失与动作—接收区域错误绑定
  • 过早停止，未达到任务要求的物理状态
  • 额外计算并不一致地修复失败：代码修复可能恢复执行但未完成任务，自我复核可能推翻正确判断
  • 失败代价分布不均：最强规划者把失败 token 集中在长时间本体控制任务上，其他模型则广泛失败
Analyze（问题分析）
作者通过统一的最小化测试框架在五个能力域上对十个 VLM 智能体做多源聚合评测，并借助自建 GeoProbe 补足相机、运动、深度、尺度估计维度；进一步对失败模式做细粒度剖析（几何误差分解、区域与动作点关系、执行期失败类型、计算投入效果、失败 token 成本分布），并用匹配轨迹分析成功恢复如何利用反馈补足缺失前提。
Method（方法）
  • 提出 Embodied Agent Arena 五域评测框架（几何、空间推理、可供性、任务规划、操作）
  • 聚合 32 个已有评测来源共 1000 例
  • 构建 GeoProbe：168 例相机、运动、深度与尺度估计基准
  • 采用最小化测试框架，让模型通过源生接口自行做任务决策
  • 对失败进行分层分析：几何误差结构、区域—动作点、执行期错误、计算扩展效果、失败 token 成本
  • 用匹配轨迹对比成功恢复与失败路径
Experiments（实验）
  • 十个 VLM 智能体在五个领域上评测；闭源权重模型在全部五个领域领先
  • 开源权重 VLM 表现出可用的空间推理，但规划与操作成功率显著更低
  • 相似的平均几何误差下隐藏不同的尺度与形状扭曲
  • 有效的区域估计不必然给出可用的动作点
  • 执行期可观察到：达成早期子目标后失去物体控制、动作绑定到错误接收区域、在所需物理状态成立前停止
  • 额外计算并非普遍有效：代码修复可恢复执行但不完成任务，自我复核可反转正确判断
  • 最强规划者将失败 token 支出集中在长时间本体控制任务；其他模型在流程上广泛失败
  • 匹配轨迹显示成功恢复利用反馈补足缺失前提并推进剩余任务
