Setting（研究设定）
在机器人操作任务中，基于预训练世界动作模型（Motus）和 StarVLA 策略，仅微调少量参数，利用冻结跟踪模型提供的对应关系将历史视觉特征对齐到当前位置，计算时序残差以增强当前视觉条件。
Motivation（研究动机）
比较当前与过去观测有助于机器人理解场景变化并选择动作，但直接在同一图像位置比较视觉特征会在物体或相机移动时混入不同场景内容。
Insight（核心洞察）
对应关系应决定哪些历史内容与当前内容进行比较，而非作为独立的轨迹表示进入策略；通过对应对齐的时序残差可以参数高效地补充当前视觉条件。
Challenge（技术挑战）
  • 物体和相机运动导致同一图像位置的特征内容不匹配
  • 在冻结预训练骨干下高效注入时序信息
  • 将时序残差有效门控并整合到现有策略中
Analyze（问题分析）
作者指出直接在同一图像位置比较视觉特征会混合不同场景内容，因此提出使用冻结跟踪模型的对应关系将历史特征迁移到当前位置后再计算有符号差异。
Method（方法）
  • TraceDelta 模块使用冻结跟踪模型提供的对应关系，将历史视觉特征迁移到当前位置
  • 在共享预训练特征空间中计算有符号差异
  • 轻量适配器将差异转换为有效性门控的残差，补充当前视觉条件
  • 基于 Motus，保持预训练骨干权重冻结，仅优化 1.59M 参数
  • 将 TraceDelta 集成到基于 StarVLA 的策略中以验证可迁移性
Experiments（实验）
  • 在 50 个 RoboTwin 2.0 任务上，使用 5,000 次更新适配预算，CoRe-WAM 达到 92.22% 干净成功率，比 Motus 高 3.56 个百分点
  • 在随机化评估中达到 89.60% 成功率，提升 2.58 个百分点
  • 将 TraceDelta 集成到基于 StarVLA 的策略，干净成功率从 58.10% 提升到 67.62%
Limitations（局限）

直接在同一图像位置比较视觉特征会混合不同场景内容。：However, comparing visual features at the same image location can mix different scene content when objects or the camera move.
TraceDelta 使用冻结跟踪模型的对应关系将历史视觉特征迁移到当前位置后计算有符号差异。：Its TraceDelta module uses correspondences from a frozen tracking model to transport historical visual features to current locations before computing signed differences in a shared pretrained feature space.
对应关系决定哪些历史内容与当前内容比较，而非作为独立轨迹表示进入策略。：Correspondence thus determines which historical content is compared with the present, rather than entering the policy as a separate trajectory representation.
轻量适配器将差异转换为有效性门控残差以补充当前视觉条件。：A lightweight adapter converts these differences into validity-gated residuals that supplement current visual conditioning, allowing the policy to use recent changes alongside current-scene information.
基于 Motus，保持预训练骨干冻结并优化 1.59M 参数。：Built on Motus, CoRe-WAM keeps the pretrained backbone weights frozen and optimizes 1.59 million parameters.
在 50 个 RoboTwin 2.0 任务上取得 92.22% 干净成功率，比 Motus 高 3.56 个百分点。：With a 5,000-update adaptation budget, CoRe-WAM achieves 92.22% clean success across 50 RoboTwin 2.0 tasks, 3.56 percentage points above Motus;
随机化评估达到 89.60% 成功率，提升 2.58 个百分点。：on randomized evaluation, it achieves 89.60% success, a 2.58-point gain.
将 TraceDelta 集成到 StarVLA 策略，干净成功率从 58.10% 提升到 67.62%。：Integrating TraceDelta into a StarVLA-based policy improves clean success from 58.10% to 67.62%, supporting transfer of the temporal interface beyond Motus.
