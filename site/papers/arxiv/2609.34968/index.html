Setting（研究设定）
多客户端联邦学习环境下，各客户端拥有稀缺、机构隔离且任务异构的物理交互数据，需在不交换全模型更新的前提下适配共享基础世界动作模型。
Motivation（研究动机）
视觉语言动作模型与世界动作模型受限于物理交互数据稀缺、机构隔离和任务异构，联邦学习结合参数高效微调是可避免交换全模型更新的自然方案，但直接聚合适配器会纠缠不兼容更新，而将 MoE 风格路由引入联邦聚合可能稀释专精化并破坏专家选择稳定性。
Insight（核心洞察）
可以把客户端本地训练的 LoRA 适配器直接安装为服务器端 MoE 的专家分支，使服务器路由器在这些先验知识分支上学习 token 分配，并联合优化路由与专家参数，从而在联邦框架内实现结构化专家组装。
Challenge（技术挑战）
  • 直接聚合不同客户端的适配器会纠缠不兼容的更新
  • 将 MoE 风格路由纳入联邦聚合可能稀释专家专精化
  • 专家选择可能不稳定
  • 需在保持个性化分发的同时将完整专家更新压缩为紧凑全局适配器

Method（方法）
  • 提出 RoboFL，为联邦世界动作学习实例化 MoSAIC（Mixture of Slotted Adapters）
  • MoSAIC 将本地训练的 LoRA 适配器直接安装为服务器 MoE 的专家分支
  • 服务器路由器在这些先验知识分支上学习 token 分配，并联合优化路由与专家参数
  • 引入 Foresight-to-Action Routing Distillation (FARD)，对齐模型三条路径上的路由
  • 引入 Path-Consensus Expert Aggregation (PCEA)，将完整专家更新转换为紧凑全局适配器用于个性化再分发
Experiments（实验）
  • 在 RoboTwin 2.0、RLBench 以及真实世界 Franka 机械臂上进行实验
  • 在 Franka 机械臂上比集中式 PEFT InternVLA-A1 高出 12.23%
  • 相对于基于 MoE 的联邦 VLA 基线，每轮客户端通信降低最多 86.81%

服务器路由器学习 token 分配并联合优化路由与专家参数：Server-side routers learn token assignments over these prior-informed branches while jointly refining routing and expert parameters.
FARD 用于对齐模型三条路径上的路由：Foresight-to-Action Routing Distillation (FARD) aligns routing across the model's three paths
PCEA 将完整专家更新转换为紧凑全局适配器用于个性化再分发：Path-Consensus Expert Aggregation (PCEA) converts complete expert updates into a compact global adapter for personalized redistribution.
