Where Memory Belongs: Ledger, an Object Ledger for Memory-Augmented VLAs

核心洞察

记忆类型决定记忆应当存放的位置：短期感知记忆（重复、计时、回溯）适合放在策略内部，而长期对象记忆（持久空间状态、包含关系、事件历史）应当放在策略外部，作为显式、可读的记录。

为什么值得看：该工作提出清晰的记忆分层原则，并用单一权重在 RoboMME 上取得显著提升，对研究长时序 VLA、外部记忆与世界动作模型状态表示的研究者具有直接借鉴意义。

Setting（研究设定）
长时序、部分可观测的机器人操作任务，需要机器人记住物体放置位置、物体归属以及动作周期计数等信息；在 RoboMME 基准上进行评测。
Motivation（研究动机）
记忆对长时序部分可观测操作至关重要，但现有将记忆直接嵌入策略内部的 VLA 方法在基准上没有任何单一策略内机制能覆盖全部时空维度，且与 oracle 方法差距很大。
Insight（核心洞察）
记忆类型决定记忆应当存放的位置：短期感知记忆（重复、计时、回溯）适合放在策略内部，而长期对象记忆（持久空间状态、包含关系、事件历史）应当放在策略外部，作为显式、可读的记录。
Challenge（技术挑战）
  • 策略内记忆机制无法覆盖所有时空维度
  • 长期对象记忆需要持久、可读、可维护的外部表示
  • 需要在运行时从指令和记录中决定记忆来源，避免任务级路由器
  • 用单一组权重同时服务多种记忆需求
Analyze（问题分析）
作者通过对比现有策略内记忆机制在基准上的表现，指出没有单一机制覆盖所有时空维度并大幅落后于 oracle 方法，据此提出按记忆类型划分记忆归属的分析框架。
Method（方法）
  • 将记忆拆分为策略内短期感知记忆与策略外长期对象记忆
  • 在单个微调后的 π_{0.5} 策略上实现该划分
  • 策略内使用帧采样记忆
  • 外部构建对象账本（ledger），由 SAM3 跟踪器和 VLM 描述器从演示中构建
  • 由 LLM 规划器在步骤边界读取账本并决策
  • 运行时根据指令与记录选择记忆来源，无需任务级路由器
Experiments（实验）
  • 在 RoboMME 上，Ledger 在评估方法中达到最高的四套件平均 64.3%（最强先前方法在相同评估下为 45.9%）
  • 对象指代 60.7%（对比 40.3%）
  • 对象恒存性 86.7%（对比 56.2%）
  • 使用单一组权重
Limitations（局限）
  • 材料未说明
与你的研究关系
直接涉及具身智能与 VLA 的可执行动作生成与长时序预测：通过将长期对象记忆外置为可读账本并结合 LLM 规划器，缓解策略内记忆的时空覆盖不足，改善长时序操作中的状态持久性与对象指代，对世界模型式的持久状态建模与实时系统设计具有参考价值。
