Setting（研究设定）
从一个预训练的通用 VLA 策略出发，在 16 台双臂机器人组成的机队上跨八个真实世界操作任务进行持续后训练；任务包括语义杂货补货和 3 至 5 分钟长时序任务。利用部署过程中采集的自主 rollout 与人类干预构成共享物理经验，形成部署、共享经验、策略改进、再部署的闭环。
Motivation（研究动机）
通用机器人策略受益于大规模预训练，但仅靠离线数据不足以支撑稳健的真实世界部署。部署中的机器人会遇到分布偏移、长尾失败、任务变化以及人类纠正机会，这些是固定示范数据集无法完全覆盖的。
Insight（核心洞察）
部署阶段本身可以成为持续学习的数据来源：通过机队规模地汇聚自主 rollout 和人类干预形成的异构稀疏奖励经验，并在离线到在线强化学习中稳定地改进预训练 VLA 策略，使单一通用策略随经验累积而提升。
Challenge（技术挑战）
  • 从异构、稀疏奖励的机队数据中稳定学习
  • 部署环境中的分布偏移与长尾失败
  • 长时序任务的持续改进
  • 在基于流的 VLA 动作生成器上进行策略提取
  • 跨机队共享经验并闭环回部署

Method（方法）
  • 提出 Learning While Deploying（LWD）框架，用于通用 VLA 策略的持续后训练，属于机队级离线到在线强化学习框架
  • 以预训练 VLA 策略为起点，闭合部署、共享物理经验、策略改进与再部署之间的循环
  • 使用跨机器人机队采集的自主 rollout 与人类干预作为学习数据
  • 采用 Distributional Implicit Value Learning（DIVL）进行稳健的价值估计，以应对异构、稀疏奖励的机队数据
  • 采用 Q-learning via Adjoint Matching（QAM）在基于流的 VLA 动作生成器中进行策略提取
Experiments（实验）
  • 在由 16 台双臂机器人组成的机队上验证 LWD，覆盖八个真实世界操作任务
  • 任务包括语义杂货补货和 3 至 5 分钟长时序任务
  • 单一通用策略随机队经验累积而提升，平均成功率达到 95%
  • 在长时序任务上获得最大增益

论文提出 LWD，一个面向通用 VLA 策略持续后训练的机队级离线到在线强化学习框架：We present Learning While Deploying (LWD), a fleet-scale offline-to-online reinforcement learning framework for continual post-training of generalist Vision-Language-Action (VLA) policies.
动机是离线数据不足以支撑稳健的真实世界部署：Generalist robot policies increasingly benefit from large-scale pretraining, but offline data alone is insufficient for robust real-world deployment.
方法通过部署、共享物理经验、策略改进与再部署的闭环利用自主 rollout 和人类干预：LWD closes the loop between deployment, shared physical experience, policy improvement, and redeployment by using autonomous rollouts and human interventions collected across a robot fleet.
方法结合 DIVL 进行稳健价值估计，并用 QAM 在基于流的 VLA 动作生成器中进行策略提取：LWD combines Distributional Implicit Value Learning (DIVL) for robust value estimation with Q-learning via Adjoint Matching (QAM) for policy extraction in flow-based VLA action generators.
实验在 16 台双臂机器人、八个真实世界操作任务上验证，平均成功率达到 95%，长时序任务增益最大：We validate LWD on a fleet of 16 dual-arm robots across eight real-world manipulation tasks, including semantic grocery restocking and 3--5 minute long-horizon tasks. A single generalist policy improves as fleet experience accumulates, reaching an average success rate of 95%, with the largest gains on long-horizon tasks.
