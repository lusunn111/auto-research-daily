HexaShell：探索 VLM 智能体作为机器人编程智能体极限的轻量外壳

HexaShell: A Thin Harness for Exploring the Limits of VLM Agents as Robot Coding Agents

Hongcheng Gao · Alex Zhou · Jay Zhu · Zelin Zheng · Shijia Ge · Xiping Li · Di Wu · Yazhe Wang · Jianshu Zeng · Xuan Shangguan · Yongli Wang · Yexing Wan · Lingyu He · Zhiqi Jia · Sihang Wu · Xiao He

核心洞察

保持 harness 尽量薄（只负责把命令转换为机器人运动），把智能体的能力集中到“把经验固化成可复用代码工具”上；工具只使用机器人可观测的信息，通过三角测量与平面求交来做几何定位，并在头部相机信息不足时移动腕部相机获取第二视角。

Setting（研究设定）
用一个轻量级 harness 将 VLM 编程智能体（Codex + GPT-6-Astra，中等推理强度）接入双臂机器人；该机器人配有三路 RGB 相机，并已知相机标定信息。智能体通过单一命令行发给机器人命令，在每次失败后读取日志、诊断原因，并编写或修复小型程序（工具），从而以代码形式积累经验。
Motivation（研究动机）
作者追问：当编程智能体控制的是机器人而非计算机时，这类智能体能够走多远，又会在哪里止步；同时希望在不依赖学习型策略的情况下，检验 VLM 智能体在机器人操作排行榜上的竞争力。
Insight（核心洞察）
保持 harness 尽量薄（只负责把命令转换为机器人运动），把智能体的能力集中到“把经验固化成可复用代码工具”上；工具只使用机器人可观测的信息，通过三角测量与平面求交来做几何定位，并在头部相机信息不足时移动腕部相机获取第二视角。
Challenge（技术挑战）
  • 在仅有观测信息条件下实现可靠的物体相对定位
  • 失败后从日志中自动诊断原因并修复代码工具
  • 双臂机器人与多相机标定下的运动执行
  • 接触密集型任务（如紧配合插入）的精细运动控制
  • 工具在未见布局上的泛化
Analyze（问题分析）
作者从任务表现的结构性差异入手分析能力边界：指出限制在于接触而非推理，并给出不同任务类别的成功率作为对比证据。材料未说明更细粒度的误差分析或失败模式分类方法。
Method（方法）
  • 构建轻量 harness，只把智能体命令转换为机器人运动
  • 智能体通过单条命令行驱动双臂机器人，接收三路 RGB 相机输入并使用已知标定
  • 失败后读取日志、定位原因，并编写或修复小型程序工具
  • 以代码形式保留学到的能力，类似编程智能体修复失败测试
  • 工具仅使用机器人观测，采用三角测量求物体相对位置与相对夹爪位置
  • 利用已知平面（桌面、方块顶面）与射线求交定位点
  • 头部相机不足时移动腕部相机获取第二视角
  • 仅在单任务单种子的十种布局上构建工具，随后冻结工具并在同种子十种新布局上测试
  • 使用 Codex 搭配 GPT-6-Astra，中等推理强度
Experiments（实验）
  • 在全部 42 个 RoboDojo 任务上，HexaShell 达到 39.7% 成功率与 48.0 进度分（按排行榜相同方式平均），作者称其为 RoboDojo 新 state of the art
  • 按任务类别：pushing 达 92.5%，memory 任务 65.0%，紧配合插入仅 8.3%
  • 工具在单任务单种子的十种布局上构建后冻结，并在同种子十种新布局上测试
  • 失败时智能体通常能看见失败，但无法让运动奏效
Limitations（局限）
  • 限制在于接触而非推理；紧配合插入等接触密集任务成功率很低
  • 智能体虽然能看到失败，但往往无法让运动执行成功
与你的研究关系
该工作直接关联具身智能中的可执行动作生成与真实机器人评测：用 VLM/VLA 风格的编程智能体生成可执行动作程序；其“把经验固化为代码工具”的机制与长时序任务中的技能复用、推理效率（薄 harness、不做策略学习）相关；其接触密集型任务的失败揭示了从语言与视觉推理到物理精细控制的差距，对世界模型与物理人工智能中接触动力学建模有提示意义。但与模型压缩、实时控制频率等系统优化主题关联较弱。

系统采用薄 harness，只把智能体命令转成机器人运动：Our system, HexaShell, keeps the harness thin: it only turns the agent's commands into robot motion.
失败后智能体读日志、找原因并编写或修复代码工具：After each failed attempt, the agent reads the log, finds the cause, and writes or fixes small programs called tools.
工具仅使用机器人观测，并用三角测量与平面求交定位：The tools may use only what the robot observes. They use triangulation to find where objects are, relative to each other and to the gripper.
在 42 个 RoboDojo 任务上成功率为 39.7%、进度分 48.0，并称达到新 SOTA：On all 42 RoboDojo tasks, HexaShell reaches a success rate of 39.7% and a progress score of 48.0, averaged in the same way as the leaderboard. This is a new state of the art on RoboDojo.
瓶颈在接触而非推理，紧配合插入仅 8.3%：The limit is contact, not reasoning: pushing reaches 92.5% and memory tasks 65.0%, but tight insertion only 8.3%.
