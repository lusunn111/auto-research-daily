何时何物重要：视觉运动模仿策略中条件视觉接地问题的诊断与改进

What Matters, When? Diagnosing and Improving Conditional Visual Grounding in Visuomotor Imitation Policies

Vivek Chavan · Pengtao Xie · Yahuan Shi · Oliver Heimann · Kevin Haninger · J\"org Kr\"uger

核心洞察

将视觉失败视为条件视觉接地问题，区分了策略失去操作能力与保留运动能力但应用于错误实体两种情况，通过诊断确定失败与特定视觉线索和操作阶段相关。

为什么值得看：提供了条件视觉接地框架，系统诊断视觉干扰物导致的失败，提出轻量级干预方法，并跨ACT和VLA验证，对改进具身智能在复杂视觉环境下的可靠操作具有指导价值。

Setting（研究设定）
模拟和真实机器人（UR3e）上的抓取放置任务及状态条件仪器操作任务
Motivation（研究动机）
视觉运动模仿策略在受控环境中表现良好，但当视觉上相似的物体或容器引入时，策略可能选择错误的实体导致任务失败，而聚合成功率无法区分是执行能力丧失还是错误选择目标。
Insight（核心洞察）
将视觉失败视为条件视觉接地问题，区分了策略失去操作能力与保留运动能力但应用于错误实体两种情况，通过诊断确定失败与特定视觉线索和操作阶段相关。
Challenge（技术挑战）
  • 视觉上相似的干扰物导致目标选择错误
  • 任务相关性随操作阶段和状态变化
  • 在保持控制所需空间信息的同时改善目标选择
Analyze（问题分析）
作者通过系统地引入受控颜色和形状相似度的干扰物，对ACT策略进行诊断，并使用分阶段的成功率指标（如拾取、提升、放置）定位失败阶段，同时检查学习到的视觉表征变化。
Method（方法）
  • 对ACT进行阶段条件相关性分析，区分拾取阶段目标物体和放置阶段容器的重要性
  • 提出图像空间复制粘贴增强，在干净演示中插入合成干扰物
  • 设计阶段相关注意力正则化，监督解码器交叉注意力头关注当前相关对象并远离干扰物
  • 引入基于外观的视觉提示，提供目标物体和容器的无位置裁剪，并训练阶段预测器选择适当提示
  • 在ACT和预训练VLA上应用诊断-干预原则
Experiments（实验）
  • 在模拟和物理UR3e上，干预措施显著提高了鲁棒性
  • 在预训练视觉语言动作策略的状态条件仪器操作任务上，识别出相同的失败模式并验证了诊断干预原则
  • 详细实验数字未在提供的材料中明确给出
Limitations（局限）
  • 观察到的ACT颜色-形状层级特定于评估的资产，需要完全平衡的视觉因素验证
  • 带有提示的ACT变体获得额外目标信息，但仅增强的结果也显示出显著的鲁棒性提升
  • 注意力和表征分析是相关性的
  • 硬件评估每个条件仅20次试验
  • 探索性VLA研究每个子目标仅5次试验且指导条件不等价
  • VLA任务使用可见污染替代物和固定路由规则，而非通用污染理解
与你的研究关系
揭示视觉运动策略中视觉干扰物导致的选择错误，提出干预方法，与具身智能和视觉语言动作模型中的鲁棒执行相关，通过诊断和干预改进目标选择，提升系统鲁棒性。
证据与不确定性

具体实验数值和部分细节未在摘要或节选中明确，但根据摘要和节选内容可推断研究结论和局限；通讯作者标记基于脚注推断。

视觉运动模仿策略在分布内条件下表现良好，但视觉相似对象引入时失败：Visuomotor imitation policies can achieve high performance under in-distribution visual conditions yet fail when visually similar objects or receptacles are introduced.
视觉目标随操作阶段和任务状态变化：the visual target required for successful control changes with the manipulation phase and, in more complex tasks, with the observed task state
干扰物敏感性取决于视觉相似性和操作阶段：We find that distractor sensitivity is specific to both the type of visual similarity and the manipulation stage.
多种干预措施提高鲁棒性：These interventions substantially improve robustness in simulation and on a physical UR3e.
VLA策略也存在相同失败模式：We further examine the same failure pattern in a pretrained vision-language-action policy on a state-conditioned instrument-handling task
底层操作技能完好的情况下视觉干扰物可导致错误目标选择：visual distractors can cause incorrect object or destination selection even when the underlying manipulation skill remains intact
