Le Chen · Lixin Liu · Jan Schneider · Zeju Qiu · Simon Guist · Bernhard Sch\"olkopf · Dieter B\"uchler

核心洞察

将编码智能体与可复用的优化指导、测量和验证工具结合，形成瓶颈驱动的工作流，让智能体自动剖析推理、修改代码、验证效果并迭代优化，就能在保持动作质量的前提下自动生成加速栈。

为什么值得看：对关注具身智能与世界动作模型部署的研究者，本文提供了用编码智能体自动进行瓶颈驱动推理加速的系统化方法，并在多模型、多智能体、多 GPU 架构上验证了最高 9.95 倍无损加速和相当的任務成功率，兼具方法迁移价值与工程参考意义。

Setting（研究设定）
面向机器人操作的世界动作模型（WAM）部署场景，WAM 利用预训练视频基础模型进行视频-动作联合预测，但骨干网络大、联合预测开销高。研究设定为在多种 WAM、多种编码智能体和多种 GPU 架构上自动生成推理加速栈。
Motivation（研究动机）
现有加速技术虽然多样，但针对每个模型和硬件平台选择与组合这些技术需要大量工程工作，构成 WAM 部署的瓶颈。作者希望降低这一工程门槛，自动产出有效的加速方案。
Insight（核心洞察）
将编码智能体与可复用的优化指导、测量和验证工具结合，形成瓶颈驱动的工作流，让智能体自动剖析推理、修改代码、验证效果并迭代优化，就能在保持动作质量的前提下自动生成加速栈。
Challenge（技术挑战）
  • WAM 骨干网络大，视频-动作联合预测计算开销高
  • 加速技术的选择与组合依赖模型和硬件平台，工程成本高
  • 在加速的同时需要保持动作质量（lossless 或 comparable success rates）
  • 瓶颈会随优化过程迁移，需要迭代调整加速策略
Analyze（问题分析）
材料未说明具体分析方式，仅从摘要可知作者以瓶颈驱动工作流来组织优化：先剖析推理瓶颈，再针对性修改代码、验证效果并迭代精炼。未提供更细粒度的分析细节。
Method（方法）
  • 提出 WAMJET，一个智能体化 harness（agentic harness），用可复用的优化指导与测量、验证工具装备编码智能体
  • 采用瓶颈驱动工作流：智能体剖析推理、定位并修改目标代码、验证效果、随瓶颈迁移迭代精炼加速栈
  • 在加速过程中保持动作质量
  • 实验覆盖六种 WAM、三种编码智能体与两种 GPU 架构
Experiments（实验）
  • 实验覆盖六个 WAM、三个编码智能体和两种 GPU 架构
  • 相对上游实现取得最高 9.95 倍的无损加速（up to 9.95x lossless speedup）
  • 近似与硬件感知优化带来额外延迟降低，成功率相当（comparable success rates）
  • 结果表明 WAMJET 能为 WAM 部署产出有效的加速栈

WAMJET 是一个用于加速世界动作模型推理的智能体化框架：we present WAMJET, an agentic harness that accelerates WAM inference by equipping coding agents with reusable optimization guidance and measurement and validation tools
WAM 利用预训练视频基础模型进行机器人操作，但大型骨干网络与视频-动作联合预测开销高昂：World Action Models (WAMs) leverage pretrained video foundation models for robot manipulation, but their large backbones and video-action co-prediction are expensive
现有加速技术的选择与组合需要针对每个模型和硬件平台做大量工程：selecting and composing them requires substantial engineering for each model and hardware platform
WAMJET 采用瓶颈驱动工作流，剖析、修改、验证并迭代优化，同时保持动作质量：WAMJET follows a bottleneck-driven workflow where the agent profiles inference, modifies targeted code, validates effects, and iteratively refines the acceleration stack as bottlenecks shift, while preserving action quality
实验覆盖六个 WAM、三个编码智能体和两种 GPU 架构，取得最高 9.95 倍无损加速：Experiments span six WAMs, three coding agents, and two GPU architectures. WAMJET achieves up to 9.95x lossless speedup over upstream implementations
