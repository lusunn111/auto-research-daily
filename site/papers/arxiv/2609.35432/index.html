自我进化的编码智能体：从数字程序到物理世界智能

Self-Evolving Coding Agents: From Digital Programs to Physical-World Intelligence

Hongcheng Gao · Jingjing Zhou · Zelin Zheng · Shijia Ge · Jay Zhu · Yazhe Wang · Jianshu Zeng · Xuan Shangguan · Di Wu · Lingyu He · Zhiqi Jia · Sihang Wu · Xiao He

核心洞察

数字编码智能体（LLM 调用工具、验证结果、依据反馈以可执行代码修正）提供了先例；显式状态、可控执行与可修订流程这一相同工作模式，同样构成物理世界泛化与长时序执行的基础，使物理经验可回流为可复用的程序、记忆或证据。

为什么值得看：它提出了一条从表示层解决 VLA/WAM 泛化与长时序脆弱性的路线：用可执行代码显式化任务状态与执行流程，并给出在 RoboCasa365、PhyBench 与真实双臂平台上的验证，以及 Harness 训练向模型权重内化的证据，对关注可执行动作生成、长时序执行、真实机器人评测与工具调用式智能体的研究者具有直接参考价值。

Setting（研究设定）
机器人操作与物理实验场景：在 RoboCasa365 基准、PhyBench 以及双臂 AgileX 真机上，将任务状态与执行过程表示为可执行代码，调用感知、规划、控制工具（含 VLA/WAM 策略）并由外部反馈在环决策。
Motivation（研究动机）
VLA 与 WAM 模型将观测和指令直接映射为动作，这种直接性把策略绑定到训练分布：布局或视角的微小变化即导致失败，指令泛化差。根因在于表示：任务需求、条件、进度与失败恢复都隐式编码在动作序列中，难以检查或修改。
Insight（核心洞察）
数字编码智能体（LLM 调用工具、验证结果、依据反馈以可执行代码修正）提供了先例；显式状态、可控执行与可修订流程这一相同工作模式，同样构成物理世界泛化与长时序执行的基础，使物理经验可回流为可复用的程序、记忆或证据。
Challenge（技术挑战）
  • 任务需求、条件、进度与失败恢复隐式编码在动作序列中，难以检查或修订
  • 对布局或视角的微小变化敏感，指令泛化差
  • 将数字编码智能体的工作模式迁移到物理世界，需要显式状态、可控执行与可修订流程
  • 让已验证的执行轨迹转化为可复用的数据与记忆，并进一步内化到模型权重、架构乃至硬件与任务设计
Analyze（问题分析）
作者将 VLA/WAM 的脆弱性归因于表示问题：任务状态与执行过程被隐式压在动作序列里，因此不可检查、不可修订、难以恢复；并类比数字编码智能体的可执行代码工作模式，论证在物理世界中同样需要显式状态、可控执行与可修订流程。
Method（方法）
  • 提出 Physical Coding：把任务状态与执行表示为代码
  • Code as World：记录对象、关系、约束与进度
  • Code as Policy：组织规划、验证、恢复与执行
  • 构建 HexaAnything：调用感知、规划与控制工具（包括 VLA/WAM 策略），基于外部反馈做在环决策
  • 将已验证的执行轨迹转化为数据与记忆，支持从工具与 Harness 向模型权重、架构，最终向硬件与任务设计的进化
Experiments（实验）
  • 在 RoboCasa365 上，HexaAnything 相比 XR-1 VLA 提升了 Composite-Unseen 与总体成功率
  • 经 Harness 训练的 HexaModel 在每一个 split 上都优于基座模型，表明代码轨迹内化了物理执行
  • 在 PhyBench 与双臂 AgileX 机器人上，该智能体自主完成物理实验与大多数桌面任务，且常快于已发表结果
  • 观察到数据、模型与工具层面的自我进化
Limitations（局限）
  • 材料提及未来工作目标，包括权重内化、架构/语言/表示/任务的自主重设计，以及在制造与科学场景的部署，暗示这些尚未实现
与你的研究关系
该工作直接面向具身智能与 VLA/WAM：以代码作为世界表示与策略表示，把 VLA/WAM 策略作为可调用工具嵌入在环决策，同时涉及长时序执行、失败恢复、工具调用与执行轨迹向模型权重的内化，与可执行动作生成、长时序预测、真实机器人评测高度相关；其 Harness 到模型权重的演进路径也与模型压缩与系统优化存在概念关联。
证据与不确定性

仅有标题与摘要，无全文与具体数值；成功率提升幅度、Harness 训练细节、自我进化的度量方式、真机任务数量与基线对比条件均不明确；第一单位与通讯作者未提供。

VLA/WAM 直接映射观测与指令到动作，导致对布局或视角变化敏感、指令泛化差：Vision-language-action (VLA) and world-action (WAM) models map observations and instructions directly to robot actions. This directness ties a policy to training: minor layout or viewpoint changes cause failure, and instructions generalize poorly.
根因在于表示：任务需求、条件、进度与失败恢复被隐式编码在动作序列中，难以检查或修订：The root cause lies in representation: task requirements, conditions, progress, and failure recovery are implicitly encoded in action sequences, making them difficult to inspect or revise.
论文提出 Physical Coding，把任务状态与执行表示为代码，并分为 Code as World 与 Code as Policy：We propose Physical Coding, representing task state and execution as code. Code as World records objects, relations, constraints, and progress; Code as Policy organizes planning, verification, recovery, and execution.
HexaAnything 调用感知、规划与控制工具（含 VLA/WAM 策略），基于外部反馈在环决策，已验证轨迹成为数据与记忆并支持逐层进化：We build HexaAnything, which calls perception, planning, and control tools, including VLA/WAM policies, and makes in-the-loop decisions from external feedback. Verified traces become data and memory, enabling evolution from tools and Harness to model weights, architectures, and ultimately hardware and task design.
在 RoboCasa365 上提升 Composite-Unseen 与总体成功率，Harness 训练的 HexaModel 在每个 split 上均优于基座：On RoboCasa365, HexaAnything improves Composite-Unseen and overall success over XR-1 VLA, and its Harness-trained HexaModel beats the base on every split, indicating code traces internalize physical execution.
在 PhyBench 与双臂 AgileX 真机上自主完成物理实验与多数桌面任务，且常快于已发表结果：On PhyBench and a dual-arm AgileX robot, the agent autonomously completes physics experiments and most tabletop tasks, often faster than published results.
作者观察到数据、模型与工具的自我进化，未来工作指向权重内化、架构/语言/表示/任务自主重设计及制造与科学部署：We observe data, model, and tool self-evolution; future work targets weight internalization, autonomous redesign of architectures, languages, representations, and tasks, and deployment in manufacturing and science.
