Setting（研究设定）
在仿真基准与真实硬件双臂灵巧操作任务上，对预训练的视觉-语言-动作模型进行微调，通过训练价值函数与优势条件化策略迭代提升任务成功率。
Motivation（研究动机）
已有优势条件化方法仅使用简单的成功/失败二值奖励，信息量低，导致价值函数只能区分任务进度，而无法区分处于相同进度的不同质量状态。
Insight（核心洞察）
以嵌入空间距离作为奖励，可以得到信息量更丰富的价值函数，并因此获得更高的下游任务成功率。这一思路受到对分布外（OOD）检测方法探索的启发。
Challenge（技术挑战）
  • 简单成功/失败奖励信息量不足，价值函数难以区分进度相同但质量不同的状态
  • 需要在不依赖人工密集奖励的前提下构造更具判别力的奖励信号
  • 需在仿真与真实双臂灵巧操作硬件上同时验证方法的有效性
Analyze（问题分析）
作者通过探索分布外（OOD）检测方法，识别出嵌入空间距离可作为区分状态质量的信号，并将其转化为奖励用于价值函数学习；具体分析过程材料未说明。
Method（方法）
  • 沿用优势条件化框架：在部署数据上训练价值函数，再用其训练优势条件化策略并迭代改进VLA
  • 引入基于距离的优势学习（DistAL）：使用嵌入空间距离作为奖励信号
  • 以该距离奖励训练价值函数，从而得到信息量更丰富的价值估计
  • 将改进后的价值函数用于训练优势条件化策略，提升下游任务成功率
Experiments（实验）
  • 在一系列仿真基准上验证方法
  • 在真实硬件上验证双臂灵巧操作任务
  • 摘要声称相比使用简单成功/失败奖励的先前方法，获得更高的下游任务成功率；具体数值未提供

论文聚焦于VLA的优势条件化微调：Advantage conditioning is a recent technique that iteratively improves VLAs by training a value function on deployment data and using this to train an advantage-conditioned policy.
先前方法仅使用简单二值奖励，信息量低，价值函数无法区分不同质量状态：Previous works have only applied simple, low-information success/failure rewards, which leave the value function unable to distinguish states of differing quality beyond how far along the task they appear.
方法灵感来源于对OOD检测方法的探索，以嵌入空间距离作为奖励：Motivated by an exploration of out-of-distribution (OOD) detection methods, we introduce Distance-based Advantage Learning (DistAL), which, by using an embedding space distance as a reward, produces a more informative value function and subsequently a higher downstream task success rate.
方法在仿真基准与真实硬件双臂灵巧操作任务上得到验证：We validate our method on a series of simulation benchmarks and dexterous bi-manual manipulation tasks on real hardware.
