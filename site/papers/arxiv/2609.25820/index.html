Setting（研究设定）
在统一的离散动作分词接口下，比较固定解析式表示（Temporal-DCT）、数据驱动线性表示（PCA）与非线性神经表示（自编码器），用于自回归视觉-语言-动作（VLA）模型；评估涵盖率失真分析、序列建模诊断与 LIBERO 闭环 rollout。
Motivation（研究动机）
动作表示在自回归 VLA 中通常主要通过重建保真度来评估，但作者质疑这种评估准则是否真能反映闭环控制所关心的表示性质。
Insight（核心洞察）
重建保真度本身不足以可靠地选择面向自回归控制的动作表示，需要联合评估几何保真度、序列可预测性、解码器稳定性与闭环性能。
Challenge（技术挑战）
  • 不同评估准则下动作表示排序会发生变化
  • 低重建误差可能伴随更差的 token 序列可预测性
  • 离散 token 扰动会带来解码器稳定性问题
  • 单一训练随机种子下策略排序可能反转，评估稳定性难以保证
Analyze（问题分析）
作者通过率失真分析、序列建模诊断与 3500 次 LIBERO rollout，在统一分词接口下比较三类动作表示，并观察表示排序如何随评估准则变化。
Method（方法）
  • 在统一 tokenization 接口下比较三类动作表示：固定解析式表示、数据驱动线性表示、非线性神经表示
  • 采用率失真分析评估表示的重建-码率特性
  • 进行序列建模诊断以评估 token 序列可预测性
  • 在 LIBERO 上执行 3,500 次闭环 rollout 进行策略训练与评测
  • 通过三个 policy-training seed 与 seed-42 匹配消融检验表示对策略性能的影响
Experiments（实验）
  • PCA 的名义重建误差低于 Temporal-DCT
  • PCA 产生更不可预测的 token 序列，并在三个已见任务策略训练 seed 上平均成功率低 3.0 个百分点
  • 在一个 seed 中策略排序发生反转
  • 在 seed-42 匹配消融中，自编码器进一步降低重建误差，但未取得最强策略，且对离散 token 扰动更敏感

动作表示常主要按重建保真度评估，但论文质疑其是否反映闭环控制真正重要的性质。：Discrete action tokenization is central to autoregressive vision-language-action (VLA) models, yet action representations are often evaluated primarily through reconstruction fidelity. We ask which representation properties actually matter for closed-loop control
在统一分词接口下比较了解析式、数据驱动线性与非线性神经三类表示。：comparing fixed analytical, data-driven linear, and nonlinear neural representations under a unified tokenization interface
表示排序会随评估准则变化。：representation rankings change with the evaluation criterion
PCA 重建误差低于 Temporal-DCT，但 token 序列更不可预测，且平均已见任务成功率低 3.0 个百分点。：PCA achieves lower nominal reconstruction error than Temporal-DCT, but produces less predictable token sequences and 3.0 percentage points lower mean seen-task success across three policy-training seeds
自编码器进一步降低重建误差却不产生最强策略，并对离散 token 扰动更敏感。：an autoencoder further reduces reconstruction error yet does not yield the strongest policy and exhibits greater sensitivity to discrete token perturbations
论文结论是重建保真度不足以可靠选择动作表示，需要联合评估多个准则。：These findings show that reconstruction fidelity alone cannot reliably select action representations for autoregressive control, motivating joint evaluation of geometric fidelity, sequence predictability, decoder stability, and closed-loop performance.
