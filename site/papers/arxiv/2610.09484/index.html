Setting（研究设定）
训练与评估交互式语言智能体需要丰富的用户交互，而真实人类反馈成本高、难扩展；论文用可扩展的模拟用户替代真实用户，并进一步把冻结的模拟器当作智能体的训练环境。
Motivation（研究动机）
现有智能体训练框架多依赖通用助手型 LLM 充当用户，其乐于助人的特性使其比真实用户更配合、更直白、行为更同质，因而既不像真实用户，也无法提供有价值的学习信号。
Insight（核心洞察）
需要专门定制的用户模拟器：以真实人机对话为训练数据，加入显式推理监督和来自真实交互的 13 种现实行为模式，使其既行为逼真又能作为智能体的有效训练环境。
Challenge（技术挑战）
  • 模拟用户既要接近真实用户行为，又要为智能体提供有用的学习经验
  • 通用助手 LLM 过于配合、表达过于直白、行为同质化
  • 真实人类反馈昂贵且难以规模化
  • 稀疏的任务奖励不足以提供密集监督信号
Analyze（问题分析）
作者通过引入 SOUL-Index、RealUserSim、SimulatorArena、Turing distance 等指标比较模拟用户的行为保真度与图灵距离，并通过在八个环境中与不同模拟器训练对比、在九个未见用户模拟器上评测，分析智能体的泛化能力；具体分析细节材料未说明。
Method（方法）
  • 构建 MIMESIS：在真实人机对话上训练的用户模拟器，带显式推理监督
  • 使用来自真实用户交互的 13 种现实行为模式
  • 冻结模拟器，让智能体与其交互并用多轮强化学习训练
  • 提出 Coached On-Policy Self-Distillation (CSD)：利用模拟器生成的私有推理轨迹和后续话语作为反馈
  • 由 coach 将反馈转成简明的 coaching notes，描述智能体如何更好预判用户需求并在交互中调整行为
  • 将反馈转化为 token 级的稠密监督，补充稀疏任务奖励
Experiments（实验）
  • 9B 模型的 SOUL-Index 为 65.7，超过最强前沿模型
  • 相比 RealUserSim 和 SimulatorArena 上最强基线 Claude-Opus-5，行为保真度提升 13.4 点，图灵距离降低 3.6 点
  • 在八个环境中，用 MIMESIS 训练得到的智能体性能优于用 GPT-5.5 训练，且在全部九个未见用户模拟器上均如此，显示对新用户模拟器更强的泛化能力
  • CSD 在全部九个评估用户模型上带来进一步增益

论文提出专门构建的用户模拟器 MIMESIS，在真实人机对话上训练并加入显式推理监督与 13 种现实行为模式：We introduce MIMESIS, a purpose-built user simulator trained on human conversations with explicit reasoning supervision and 13 realistic behavioral patterns derived from real user interactions.
通用助手 LLM 作为模拟用户过于配合、直白且行为同质：most agent-training frameworks rely on off-the-shelf assistant LLMs, whose helpfulness can make them overly cooperative, explicit, and behaviorally homogeneous compared with real users.
9B 模型 SOUL-Index 为 65.7，超过最强前沿模型：our 9B model achieves a SOUL-Index of 65.7, surpassing the strongest frontier model.
相比 Claude-Opus-5，行为保真度提升 13.4 点，图灵距离降低 3.6 点：MIMESIS improves behavioral fidelity by 13.4 points and reduces Turing distance by 3.6 points, respectively.
冻结模拟器后通过多轮强化学习训练智能体，在八个环境中优于 GPT-5.5，并在九个未见用户模拟器上泛化更好：Across eight environments, training with MIMESIS yields better agent performance than training with GPT-5.5 under all nine unseen user simulators, demonstrating stronger generalization to new user simulators.
CSD 将模拟器生成的推理轨迹与后续话语转化为稠密的 token 级监督：CSD turns this feedback into dense, token-level supervision beyond sparse task rewards, yielding further gains across all nine evaluation user models.
