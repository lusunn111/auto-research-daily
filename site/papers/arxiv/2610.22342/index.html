核心洞察

触觉不仅可以作为策略的部署输入，还可以作为可扩展的监督信号：预训练阶段用触觉手套导出的图像空间接触图和冻结 3D 几何教师特征监督视觉 token，推理时移除这些目标，使单一检查点同时支持纯视觉与触觉条件化部署。

为什么值得看：该工作给出触觉作为预训练监督而非仅部署输入的明确证据，并用同数据同算力的对照量化收益；其‘预训练加监督、推理去目标’的单检查点设计对关注 VLA/VTLA、灵巧操作与真实机器人评测的研究者具有直接可迁移的方法论价值，同时提供了新数据集与新基准。

Setting（研究设定）
通用机器人策略的预训练与部署：用大规模人类全手触觉数据与人第一视角视频、机器人数据、仿真数据联合预训练一个视觉-触觉-语言-动作模型，并在视觉单独任务与触觉条件化的真实机器人灵巧操作任务上评测。
Motivation（研究动机）
通用机器人策略受益于大规模视觉预训练，但在接触丰富的灵巧操作中，力、柔顺性和初始滑移难以从图像观测，纯视觉预训练存在明显不足。
Insight（核心洞察）
触觉不仅可以作为策略的部署输入，还可以作为可扩展的监督信号：预训练阶段用触觉手套导出的图像空间接触图和冻结 3D 几何教师特征监督视觉 token，推理时移除这些目标，使单一检查点同时支持纯视觉与触觉条件化部署。
Challenge（技术挑战）
  • 接触丰富灵巧操作中的力、柔顺性与初始滑移难以从图像观测
  • 触觉监督需与视觉 token 在空间上对齐
  • 单一检查点需兼容有无触觉的两种部署形态
  • 需要大规模全手触觉人类操作数据以支撑预训练
  • 缺乏同时覆盖纯视觉仿真与触觉真实机器人的统一灵巧操作基准
Analyze（问题分析）
材料未说明作者如何具体分析问题，仅从摘要可见其以‘触觉作为监督而非仅输入’的视角论证纯视觉预训练的不足，并通过同一数据与算力下保留/丢弃触觉的对比来分离触觉监督的贡献。
Method（方法）
  • 构建空间对齐的视觉-触觉-语言-动作（VTLA）模型 Spark-0，以两种互补方式使用触觉
  • 预训练阶段：由触觉手套导出图像空间接触图，并结合冻结 3D 几何教师的特征监督视觉 token，这些目标在推理时移除
  • 并行触觉通路编码区域力历史与 3D taxel 状态，用于条件化动作专家
  • 单一检查点支持纯视觉部署与触觉条件化部署
  • 构建 1,000 小时全手触觉人类操作数据集 HumanTouch，并与第一视角视频、机器人数据、仿真数据联合预训练
  • 发布 SparkArena，在同一灵巧本体上配对纯视觉仿真任务与触觉条件化真实机器人任务
Experiments（实验）
  • Spark-0 在 SparkArena 两条赛道均取得最高平均成功率
  • 在 Ego Humanoid Manipulation Benchmark 的全部八项聚合指标上排名第一
  • 与在相同数据和算力下丢弃触觉的纯视觉预训练相比，保留 1,000 小时 HumanTouch 触觉使 Ego Humanoid 上的纯视觉成功率从 52.5% 提升到 71.7%
  • 相同对比下，SparkArena-Real（部署时也使用触觉）成功率从 44.0% 提升到 52.0%

论文提出空间对齐的视觉-触觉-语言-动作模型 Spark-0，以两种互补方式使用触觉。：We present Spark-0, a spatially aligned vision-tactile-language-action (VTLA) model that uses touch in two complementary ways.
预训练阶段用触觉手套导出的图像空间接触图与冻结 3D 几何教师特征监督视觉 token，这些目标在推理时移除。：During pretraining, image-space contact maps derived from tactile gloves, together with features from a frozen 3D geometry teacher, supervise the visual tokens; these objectives are removed at inference.
触觉通路编码区域力历史与 3D taxel 状态以条件化动作专家，单检查点支持纯视觉与触觉条件化部署。：In parallel, a tactile pathway encodes regional force histories and 3D taxel states to condition the action expert. A single checkpoint therefore supports both vision-only and tactile-conditioned deployment.
构建了 1,000 小时全手触觉人类操作数据集 HumanTouch，并与第一视角视频、机器人数据和仿真联合预训练。：we build HumanTouch, a 1,000-hour dataset of full-hand tactile human manipulation, and pretrain Spark-0 on it together with egocentric video, robot data, and simulation.
发布 SparkArena，在同一灵巧本体上配对纯视觉仿真任务与触觉条件化真实机器人任务。：We also release SparkArena, which pairs vision-only simulated tasks with tactile-conditioned real-robot tasks on one dexterous embodiment.
