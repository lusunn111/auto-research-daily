Setting（研究设定）
面向同时输入音频、视频和文本的全模态大语言模型（Omni-LLMs），在推理阶段对其 KV 缓存进行超低位（2-bit）量化以降低显存开销。
Motivation（研究动机）
Omni-LLMs 同时处理音频、视频和文本，KV 缓存显存开销显著增长；KV 缓存量化在纯文本 LLM 中已是事实标准方法，但其在全模态 LLM 上的适用性尚未被探索。
Insight（核心洞察）
将基于旋转的 KV 缓存量化方法（以 TurboQuant 为代表）直接用于多模态缓存时会出现两个关键问题：时间维度上的 key 漂移（temporal key drift）与不同模态间 value 几何结构异质（heterogeneous value geometry）。
Challenge（技术挑战）
  • 多模态输入流中 key 表示随时间发生漂移，导致统一量化范围难以适配。
  • 不同模态的 value 表示几何分布不一致，共享旋转/量化策略效果受损。
  • 需要在不构建稠密 FP16 缓存的前提下完成低位缓存的注意力解码。
Analyze（问题分析）
作者以 TurboQuant 这一代表性旋转式 KV 缓存量化方法为对象，分析其在多模态缓存上的行为，并据此识别出 temporal key drift 与 heterogeneous value geometry 两个关键问题。
Method（方法）
  • (i) 在每个输入流的短窗口上设定 key 的量化范围，以应对时间维度上的 key 漂移。
  • (ii) 按模态分别对 value 进行旋转，以适配不同模态的 value 几何差异。
  • 整个框架无需训练（training-free）。
  • 提供融合的 Triton 解码核，在注意力计算过程中解包 2-bit 缓存，从而不再构建稠密的 FP16 KV 缓存。
Experiments（实验）
  • 在 Qwen2.5-Omni 与 Qwen3-Omni 上验证，OmniKVQuant 支持 2-bit KV 缓存。
  • 在七个音视频基准上大幅保持性能（摘要未给出具体数值）。

核心洞察

将任务感知压缩形式化为加权率失真问题：若每个分量的加权失真权重能编码任务重要性并可依赖信源，则可通过单一编解码器实现任务自适应；并引入“任务一致性”概念——最小化加权失真也最小化真实任务损失。

Motivation（研究动机）
传统有损压缩由任务无关失真（MSE、MS-SSIM）驱动，但许多新兴应用中接收端不关心均匀保真度，而关心信号中随时间变化的相关内容所服务的下游任务；同时逐任务重训练在带宽受限系统中不可行。
Insight（核心洞察）
将任务感知压缩形式化为加权率失真问题：若每个分量的加权失真权重能编码任务重要性并可依赖信源，则可通过单一编解码器实现任务自适应；并引入“任务一致性”概念——最小化加权失真也最小化真实任务损失。
Challenge（技术挑战）
  • 任务一致性的成立条件难以刻画：线性任务需在合适交叉项条件下任务损失才具有信号无关权重的加权 MSE 形式
  • 非线性任务缺乏直接理论保证，需借助积分梯度分析来启发可分任务感知权重
  • 任务对称性与任务无关性会进一步约束可容许的权重集合
  • 单一固定骨干需在运行时仅通过注入权重切换任务而无需重训练，且仍输出单份人类可看重建
Analyze（问题分析）
作者从率失真理论出发，把任务感知压缩建模为加权率失真问题，引入任务一致性判据并分析其成立条件：对线性任务证明其任务损失在合适交叉项条件下可写成信号无关权重的加权 MSE 形式；对非线性任务用积分梯度分析来启发可分任务感知权重；并讨论任务对称性与任务无关性对可容许权重的额外约束。
Method（方法）
  • 将任务感知压缩形式化为加权率失真问题，采用可分的逐分量加权失真，权重编码任务重要性且可依赖信源
  • 提出任务一致性（最小化加权失真即最小化真实任务损失）并刻画其成立条件
  • 对线性任务推导加权 MSE 形式与信号无关权重所需的交叉项条件
  • 对非线性任务使用积分梯度分析以启发可分任务感知权重
  • 分析任务对称性与任务无关性对可容许权重的约束
  • 实现权重条件化的单一学习式 ViT 编解码器，其 token 级注意力原生消费逐分量重要性向量，运行时仅替换注入权重即可从通用模式重定向到任务专用模式，无需重训练，并产生单份人类可看重建
