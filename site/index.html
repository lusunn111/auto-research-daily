Setting（研究设定）
在冻结基座 VLA 模型（OpenVLA-OFT 等）的前提下，学习一个轻量视觉令牌剪枝策略，用于机器人操作任务的高效推理；评估覆盖 LIBERO 仿真基准与真实世界操作任务。
Motivation（研究动机）
VLA 模型在每个控制步处理长多模态序列，视觉令牌占主导且存在大量冗余，导致计算开销大、延迟高，限制实时部署。现有方法要么依赖间接的免训练启发式（注意力分数、运动阈值），要么需要对基座 VLA 进行昂贵微调。
Insight（核心洞察）
令牌选择应以其对下游动作输出的实际影响为监督信号；在冻结基座 VLA 的前提下，用动作一致性学习训练轻量 patch scorer，可在激进剪枝下保持控制性能。
Challenge（技术挑战）
  • 免训练启发式只能间接估计令牌重要性，无法捕捉令牌移除对模型性能的实际影响
  • 免训练方法常需层/时间步特定的超参数或访问内部状态与注意力图，兼容性受限
  • 训练式方法需联合微调基座 VLA，代价高且将 checkpoint 绑定到特定剪枝机制
  • 训练时软剪枝与推理时硬 Top-K 剪枝之间存在不匹配
Analyze（问题分析）
作者将问题归结为：能否在不微调基座 VLA 的情况下，从令牌选择对下游动作的影响中学习有效的视觉令牌选择。通过对比免训练启发式与训练式联合微调两类方法的局限，提出以动作一致性作为学习信号，并用软 Top-K 松弛缓解训练-推理不匹配。
Method（方法）
  • 保持基座 VLA 完全冻结，训练一个轻量 Transformer 作为 patch scorer
  • 以动作级监督训练：剪枝视觉上下文产生的动作需与全上下文教师模型的动作保持一致
  • 使用真实动作作为辅助监督
  • 训练时用软 Top-K 松弛对视觉嵌入进行门控，并逐步锐化选择权重，缩小与推理时硬剪枝的差距
  • 每个相机视角在送入语言骨干前选择 Top-K 令牌
  • 不访问或修改基座模型内部状态，保持与现有 VLA 架构的兼容性
Experiments（实验）
  • 在 LIBERO 四个套件（Spatial、Object、Goal、Long）上评估，采用 OpenVLA-OFT 评估设置，每控制步预测 8 个连续动作；每个任务 3 个随机种子、50 次试验，每个套件 1500 回合；基线成功率取自对应论文
  • K=32 时减少 75% FLOPs，相对 OpenVLA-OFT 基线获得 1.5× 加速，平均成功率仅下降 1.4%
  • K=64 时减少 65% FLOPs，获得 1.4× 加速，平均成功率略超基线（+0.2%）
  • 两种配置在 LIBERO-Long 上差异最大，长时序轨迹对 K=32 时减少的视觉上下文更敏感
  • 支持最多 87.5% 的视觉令牌剪枝
  • 仅在单个 GPU 上训练数小时，5000 训练步，使用 AdamW，学习率 1e-4，batch size 8
  • VLA-Cache、SpecPrune-VLA、VLA-Pruner 依赖缓存 LLM 内部激活，破坏 FlashAttention 兼容性，实际延迟收益被抵消
  • 在真实世界操作任务上验证，并跨两个 VLA 骨干评估
Limitations（局限）
  • 在 K=32 时 LIBERO-Long 等长时序任务性能下降较明显，显示激进剪枝对长时序轨迹的视觉上下文敏感
  • 材料未提供更广泛的失败模式或部署限制的讨论

Analyze（问题分析）
论文从控制理论角度分析：CBF 约束控制输入以维持指定安全集的前向不变性，但其有效性取决于安全函数是否能捕捉受保护机器人几何与周围障碍物之间的分离；因此几何表征决定了可强制执行的碰撞模式。论文用平滑 Bernstein 多项式表示空间距离并组合正运动学，使几何间隙可对关节配置 q 微分，从而将几何间隙纳入基于优化的控制与几何 CBF 构造。
Method（方法）
  • 构建 grasp-conditioned safe set：用抓取模式 σ∈{0,1} 定义受保护几何集合 B_σ，抓取前为机器人本体集合 L，抓取确认后为 L 并上附着目标体 b_att。
  • 使用 BP-SDF（Bernstein 多项式符号距离场）表示受保护体与场景障碍物，并为每个机器人连杆 b 构造相对于配置 q 的间隙函数，利用光滑 Bernstein 表示提供空间距离梯度，并通过与正运动学复合使其对 q 可微。
  • 将演化的几何转化为可微 CBF 约束，作用于冻结 VLA 策略 π 输出的 7 维标称动作 a_nom=[u_nom; g_nom]，其中 u_nom=[Δp; Δr]∈R^6 为操作空间运动指令，g_nom 为标量夹爪指令。
  • 仅对 VLA 的六维操作空间动作进行最小修改以避碰，覆盖机器人、场景与附着几何，不重训练 VLA、不修改操作空间控制器。
  • 在给定 (u_nom, q, σ, O) 的条件下求解优化问题，其中 O 为需避碰的重建场景体集合，排除需要任务接触的物体，附着目标体不对自身施加约束。

Setting（研究设定）
