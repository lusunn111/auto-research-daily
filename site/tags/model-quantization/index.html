Setting（研究设定）
面向机器人操作的视觉-语言-动作模型，将连续动作信号通过分词器映射为离散 token 以适配自回归建模；在 RoboTwin、Simpler-Env 仿真基准及 3 个零样本真实世界任务上评估。
Motivation（研究动机）
现有离散动作分词器重建损失高，无法保留精确控制所需的细粒度动力学，形成“离散化瓶颈”，限制了 VLA 模型性能上限。
Insight（核心洞察）
高维动作空间不适合用残差向量量化表达，而应通过将隐动作特征分解为多个子空间（多个 head），并为每个 head 分配独立码本，利用多码本的组合密度提升表示表达能力，从而降低重建损失。
Challenge（技术挑战）
  • 语义纠缠：将 6-DoF 位姿与二值夹爪状态等异构信号投影到共享隐空间，难以显式建模不同动作维度的语义差异
  • 表示表达能力受限：RVQ 的容量受码本大小约束，缺乏覆盖高频操作动作空间所需的组合密度，导致粗略近似与细粒度控制细节丢失
Analyze（问题分析）
作者通过识别现有分词器的两类根本局限（语义纠缠与表示表达能力受限）来分析离散化瓶颈，并用 RoboTwin 数据上的重建 L1 损失对比不同分词器加以说明。
Method（方法）
  • 子空间分解：将隐动作特征拆分为多个 head，使模型隐式地将特定 head 对齐到不同的底层动力学（如末端执行器位姿 vs. 夹爪状态）
  • 组合量化：为每个 head 分配独立码本，利用多码本的组合性质扩展分词器的表示表达能力，显著降低重建损失
  • 轻量转换模块：使 VLA 模型能够有效解读多头多码本架构学习到的解耦语义，提升下游 VLA 性能
Experiments（实验）

  • 在 RoboTwin、Simpler-Env 及 3 个零样本真实世界任务上评估基于 M2Tok 的 VLA
  • 结果表明方法不仅实现更优重建保真度，还显著提升 VLA 模型成功率
  • 消融研究确认多头与多码本机制的有效性
  • 展示了两项操作任务案例：“Place Container Plate”与“Pick Diverse Bottles”，体现模型识别物体空间位置并执行精确抓取的能力

Setting（研究设定）
在6G无线网络环境下，多个异构机器人客户端以联邦学习方式协作训练/适配VLA模型，不共享原始交互数据；服务器聚合各客户端的模态特定更新，并针对视觉、语言、动作三条通路分别处理聚合、隐私预算与通信压缩。
Motivation（研究动机）
6G被视为大规模具身智能的关键基础设施，VLA模型可统一视觉感知、语言理解与动作生成，但将VLA模型分布式适配到机器人智能体面临隐私保护、通信效率和模型异构挑战。现有联邦学习方法只关注客户端级异构，忽略了VLA内部视觉、语言、动作通路在参数规模、隐私暴露、更新动态以及对压缩/扰动容忍度上的本质差异。
Insight（核心洞察）
VLA模型的视觉、语言和动作通路具有结构性差异：视觉编码器参数多且对视角/光照/场景敏感；语言通路常通过轻量模块适配且相对耐受量化；动作通路与本体、动力学和控制精度紧密耦合。统一处理三条通路会造成更新冲突、隐私预算错配和动作精度损失，因此需要模态解耦的联邦聚合、隐私分配和通信压缩。
Challenge（技术挑战）
  • 视觉、语言、动作通路间的梯度干涉与聚合冲突
  • 不同模态对差分隐私噪声的敏感度与容忍度差异大
  • 动作通路对量化/压缩极其敏感，统一压缩会导致末端执行器误差和抓取失败
  • 6G无线信道存在衰落、同频干扰和恶意干扰，需保障动作流的超可靠低时延传输
  • 客户端数据强非独立同分布且跨多种机器人本体与任务族
Analyze（问题分析）
作者通过分析VLA模型内部模态差异来论证模态解耦的必要性：指出视觉编码器参数重且对视角/光照/场景敏感，语言通路轻量且耐受量化，动作通路与本体和动力学紧耦合；并通过梯度几何测量显示跨本体动作更新相似度接近零、组内约0.6，视觉梯度形成三个场景簇，语言梯度对齐高于0.8；还通过逐模态压缩/噪声注入微基准量化各模态的扰动容忍度，从而支撑MAFA、MAPA、MACO三种机制的设计。
Method（方法）
  • 提出FedMVLA模态解耦联邦学习框架，包含模态感知联邦聚合（MAFA）、模态感知隐私分配（MAPA）、模态感知通信压缩（MACO）三种机制
  • MAFA通过差异化聚合拓扑缓解跨模态梯度干涉，针对动作、视觉、语言分别设计聚合方式
  • MAPA联合考虑各模态隐私敏感度与实测扰动容忍度来分配差分隐私预算
  • MACO为各模态匹配不同压缩方案，如视觉用Top-1%稀疏化加误差反馈，语言用4比特量化，动作保留FP32
  • 设计模态切片传输，将精度关键的动作流路由到受保护的URLLC切片，视觉和语言共享eMBB切片
  • 在基于3GPP TR 38.901室内工厂信道的仿真环境中，以OpenVLA风格VLA骨干开展联邦机器人操作案例研究
